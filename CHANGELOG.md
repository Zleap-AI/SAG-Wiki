# 更新日志 / Changelog

## 0.4.5

- **文档查看模式**可在「设置 → 通用」设为 Markdown 的默认打开方式，初始设置为编辑。在查看模式下点击右上角的「编辑」可原地修改，保存后回到查看模式。长 Markdown 和 PDF 的 Markdown 转换稿也适用。
- **修复 SAG Wiki 助手的回答流式输出**。配置回答模型后，回答会在生成过程中实时显示。

### English

- **Document view mode** can be set as the default for Markdown in **Settings → General**. Edit mode is the initial default. In view mode, click **Edit** to make changes in place, then save to return to view mode. This also applies to long Markdown documents and Markdown converted from PDFs.
- **Fixed streaming output in SAG Wiki Assistant**. With an answer model configured, the assistant displays the response as it is generated.

## 0.4.4

- **新增 Agent 产物导入功能**，支持归档 Claude Code、Claude Desktop、Codex 和 WorkBuddy 生成的文件。可按文件类型筛选、勾选文件，并为各应用单独开启自动同步。
- **Linux 网页端**支持从服务器已接入的文件夹导入和自动同步 Agent 产物。可以选择交付目录和归档位置，归档后的文件可在文件页查看。
- **聊天记录导入**新增 Claude Desktop 和 WorkBuddy。可预览和选择会话，再按来源保存为 Markdown。工具调用默认隐藏。
- **设置页**调整侧栏分组、间距和颜色，并将重新索引的提示放到操作旁。

### English

- **New agent artifact import** lets you archive files generated by Claude Code, Claude Desktop, Codex, and WorkBuddy. Filter by file type, select files to archive, and enable automatic sync for each app.
- **Linux web workspace** supports importing and automatically syncing agent artifacts from folders already added on the server. Choose the output folder and archive location, then view archived files in the Files tab.
- **Chat history import** now supports Claude Desktop and WorkBuddy. Preview and select conversations, then save them as Markdown grouped by source. Tool calls are hidden by default.
- **Settings** has updated sidebar groups, spacing, and colors. Reindex guidance appears next to the action.

## 0.4.3

- **在线数据源**新增 GitHub、GitLab、钉钉文档、腾讯 ima、API 请求和 Apify。GitHub 和 GitLab 可按分支、目录或单个 Markdown 文件同步。API 请求支持在桌面端和 Linux 网页端通过 GET 或 POST 获取 JSON，选择字段并定时追加到每日 Markdown，可在同一天内按记录 ID 去重，也可选用 AI 清洗。Apify 可在后台运行 Actor，将网页正文或选定字段导入为 Markdown，并按连接设置定时同步。
- **导入入口**统一为「设置 → 数据源」，也可从文件页右键进入。首次在线导入成功后可直达保存目录，默认导入位置在 `sag-wiki/data-sources/` 下按平台和连接组织。
- **网络代理**统一在「设置 → 网络代理」配置和测试。

### English

- **Online data sources** now include GitHub, GitLab, DingTalk Docs, Tencent ima, API requests, and Apify. Sync branches, folders, or individual Markdown files from GitHub and GitLab. On desktop and Linux web, use GET or POST to fetch JSON and append selected fields to daily Markdown files on a schedule, with optional same-day deduplication by record ID and AI cleanup. Apify can run Actors in the background and import web page content or selected fields as Markdown on a schedule for each connection.
- **Data import** is available under **Settings → Data sources** and from the Files context menu. You can go straight to the destination after a first successful online import. Default destinations are grouped by platform and connection under `sag-wiki/data-sources/`.
- **Network proxy** configuration and testing are available under **Settings → Network proxy**.

## 0.4.2

- **快速配置**：未配置回答模型时，问答首页和快速入门提供「快速配置」入口。填入一个 302.AI API Key 并测试通过后，自动配好 qwen3.8-flash 回答模型、jev-latest 决策模型和 302.AI MinerU 解析。新安装的默认回答模型改为 qwen3.8-flash。([PR #188](https://github.com/Zleap-AI/SAG-Wiki/pull/188))
- **网络代理**：新增「设置 → 网络代理」页面，可选跟随系统、自定义或不使用代理。自定义代理支持 SOCKS5 和账号密码，密码只保存在本机；测试连接会报告实际走的线路。([Issue #171](https://github.com/Zleap-AI/SAG-Wiki/issues/171)、[Issue #125](https://github.com/Zleap-AI/SAG-Wiki/issues/125)、[PR #183](https://github.com/Zleap-AI/SAG-Wiki/pull/183))
- **探索模式**：转换结果存放在应用数据目录时，PDF、Office 文档不再从探索视图中消失。([Issue #185](https://github.com/Zleap-AI/SAG-Wiki/issues/185)、[PR #186](https://github.com/Zleap-AI/SAG-Wiki/pull/186))
- **问答回复格式**：多轮追问时不再出现 `{"answer":…}` 形式的 JSON 回答。([PR #177](https://github.com/Zleap-AI/SAG-Wiki/pull/177))
- **上下文压缩**：压缩时显示“第 N/M 块”进度，不再像卡死；摘要失败时继续作答并说明原因，不再整轮失败。
- **空回答**：模型只返回空白时自动重试一次，仍为空则明确报错，不再显示“已完成”却没有正文。
- **工具调用**：同一轮内参数完全相同的重复检索自动跳过；每轮调用上限默认改为 20，已设为 0 的继续不限制。

### English

- **Quick setup**: While no answer model is configured, the chat home and the quick-start guide offer **Quick setup**. Enter one 302.AI API key; once the tests pass, the app configures the qwen3.8-flash answer model, the jev-latest decision model and 302.AI MinerU parsing. New installs default to qwen3.8-flash. ([PR #188](https://github.com/Zleap-AI/SAG-Wiki/pull/188))
- **Network proxy**: Add a **Settings → Network proxy** page with follow-system, custom and direct modes. A custom proxy accepts SOCKS5 and username/password, the password stays on this device, and **Test connection** reports the route taken. ([Issue #171](https://github.com/Zleap-AI/SAG-Wiki/issues/171), [Issue #125](https://github.com/Zleap-AI/SAG-Wiki/issues/125), [PR #183](https://github.com/Zleap-AI/SAG-Wiki/pull/183))
- **Explore mode**: PDF and Office documents no longer disappear from Explore when conversion results are stored in the application data directory. ([Issue #185](https://github.com/Zleap-AI/SAG-Wiki/issues/185), [PR #186](https://github.com/Zleap-AI/SAG-Wiki/pull/186))
- **Reply format**: Follow-up answers no longer come back as `{"answer":…}` JSON. ([PR #177](https://github.com/Zleap-AI/SAG-Wiki/pull/177))
- **Context compaction**: Compaction shows "part N of M" progress instead of looking stuck, and a failed summary no longer fails the turn; the answer continues with the reason shown.
- **Empty answers**: A whitespace-only reply is retried once, then reported as an error instead of a "complete" turn with no text.
- **Tool calls**: Repeated retrieval calls with identical arguments are skipped; the per-turn limit defaults to 20, and a saved 0 stays unlimited.
