# API 设置交互原型

已选定 **A：纵向分组** 作为设置页设计，连接、开关和 Key 管理集中在同一页。B、C 保留用于对照。原型复刻设置窗口外框，独立于正在修改的正式设置组件运行。所有数据为演示数据，只存于页面内存；不会启动服务、注册自启、访问真实知识库或修改真实密钥。

从仓库根目录运行：

```bash
python3 -m http.server 3240 --bind 127.0.0.1 --directory bench/api-settings-prototype
```

打开 `http://127.0.0.1:3240/?variant=A`，或直接打开本目录的 `index.html` 查看布局。

- A：纵向分组，接近现有设置页。
- B：服务连接与 API Key 分页。
- C：左侧连接控制，右侧 Key 管理。

底部浮动栏及左右方向键切换方案，输入框内的方向键保持正常。浮动栏“状态”可以查看原型当前状态，切换方案不会丢失本次会话内的修改，刷新后重置。

可操作：API 开关、自启开关、关闭 API 后编辑监听地址与端口、复制地址、创建并一次性查看演示 Key、撤销 Key、查看及复制调用示例。撤销最后一个 Key 后 API 保持运行，显示未授权提示。

页面右上角“API 文档”在新标签页打开本地文档站 `http://127.0.0.1:3236/zh/docs/api`，API 关闭或没有 Key 时也可使用。文档站侧栏的“API 服务”大类包含“API 说明”和“API 文档”两个选项。正式实现时跳转到已发布文档站的对应语言页面。

本地文档站需同时运行在 3236 端口。需要重新启动预览时，从仓库根目录执行：

```bash
npm --prefix docs-site run dev -- --hostname 127.0.0.1 --port 3236
```

当前示例使用 macOS 的登录自启文案；Linux 实际自启机制仍以设计文档为准。

原型未挂载到正式应用或生产构建入口。正式界面按 A 方案及设计文档实现。
