# SAG2 回归核对（2026-10-15）

本次核对覆盖客户端的请求分批、候选排序、文件分组与原文引用。原始知识文件和 Python 参考实现均只读。

## 发现与修复

### 未命中的扩展词被重复分词

客户端在名称修复没有改变词项时，仍会再次分词。最小复现中，`half-ounce` 被改成 `half ounce half-ounce`。原版只在名称确实发生修复时重新分词。

修复仅调整这一条件，不修改评分说明、候选数量或扩展轮数。新增测试先复现失败，再验证修复通过。

### 含组合标记的文字影响排序

客户端用于多样性排序的字符判断与 Python 参考实现不同。部分希伯来文、阿拉伯文的组合标记被保留在词中，改变了词频及片段相似度。已保存结果的第 165 题（索引 164）可复现排序不一致。

修复后按原版的字母、数字类别分词。加入希伯来文、阿拉伯文及组合重音字符测试，先复现失败，再验证修复通过。

## 分批核对

- 早期 `SAG2-Optimization/scripts/sag2.py` 有自动分批。当前 Python V10 参考文件仍含整轮超限报错，因此分批不能只以该文件作为正确基准。
- 客户端按每批约 32K 的本地估算值分批；服务返回 `max_tokens_exceeded` 时，仅继续拆分被拒绝的批次。
- 每批使用相同共享证据和完整候选正文，不截断原文。
- 测试强制后面的批次先返回、同一批答案倒序返回，合并后候选顺序和分数仍正确。
- 连续两层拆分不会丢失或重复候选。缺失编号、错误编号、错误评分类型及超出范围的分数均报错，不产出部分排序。
