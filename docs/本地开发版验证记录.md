日期：2026-10-14。平台：macOS / Apple Silicon。范围：第一版本地运行、文件安全、SAG2 确定性对照及主要界面操作。

## 已实现

- 独立 Tauri 应用与 SQLite 数据目录；产品名 SAG Desktop，避免与已有个人版混淆。
- 本地目录接入、嵌套去重、目录树、仅点击箭头展开、独立查询范围、根目录移除。
- Markdown 原文索引；Jieba 分词、FTS5 BM25、SAG2 v9 多轮扩展和 Jev 联合评分。
- 文件监听与增量更新：相同修改时间及文件大小时不重新读取；重新读取菜单会强制复核内容。
- @ 文件引用、回答模型切换、流式回答、可停止、引用快照、问答历史重命名与恢复。
- 默认可编辑的 Markdown 编辑器；新文件保存才落盘；草稿独立存储、外部修改冲突检查、原子替换。
- 模型设置、连接测试、系统凭据存储、移除已保存密钥；设置与历史存 SQLite。

## 本地客户端操作检查

所有操作使用 `.cache/ui-fixture` 中由本任务创建的文件，未操作用户原有知识库。

- 原生文件夹选择器添加目录；目录立即出现，随后后台建立索引。
- 新建文档直接进入编辑器，保存前磁盘不存在目标文件；保存后文件及索引均出现。
- 打开已有文档并直接保存，文件校验值不变。
- 使用范围树限定到“研究”；左侧目录展开状态和浏览位置不因此改变。
- 使用本机 `127.0.0.1:18080` 测试服务完成搜索 → 原文预览、问答 → 引用查看。
- @ 通过键盘选择文件；问答记录成功持久化，可重命名、删除和撤销。

正式 release 构建完成同样的问答和引用流程，重启后历史和模型配置可恢复。测试根目录移除后，5 份测试文件校验值均未变化。最后已移除测试目录接入、隐藏测试历史、恢复默认接口并清除两项临时密钥。

## 构建与资源

macOS release 应用约 16 MiB；启动主 JS gzip 约 39.3 KiB，CSS gzip 约 10.4 KiB。Markdown/编辑器的公共模块按需加载，gzip 约 172.9 KiB。生产构建中的大模块提示来自这个延迟加载模块。

这些数值不含系统 WebView，也不代表完整安装包、空闲内存和大库性能达标。完整压力测试、冷/热启动 P95、Windows 实机和签名/公证尚未完成。

## 已修复的启动问题

调试构建保存的临时凭据在 release 构建中触发系统授权取消错误。原实现因此中断了设置和文件列表初始化。现将凭据读取错误单独显示，文件管理可继续使用；同一 release 构建写入的测试凭据读取和清除均通过。跨构建的钥匙串授权仍由系统处理，发布签名后需要再次验证。
