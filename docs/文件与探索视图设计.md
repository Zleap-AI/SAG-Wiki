# 文件与探索视图设计

## 工作区与状态

知识库工作区提供文件和探索两种视图。浏览目录与问答、搜索范围分别管理。切换文件夹时保留对应会话的模式、滚动位置、关联图视野、选中文档和探索历史。

主要实现入口：

| 路径 | 职责 |
| --- | --- |
| `src/components/LibraryWorkspace.svelte` | 工作区模式与文件列表 |
| `src/components/ExploreView.svelte` | 关联图页面、文档选择、局部探索和证据 |
| `src/components/ExploreGraph.svelte` | 节点绘制、布局、缩放与拖动 |
| `src/lib/explore.ts` | 会话数据结构、图谱转换与历史状态 |
| `src/lib/graph-layout.ts` | 主要连线、视野、布局过渡和文件夹配色 |
| `src-tauri/src/explore.rs` | 本地关联计算、快照、分页与证据接口 |

## 文件视图

- 点击目录名称进入目录，点击树箭头只控制展开。
- 添加文件夹后提交后台索引，展示真实进度和错误。
- Markdown 支持编辑；其他支持格式使用只读视图。
- 移除知识库目录保留原始文件。子目录移除后持久排除，可从设置恢复。
- 外部文件变化更新目录数据，避免重置当前输入和滚动位置。

## 关联数据

文档关联使用本地派生词项和 TF-IDF 权重计算。连线表示内容相似，分数不作为答案正确率，也不表示文档互引或因果关系。生成图谱不调用 Jev 或回答模型。

接口返回当前范围、索引版本、文档信息与带快照标识的关联。文档哈希和索引版本用于识别过期结果。文件变化后刷新相关缓存和图谱数据，已失效的证据需要重新获取。

## 总览与局部探索

进入探索视图时展示当前范围的关系总览。总览在保持连通结构的基础上突出主要关联，减少大量弱连线的持续显示。悬停或选中文档时可以查看其达标的直接关联。

搜索框用于定位文档。单击节点打开侧边预览，双击或点击“查看局部”进入该文档的局部关系；“返回上一步”和“关系总览”恢复对应状态。

关联强度控制显示阈值。界面显示实际文档与连线数量，以及正在索引、部分失败等状态。

## 绘制与交互

图谱使用 Sigma、Graphology 和 ForceAtlas2。算法数据与前端显示状态分开，减少拖动和缩放期间的重复计算。

- 节点按父文件夹稳定配色，并适配明暗主题。
- 默认不显示常驻文件名，悬停时展示完整名称。
- 布局过程中节点和连线同步移动，收敛后保持视野稳定。
- 拖动用于平移或移动节点，滚轮用于缩放，提供显式的适应窗口操作。
- 系统减少动态效果设置下使用静态布局。
- 图谱组件按需加载；离开页面时取消未完成的数据请求和动画。

## 文档与证据

选中文档后，侧栏显示名称、路径、正文预览和相关文档。打开文档沿用桌面的统一文档入口。

关联证据通过独立接口读取，返回双方的原文片段、文件版本和共同词。查看证据不触发模型请求；索引版本失效时明确提示刷新。

## 实现边界

当前按文件夹配色，不据此推断自动主题分类。文档关联使用本地词项统计，涉及语义判断的自然语言问题继续由 SAG2 检索处理。依赖归属与许可证保存在 `src-tauri/licenses/GRAPH-VIEW.txt`。
