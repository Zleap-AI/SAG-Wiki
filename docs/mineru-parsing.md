# MinerU 文档解析

进入“设置 → 模型设置 → 文档解析 · MinerU”，选择302.AI（默认）或MinerU官方，只需填写对应API Key / Token。服务地址自动选择。保存密钥后自动优先使用MinerU，无需手动启用；清除当前服务商密钥后恢复本地解析。

## 解析顺序

启用后，受支持的PDF、图片及Office文档先使用MinerU；失败后依次尝试适用的内置anydoc和本地Docling。纯文本、Markdown、代码直接索引；MinerU不支持的其他格式进入原有本地链路。不会自动切换另一家云端服务，也不会自动安装Docling。

API Key按服务商分开保存。切换服务商会清空当前输入框，已保存密钥不回传前端；测试连接可使用尚未保存的输入，不上传文档或创建解析任务。测试返回“服务可达但密钥未确认”时，不代表密钥已验证或解析一定可用。

## 大文件与任务恢复

- 302.AI使用文件上传加MinerU官方代理任务接口；官方使用签名上传地址和批量结果查询。
- PDF按供应商200页限制以及上传字节限制拆分，合并后保留原始页号标记。所有分段成功才发布完整正文。
- 分段结果若缺少可验证的页码映射，则整体失败并降级。ZIP 结果的图片、原始 full.md 和 content-list JSON 保存在转换正文旁的 `.sag-mineru-assets/<结果哈希>/`，正文使用本地相对图片链接；不同结果互不覆盖。
- 图片目录不独立索引。检索保留图片描述及图注，过滤 Markdown 内联图片地址与 HTML img 标签的资源地址；搜索模型仍接收文本，不自动读取图片像素。
- 资源缓存独立于正文发布，重转或取消不会破坏已有正文引用。旧资源包保留在转换缓存中，不随单篇正文删除；302 直接返回 Markdown 时没有 ZIP 资源包，远程链接保持服务端原样。
- 任务记录保存在转换目录内的`.sag-mineru-tasks`，用于超时、暂停或重启后的续查；相同任务不盲目重复提交。提交响应丢失时记录为“结果未确认”，保留记录并降级本地。
- 解析模型、OCR、表格或公式选项、服务商变化会改变缓存标识；超时和并发变化不会重算已成功结果。
- 单次请求超时、总任务时限、轮询间隔、并发和识别选项可在高级解析参数中调整；文件/正文限制服从文件设置。

索引历史可查看各引擎的耗时、云端处理阶段、失败原因与降级结果。失败不会发布残缺正文或覆盖用户修改的转换文件；已有有效转换保留。停止索引会停止本地等待与结果发布，已提交云端任务不保证取消。
