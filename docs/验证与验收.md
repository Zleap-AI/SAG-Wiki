# 验证与验收

以下是正式客户端的完整验收条件，不代表各项均已通过。当前已有可本地运行的 macOS 开发版，实际检查结果见《本地开发版验证记录》。算法、文件写入和性能验收使用隔离测试目录，禁止修改用户真实知识库来制造测试事件。

## 原型还原

参考《原型交互规范》和《参考源码清单》。以当前 A 版为唯一界面基线，旧截图中的已删除控件不恢复。

每种系统分别检查 960 × 600、1280 × 800、1440 × 900，Windows 再检查 125% 与 150% 缩放。尺寸指应用窗口逻辑尺寸，截图记录实际内容区域。

| 页面 | 必须检查 |
| --- | --- |
| 主窗口 | 真实关闭、最小化、最大化、窗口拖动；没有原型外框与底部布局切换器 |
| 左侧 | 最近问答与文件夹有分隔线；加号及行末菜单对齐；最多一个内容选中状态 |
| 文件树 | 名称点击只浏览，箭头只展开；顶层三个点取代勾号；不默认展开；无独立“文件”入口 |
| 文件夹页 | 名称旁无三个点；新建独立；子层第一行返回；侧栏菜单可用 |
| 问答 | 中部引导、底部输入；“向你的文件提问”；有目录时不重复显示添加按钮 |
| 搜索首页 | 输入与引导整体中部偏上；文字前无文件夹按钮；下方范围按钮有效 |
| 搜索结果 | 无重复大标题；返回图标有效；列表与原文填满剩余高度并分别滚动 |
| 编辑器 | 默认可编辑，无阅读模式切换；创建立即进入；工具栏与原型相符 |
| 设置 | 分类、模型列表、Jev、参数、主题和字号可用，无不可用功能占位开关 |

同平台同字体的主要控件位置偏差目标不超过 4 个逻辑像素；字体抗锯齿和系统按钮不做逐像素强制一致。截图差异需逐项确认，不能只用整图相似率代替人工检查。最终提交同屏对照及实际客户端演示。

## 文件与数据安全

1. 添加一个目录、多个目录、先父后子、先子后父，都不重复索引或显示同一路径；普通嵌套浏览正常。
2. 顶层移除后原始文件字节不变，重启不重新接入；撤销可恢复。子文件和子目录没有删除操作。
3. 新建后不保存：磁盘无新 .md，索引无新记录；保存后两者出现。取消和放弃不写目标文件。
4. 未修改的文档保存前后字节完全一致；编辑后语义、frontmatter、HTML、自定义块、BOM、换行符和相对图片可保留。对不支持的语法显示明确边界。
5. 外部同时修改、同名文件、无权限、只读、磁盘写入失败、Windows 文件锁都不导致覆盖原文或写出半个文件。
6. 保存落盘成功但索引失败时反馈两种结果，并可重新索引；重启能恢复一致。
7. 外部创建、编辑、重命名、删除可更新文件树和索引。编辑器的临时文件及快速连续保存不产生重复结果。
8. 根目录消失、盘符变更、休眠恢复、监听溢出都显示状态，能重新读取；权限错误不等同于目录为空，不能因此清除历史和全部索引。
9. 重建索引不删除历史、草稿、模型配置；应用异常退出后不把未保存草稿误加入知识库。
10. 文档内的 HTML、脚本、协议链接和模型输出不能执行系统命令或访问接入范围外文件。

## SAG2 一致性

以同一语料、同一切分参数、同一模型响应做 Node 原版与 Rust 对照。固定 Jev 响应可以离线复现，真实 API 的随机变化不用于判定代码是否一致。

| 检查对象 | 通过条件 |
| --- | --- |
| 原文解析 | 段落、章节、代码块和行范围一致；空文件明确标记为无可检索正文，仍可浏览编辑 |
| 分词 | NFKC、大小写、中文、英文缩写、连字符、停用词与词典结果一致 |
| 初始召回 | 片段和顺序一致，BM25 数值在约定浮点容差内 |
| 扩展 | 每轮起点、扩展词、名称短语、各项候选与交替合并顺序一致 |
| 联合评分 | 首轮前 5、累计起点、新候选、公共证据及候选字段一致 |
| Jev 请求 | 提示词、Noul 字段、批次边界、估算 token、附加预算一致 |
| 最终结果 | 固定响应下片段排序完全一致；不增加阈值与最终重排 |
| 停止与失败 | 无候选、无扩展词、预算超限、取消、重试和服务返回格式错误按规则处理 |

固定测试包含中文、英文、混合术语、emoji、长代码块、同分结果、相同内容不同路径，以及不同范围。UTF-16 长度、单行部分引用、CRLF 边界、locale 排序和浮点累加必须有专门样本，避免只在英文短文上对齐。

范围测试检查 LIMIT 之前筛选，以及每轮候选、起点、公共证据、回答引用；无 @ 时必须全部属于所选范围。有 @ 时仅允许显式引用文件作为范围外例外。还需验证范围相似路径、文件移除、失效引用、任务执行中源文件变化。

使用相同模型、同一批有证据标签的问题，分别记录 Rust 与原版 Recall@5、Recall@10、查询时长和用量。确定性测试要求完全一致；真实模型测试若出现差异，先保存逐轮轨迹定位，不能用总分接近掩盖不同实现。

另建小型真实 Markdown 评测集，覆盖单跳、多跳、无答案、目录限定和多轮追问。记录检索证据命中与答案引用支持率；不能把公开基准的分数直接当作用户知识库效果保证。

## 问答与历史

- 回答模型列表保存与切换有效，Jev 和回答模型分别测试连接。
- @ 候选只加载文件元数据，支持键盘和中文输入法组合输入，不在组词阶段误触发发送。
- 首条消息即时持久化；重启恢复标题、消息、范围、模型与引用。
- 重命名后继续提问不会覆盖自定义标题；删除、撤销均不产生重复历史。
- 追问使用正确上下文；可查看实际检索问题，旧问题不因新回答被改写。
- 停止后旧任务不继续修改界面；网络重试可取消；更换范围后不显示迟到结果。
- 来源已改动或移除仍能查看生成时的引用片段，跳转到当前文件时有明确版本提示。
- Jev 无法连接时说明检索失败；回答模型失败时保留已检索证据；都不能伪造答案或完成状态。

## 资源与速度目标

以下是待验证的工程目标，不能在发布说明中写为已实现数据。记录硬件、系统版本、SQLite/词典/依赖版本、杀毒软件、运行模式、文件数量和总字节数。

| 项目 | 首轮目标 | 测量方法 |
| --- | --- | --- |
| 压缩安装包 | 每架构 ≤ 30 MiB | release 包，系统 WebView2 另列；不含签名调试产物 |
| 主界面资源 | JS + CSS gzip ≤ 150 KiB | 不含延迟加载编辑器；编辑器另列，目标 ≤ 300 KiB |
| 空闲内存 | macOS ≤ 150 MiB；Windows ≤ 220 MiB | 已有 1 万篇文档，打开普通页面静置 60 秒，计入整个应用及 WebView 进程组 |
| 空闲 CPU | 30 秒平均低于单逻辑核 0.5% | 无索引、查询、动画和外部文件变化 |
| 热启动可操作 | ≤ 1 秒 | 已建索引，启动到导航与输入可操作，20 次取 P95 |
| 冷启动可操作 | ≤ 2 秒 | 冷缓存条件单独记录，不混入热启动数据 |
| 接入即时反馈 | ≤ 150 毫秒 | 系统选目录返回到根目录出现在界面，后续扫描不阻塞 |
| 1000 篇首建索引 | ≤ 3 秒 | 本地 SSD，UTF-8 Markdown 合计 10 MiB；包括读取、切分、分词和提交 |
| 1 万篇首建索引 | ≤ 20 秒 | 本地 SSD，合计 100 MiB，不含排除目录和模型请求 |
| 树展开与目录切换 | P95 ≤ 100 毫秒 | 已加载元数据，大列表使用可见行渲染；分开记录首次磁盘读取 |
| 单篇索引更新 | P95 ≤ 500 毫秒 | 50 KiB 文档，单独记录事件合并等待时间 |
| 本地 BM25 首轮 | P95 ≤ 100 毫秒 | 1 万篇已建索引，中英文各取至少 50 次查询 |

macOS 记录进程组实际内存占用，Windows 记录私有工作集；不同系统指标分别报告，不直接当作同一口径比较。上述预算不含第三方模型服务资源。

SAG2 总耗时主要受 Jev 网络和评分批次影响，单独报告本地耗时、网络等待、轮数、批次和用量。回答首字还受回答模型影响，不承诺整个多跳问答在毫秒内完成。

大库压力测试增加到 10 万篇，记录峰值内存、首建时间、数据库大小和界面响应。此项用于暴露瓶颈，首版不在未测量前承诺 10 万篇仍保持前述全部目标。

一项超过预算时给出定位结果和改进记录；不通过清空数据、跳过子目录、截断文本或减少固定评测候选来制造达标结果。

## 平台与发布

macOS Apple Silicon 与 Windows x64 从阶段 0 开始实机测试，Intel 版本在声明支持前单独测试。检查系统按钮、中文输入、字体、缩放、剪贴板、目录选择、系统定位、路径权限、睡眠恢复、安装及卸载。

发布包需验证签名、公证（macOS）、WebView2 安装提示（Windows）、首次启动无目录、旧版本数据迁移、索引重建和历史保留。Windows 干净系统与已安装运行时系统分别记录下载大小。
