# 原型交互规范

本规范汇总截至 2026-10-14 已确认的界面与操作。正式客户端沿用当前黑白原型 A 版。标注“方案决定”的条目用于补齐真实客户端必需行为，不表示原型已经实现。

## 界面结构

桌面界面由系统标题栏、左侧导航和文件树、右侧工作区组成。只面向桌面，不制作移动端。默认最小窗口 960 × 600，可调整大小。

左侧依次为 SAG 标识、问答和搜索、最近问答、分隔线、文件夹树、底部设置入口。最近问答和文件夹的加号处于同一竖直位置，行末操作按钮对齐。分隔线和上下间距要能清楚区分历史与文件区域。

右侧每次只显示当前页面：问答、搜索、文件夹内容或文档编辑器。切换到问答历史时，文件夹保留浏览位置，但不显示选中底色；浏览文件夹或编辑文件时，问答历史不显示选中底色。导航入口的当前页面状态可以保留。

沿用原型颜色、字体体系、边框、圆角、图标、文本和控件间距；不引入新的卡片风格、彩色状态面板或整套 UI 库。系统字体分别适配 macOS 和 Windows，不打包额外字体。

正式版去掉原型底部布局切换器、模拟桌面外框和“尚未连接 SAG2”说明。标题栏使用真实的关闭、最小化、最大化操作；macOS 保留系统窗口按钮，Windows 保留对应系统习惯。系统控件允许平台差异。

## 本地文件夹树

只有真实的已添加本地文件夹，不设置“示例文件夹”和独立“文件”导航。

- 点击文件夹名称：只在右侧浏览内容，左侧树的展开状态不变，问答和搜索范围不变。
- 点击左侧箭头：只展开或收起这条分支，不切换右侧页面。
- 点击 Markdown：打开可编辑文档。
- 顶层已添加文件夹右侧显示三个点，替代勾号；点击后打开菜单。
- 顶层目录菜单提供问答、搜索、重新读取、移除。
- 子文件夹右键提供问答、搜索、在 Finder 中打开；Windows 显示“在文件资源管理器中打开”。
- 子文件右键提供在系统文件管理器中定位，不提供删除。
- “移除”仅用于直接管理的顶层接入目录。移除后退出知识库，原磁盘文件保留。
- 文件夹页面标题旁不放三个点；新建文档按钮保持独立。
- 嵌套文件夹内容列表的第一行提供“返回上一层”。

方案决定：首次启动恢复目录时默认收起树，不因为后台索引或重新读取而展开。用户已展开的分支在当前使用过程中保持状态。

侧栏加号打开系统目录选择器，支持连续添加多个目录。原型中的本地路径浏览保留为文件树的交互参考；正式版不在侧栏直接展示整个磁盘。权限只覆盖用户明确选择的目录。

方案决定：接入目录采用不重叠的覆盖范围。已添加父目录时，再添加其中的子目录只定位该目录，不重复添加；先添加子目录再添加父目录时，将这些子目录合并到父目录下。文件树中同一路径只显示一次。移除这个父目录会取消其整个覆盖范围。普通嵌套浏览始终支持。

## 添加与索引反馈

无目录时显示“你的文件，直接成为知识库”，并提供添加本地文件夹按钮。有目录后，问答主区域不再重复显示添加按钮；侧栏加号继续可用。

突出优势：选择文件夹即可接入，无需逐篇上传、Embedding 或模型预处理。目录先出现，文件扫描和本地索引随后完成。读取或索引尚未完成时显示真实状态和数量，不能提前宣称全部可检索。

默认索引 .md 文件，包含全部子目录。方案决定：默认排除 .git、node_modules、dist 的索引扫描；排除目录仍可在树中查看并在系统文件管理器中打开。该规则在设置中明确展示，并允许调整。隐藏项显示与是否索引分别控制，不把“隐藏”当成“排除”。符号链接目录显示为链接，不递归扫描目标。

## 文件夹内容页

保持原型简单列表：上方名称、文件与子文件夹数量、独立新建文档按钮；下方按层级列出目录和 Markdown。

列表项单击即可进入。浏览不修改查询范围。文件创建、外部改动和索引状态局部更新，不整页刷新，不打断输入和滚动。

## 新建与编辑

点击新建文档直接进入所见即所得编辑器，默认可编辑，没有“阅读／编辑”切换，也没有阅读模式。

新文档保存前只作为草稿存在，不创建目标 .md，不进入文件树、索引和检索结果。点击保存或 Cmd/Ctrl + S 后，创建到当前文件夹并自动索引。文件名必须合法且不覆盖已有文件。

现有文件同样默认编辑，支持标题、粗体、斜体、删除线、列表、引用、代码、链接、表格和图片。保持当前编辑器工具栏和正文宽度。点击保存后写入磁盘并更新索引；第一版默认手动保存。

有未保存内容时离开编辑器或关闭窗口，提供保存、放弃、取消。方案决定：为防程序异常退出，草稿可恢复地保存在应用数据中，但不因此创建源文件或加入索引；明确放弃后清除草稿。

外部程序同时修改当前文件时提示冲突，不静默覆盖。相对路径图片从文档所在目录解析。无法完整编辑的 Markdown 扩展语法保留原始内容，不因打开或保存而丢失。

## 问答

默认页面沿用原型：中部 SAG 标识、“向你的文件提问”、简短说明；输入框靠底部。文案始终使用“文件”。

输入框下方保留查询范围和回答模型选择，默认范围为“全部文件”。输入 @ 打开文件候选，支持键盘上下选择、Enter 确认、Esc 关闭。选中的文件显示为可移除标签。

Enter 发送，Shift + Enter 换行。生成过程中可停止，显示实际执行阶段。消息输出逐步出现，答案含可点击原文引用。

方案决定：@ 文件是显式证据范围，和当前文件夹范围取并集。范围按钮的选择本身不被改写；超出目录范围的文件以 @ 标签明确可见。只有这些用户明确引用的文件允许作为目录范围外证据，其他召回和扩展均受目录范围限制。缺失或已失效的引用阻止本次提交并提示重新选择。

多轮问答保留对话上下文。方案决定：遇到“它”“上面的方法”等追问，回答模型先生成独立检索问题，界面可在检索详情中查看；首个独立问题不增加改写请求。改写失败给出错误，不无提示切换成其他检索方式。该步骤与 SAG2 检索分别记录。

引用展开应能看到生成时使用的原文片段和来源；打开当前文档时，若文件已变化或不存在，保留证据快照并明确提示。

## 最近问答

左侧始终有最近问答区域，无记录显示空状态。新问答通过加号创建，首次提交才形成持久记录。

点击历史恢复对话。每行三个点提供重命名和删除，重命名不会被后续消息覆盖。删除有短暂撤销入口；不引入额外的历史管理页面。历史保存问题、答案、时间、范围、模型和必要引用快照。

## 搜索

搜索首页沿用当前黑白风格，标识、标题、说明和输入框组成一组，位于工作区中部偏上。保持最后确认的上移位置，并随窗口高度适度调整。

输入框文字前不放文件夹按钮。下方左侧为范围选择，默认为全部文件；发送按钮前提供“深入／快速”模式切换，默认深入。回车或点击提交才搜索，不因每次按键调用 Jev。已有查询切换模式时重新执行搜索。

结果页不重复显示大号“搜索”标题。输入框前是返回图标，返回首页时保留关键词和范围。下方左侧为命中文件和片段，右侧为原文预览与打开文档按钮；结果区填满剩余高度，各自滚动，不留固定的大块底部空白。

同一文档的多个命中片段合并为一个文件结果，以最相关片段排序，仍可查看该文档的其他命中片段。空结果、查询中、网络失败显示不同状态。搜索和问答使用同一个 SAG2 检索实现。

快速搜索不限制命中文件总数，每页显示 20 个文件。结果区下方显示当前范围、总数、上一页、下一页和页码；翻页后列表回到顶部。修改查询、范围或模式时回到第一页；翻页失败或停止时保留原页。

深入搜索展示最多 100 个文件，按已排好的文件顺序每页显示 20 个，不应用问答的返回片段数量限制。完整排序结果保留在当前搜索页面，翻页只切换显示范围，不重新检索或调用模型。文件不足 100 个时显示实际数量，不补入未命中文件。结果摘要旁不再放单独的“深入搜索”按钮。

## 范围选择

问答和搜索共用当前范围设置，默认全部文件。打开范围面板后显示可展开的文件夹树，支持多选。父目录包含全部子目录，重复覆盖只计算一次。

点击箭头只展开，点击勾选项只选择。取消不改变原范围，应用后才改变。通过目录右键的“问答”或“搜索”明确将范围切到该目录，并进入相应页面。

范围变化不改写已有答案、引用或历史。切换范围时取消旧范围正在运行的检索，避免迟到结果覆盖当前页面。

## 设置

保持现有分类：通用、外观、文件与编辑、快捷键、模型设置、检索设置、数据与隐私、关于。

第一版实际接入的设置：启动页，浅色／深色／跟随系统，字号，自动监听，隐藏项显示，排除目录，回答模型列表与选择，Jev 地址与模型，密钥，连接测试，请求超时，SAG2 参数，打开应用数据目录，重建索引。固定算法规则显示说明，不提供无依据的高级开关。

保持当前原型模型配置分为 LLM 和 Jev 两组，默认服务地址沿用原型中的 api.302ai.cn 配置，允许用户修改。服务可用性通过连接测试验证，不根据模型名推定支持。只保存后的设置生效。

第一版默认关闭自动保存和开机启动，关闭最后一个窗口时退出应用。自动保存、开机启动、后台常驻属于后续独立功能，正式版不展示当前不可用的灰色占位开关。“减少动态效果”跟随系统偏好。
