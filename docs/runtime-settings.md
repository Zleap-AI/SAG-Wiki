# 运行参数设置

文件设置、模型设置、搜索设置、问答设置提供对应的运行参数。常用转换超时直接展示，线程、内存、批量、缓存等收在“高级运行参数”；可恢复本组默认。默认值和范围由服务端统一提供。

保存后新任务使用新值，运行中的转换及结果接收沿用启动时的设置。修改超时、并发、缓存不重建索引；OCR、表格识别、页数或解析引擎变化会在后续扫描重算相关转换。

| 页面 | 参数 |
| --- | --- |
| 文件设置 | 内置转换超时、Docling 转换超时、输入/输出大小、线程、OCR/版面/表格批量、队列、页数、OCR/表格开关、内存预算、文本输入/解码/准备限制、文件变更合并 |
| 模型设置 | 模型失败重试次数、指数退避初始/最大间隔、模型请求总时限 |
| 搜索设置 | 本地查询线程、查询/语料缓存、JEV 请求并发、JEV 单批上下文预算 |
| 问答设置 | 文档折叠并发、每批段落数 |

- 内置转换默认120秒；Docling默认1800秒，外层额外保留60秒退出清理，用户只需调整一项。
- HTTP499也计入失败重试，总时限覆盖重试、等待和响应读取。
- 索引并行数、转换并行数和模型请求超时继续使用已有控件。
- 转换内存默认保留物理内存的一半给系统；单任务内存0表示自动。页面显示已保存配置的资源上限，实际并发还受“转换并行数”和其他运行中任务限制。
- 转换正文默认16MiB，与后续索引输入上限一致；要接收更大文本，应一起提高转换正文、索引输入、解码、准备及总准备预算。服务端拒绝互相冲突的组合。
- anydoc延续原实现：超时后放弃结果，原生转换线程可能继续执行，直到库调用返回；Docling超时会终止子进程树。

完整字段、默认值、范围和生效说明见 `protocol/src/runtime.rs`。协议帧大小、进程监控采样、数据库锁等待、日志缓冲、版本标识和组件安装/更新网络时限仍由程序管理，不作为普通解析任务参数。
