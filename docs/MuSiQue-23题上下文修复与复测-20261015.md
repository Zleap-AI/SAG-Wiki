## 最终保留的修改

- 每次工具返回后重新组织模型上下文，保留原问题、真实片段和工具实际结果，移除检索前的推测和旧分析。
- 同时保留实际执行的查询、拒绝或错误状态，以及剩余调用次数，避免刷新上下文后丢失调用状态。
- 必要关系缺失且尚有调用次数时，要求先检索缺失关系；次数用完仍缺证据时说明不足。
- SAG2 与 MCP 的工具选择、按模型启停、总调用上限、流式输出和引用编号保持原有机制。

没有加入强制非空答案、标准答案提示、题号特判或补充外部知识。独立模型复核方案在实测中出现误拒正确答案、误放错误答案，且增加调用，因此已移除，未保留在交付版本。

已用可重复测试复现旧问题：第一次检索前的错误猜测仍出现在下一次请求。修复后该测试通过；上下文刷新后的剩余次数和实际查询也有测试覆盖。最终后端 73 项测试通过，1 项原有测试跳过。

## 语料与模型限制

不能把“命中全部标注段落”直接等同于“原文证据完整”。在同一语料内检查发现：

| 题目或现象 | 核对结果 |
|---|---|
| Godiva 出生地被撤销的年份 | 语料中提到 Godiva 的相关段落说明她与修道院的关系，未写出生地。无法仅据此连接到 Mercia。 |
| Shrek 2 配音演员的配偶 | 标注段落写 Jennifer Saunders 与 Adrian Edmondson 合作，没有写两人婚姻关系。全库出现 Saunders 的 4 个段落中未找到配偶记载。 |
| Saudi Arabia 成立年份 | 不同段落分别写 1930 和 1932，存在来源冲突；本轮仍按原标准评分，没有改标签。 |
| `June`、`22 times` | 与标准答案 `mid-June`、`22` 的严格匹配不同。保留原评分，也保留完整回答便于人工核对。 |
| Kosovo 奥运题 | 原文可连接到 Kosovo 和 2016，当前 Qwen 仍答错，是尚未解决的模型理解问题。 |

另用相同代码、相同 23 题和语料，仅将回答模型换为 `gpt-5.6-sol` 做对照：严格答对 8/23，F1 44.53%，失败 0 题。它修正了部分关系判断，但也有空答和误答，不能作为已经解决全部问题的证据。客户端的默认模型设置未改变。
