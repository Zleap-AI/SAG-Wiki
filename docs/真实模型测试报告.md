## 结果

下列时间为独立调用客户端同一 Rust 模块的一次测量；包括网络等待，问答项还包括回答生成。它不是性能分位数或大型知识库承诺。

| 测试 | Jev 评分轮数 | 用时 | 结果 |
| --- | --- | --- | --- |
| 标识转换搜索 | 3 | 7.33 秒 | 命中 sag-align.md，找到 revert_id() |
| 跨文件问答 | 3 | 27.63 秒 | 同时找到导入、导出规则；回答需要新建派生资产并记录三个来源字段 |
| 限定目录搜索 | 2 | 4.02 秒 | 命中 api/create-result.md；全部返回片段均在 api 内 |
| 无答案问答 | 3 | 16.68 秒 | 明确证据不足，未编造负责人、预算和日期 |

具体问题、完整回答、候选、分数和扩展词保存在 [结构化结果](real-model-test/results.json)。

跨文件回答的关键结论已与原文核对：重新传播本地增强结果时，应创建新的 Derived Asset，并通过 `asset.derived_from` 记录 `asset_id`、`version`、`package_digest`。证据来自 `exporting-octx.md`、`importing-octx.md`、`GLOSSARY.md` 等文件。回答中的引用编号均指向实际返回证据。

无答案问题为文档中不存在的“星澜计划 ZL-94817”的负责人、预算和上线日期。最终候选评分为 0.04–0.06，回答明确表示文档未提及，证据不足。SAG2 保留原版 Top K 行为，低分候选没有被额外阈值过滤。
