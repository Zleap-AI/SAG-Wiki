---
title: "RSS / Atom"
description: "将 RSS 或 Atom 订阅中的文章导入知识库。"
---

RSS 和 Atom 是网站用来发布文章更新的订阅格式，常见于博客和新闻网站。[RSS 2.0 规范](https://www.rssboard.org/rss-specification) · [Atom 规范](https://www.rfc-editor.org/rfc/rfc4287)

1. 在 **设置 → 数据源 → RSS / Atom → 配置** 新建连接，输入订阅地址，再点 **测试连接**。地址为空时，按 Enter 或 Tab 可填入占位提示显示的示例。中文界面显示[智跃博客中文订阅](https://zleap.com/blog/rss.xml)，其他语言界面显示[英文订阅](https://zleap.com/en/blog/rss.xml)。
2. 核对订阅名称和保存位置，点 **保存并导入**。导入文件保留原文链接，并使用订阅提供的正文或标明为摘要的内容。
