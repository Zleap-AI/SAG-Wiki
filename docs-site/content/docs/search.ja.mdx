## クイック検索

**検索** を開き、ファイル名や本文に含まれる語句を入力します。クイック検索はインデックスを使ってローカルで動作し、モデルの API キーは不要です。結果を選択すると原文が開き、一致箇所が強調されます。

デスクトップアプリの実行中は、ほかのアプリを利用していてもショートカット検索を呼び出せます。既定の組み合わせは macOS が **⌘⇧Space**、Windows が **Ctrl+Shift+Space** です。[設定ガイド](/ja/docs/preferences)で変更できます。

## 詳細検索

質問の意味に沿って複数の資料から根拠を探すには、モデル設定で Jev を設定し、検索画面で詳細検索を選びます。探したい内容を具体的に入力し、結果のスニペットと原文を照らし合わせてください。

検索対象を限定したいときはフォルダーを指定します。根拠をまとめた回答も必要な場合は[質問応答](/ja/docs/chat)を使います。
