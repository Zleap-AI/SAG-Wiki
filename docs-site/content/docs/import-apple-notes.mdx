---
title: "Apple Notes"
description: "在 macOS 上导入本机已下载的备忘录。"
---

备忘录是 Apple 的笔记应用，可用来记录文字、清单和附件。[Apple 备忘录官方指南](https://support.apple.com/zh-hans/guide/notes/welcome/mac)

1. 在 SAG Wiki 的 macOS 桌面端[打开数据源](/zh/docs/data-sources#打开数据源)，点击 **Apple Notes** 旁的 **导入笔记**。
2. 勾选要导入的备忘录文件夹，确认保存位置后点击 **导入**。锁定的备忘录需要先在备忘录应用中解锁。

![选择要从本机备忘录导入的文件夹](/images/product-source-apple-notes-cn.png)

如果弹窗提示授权，点击 **打开系统设置**，在 **隐私与安全性 → 完全磁盘访问权限** 中开启当前 SAG Wiki 应用。返回后可点 **重新检查**。也可以用 **选择数据文件夹** 读取包含 `NoteStore.sqlite` 和附件目录的数据副本。
