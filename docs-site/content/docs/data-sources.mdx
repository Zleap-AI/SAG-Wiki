---
title: "连接与同步"
description: "导入本地内容，连接并同步在线来源。"
---

通过数据源，你可以导入 [Claude Code](/zh/docs/import-claude-code) 和 [Codex](/zh/docs/import-codex) 的聊天记录，以及 [Evernote](/zh/docs/import-evernote)、[Google Keep](/zh/docs/import-google-keep) 和 [Apple Notes](/zh/docs/import-apple-notes) 的笔记。也可以连接 Notion、飞书或 GitHub，选择要导入的内容，并为每个连接设置定时同步。导入的内容会加入本地知识库，可以搜索原文，也可以在问答中引用。

## 打开数据源

在桌面端点击右上角的插头图标 **数据源**，也可以从 **设置 → 数据源** 进入。

### 在文件页右键

在桌面端打开 **文件** 页的 **已索引文件** 总览，在列表空白处右键，选择 **导入数据**。

![文件页右键菜单中的导入数据](/images/product-import-context-cn.png)

### 从添加文件夹打开

点击侧栏的 **+** 或文件页的 **添加文件夹**，在窗口中切换到 **导入数据** 标签页，再选择来源。

![添加文件夹窗口中的导入数据标签页](/images/product-add-data-cn.png)

## 在线数据源

点击来源名称旁的时钟图标或右侧 **配置**。打开弹窗后，点击标题旁的 **配置教程** 可查看当前来源的操作步骤。

![数据源设置中的在线来源与定时同步入口](/images/product-online-import-cn.png)

- [Notion](/zh/docs/data-source-notion) · 连接 Notion，导入授权页面及其附件。
- [飞书](/zh/docs/data-source-feishu) · 导入飞书知识库与云盘中的文档。
- [Lark](/zh/docs/data-source-lark) · 导入 Lark 知识库与云盘中的文档。
- [语雀](/zh/docs/data-source-yuque) · 导入语雀个人或团队知识库中的文档。
- [GitHub](/zh/docs/data-source-github) · 从选定的 GitHub 分支和目录同步 Markdown。
- [GitLab](/zh/docs/data-source-gitlab) · 从选定的 GitLab 分支同步 Markdown。
- [钉钉文档](/zh/docs/data-source-dingtalk) · 将钉钉知识库中的在线文档导入为 Markdown。
- [腾讯 ima](/zh/docs/data-source-ima) · 导入腾讯 ima 知识库里的笔记、网页和文件。
- [RSS / Atom](/zh/docs/data-source-rss) · 将 RSS 或 Atom 订阅中的文章导入知识库。
- [Apify](/zh/docs/data-source-apify) · 通过 Actor 导入网页 Markdown 或结构化结果。
- [API 请求](/zh/docs/data-source-api) · 请求返回 JSON 的接口，选择字段后按天导入 Markdown。

支持定时同步的来源可按连接[设置同步计划](/zh/docs/data-source-scheduled-sync)。
