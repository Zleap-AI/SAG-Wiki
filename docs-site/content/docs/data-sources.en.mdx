Use Data sources to import local chat history from [Claude Code](/en/docs/import-claude-code), [Claude Desktop](/en/docs/import-claude-desktop), [Codex](/en/docs/import-codex), or [WorkBuddy](/en/docs/import-workbuddy) and notes from [Evernote](/en/docs/import-evernote), [Google Keep](/en/docs/import-google-keep), or [Apple Notes](/en/docs/import-apple-notes). You can also connect Notion, Feishu, or GitHub, choose what to import, and set a schedule for each connection. Imported content is added to your local knowledge base, where you can search it or reference it in Q&A.

## Open Data sources

In the desktop app, click the **Data sources** plug icon at the top right or open **Settings → Data sources**. The page lists **Agent**, **Online sources**, and **Third-party apps** in that order.

### Right-click in Files

On desktop, open the **Indexed files** overview in **Files**, right-click an empty area of the list, and choose **Import data**.

![Import data in the Files context menu](/images/product-import-context-en.png)

### Open Add folder

Click **+** in the sidebar or **Add folder** on the Files page. Switch to the **Import data** tab and choose a source.

![Import data tab in the Add folder window](/images/product-add-data-en.png)

Click **Import chat history** next to Claude Desktop or WorkBuddy to preview and select sessions. Claude Desktop imports locally saved Chat and Cowork sessions. The selected chats are saved as Markdown in the `claude desktop` and `workbuddy` subfolders of your chat archive. Tool calls are hidden by default.

## Agent Artifacts

In the desktop app or [web app](/en/docs/remote-access), open **Settings → Data sources → Agent**. Click **Import artifacts** next to Claude Code, Claude Desktop, Codex, or WorkBuddy.

In the desktop app, SAG reads final replies in Claude Code's local chat history. In a reply, list one file link or path per line under **Final deliverables** or **Delivered files**. SAG checks those paths for existing files and skips missing ones.

For other apps, SAG discovers known output folders on macOS. For Codex, it scans files and HTML projects directly under task `outputs` folders. For WorkBuddy, it uses WorkBuddy's artifact list and includes files that still exist in the default workspace. Use **Choose folder** or **Change** to select an output folder manually, including on Windows.

When configuration opens, SAG selects the artifacts it finds. You can clear individual files or the entire selection. HTML, PPT, Word, Excel / CSV, PDF, Markdown, and images are enabled by default. The format filter applies to both existing and future artifacts.

Click **Import** to archive selected artifacts in a separate folder for each source. The desktop app defaults to `Documents/sag-wiki/agent-artifacts/`. An HTML project folder containing `index.html` or `index.htm` is copied together with its local assets.

**Automatic sync** is off by default. Turn it on to import the selected artifacts immediately and sync new or updated output from that app while SAG is running. SAG skips unchanged files that you deselected when turning on sync or deleted from the archive. If you edit an archived copy, SAG saves later updates as separate files. After turning off sync, existing copies remain in [Files](/en/docs/files). Use **Open original file** from the context menu to open an archived copy in its default application. Search follows the file type and indexing settings.

### Choose an output folder in the web app

Under **Output folder**, select a connected folder on the server. SAG scans that folder and lists the files you can import. The **Save location** defaults to the `agent-artifacts` folder in the web library. You can select another connected folder. Select files and click **Import**, or enable **Automatic sync** to keep collecting new output.

## Online sources

Click the clock next to a source or choose **Configure**. In the dialog, click **Setup guide** next to the title for the source's instructions.

![Online sources and scheduled sync in Data sources settings](/images/product-online-import-en.png)

- [Notion](/en/docs/data-source-notion) · Connect Notion and import authorized pages and their attachments.
- [Feishu](/en/docs/data-source-feishu) · Import documents from Feishu knowledge bases and Drive.
- [Lark](/en/docs/data-source-lark) · Import documents from Lark knowledge bases and Drive.
- [Yuque](/en/docs/data-source-yuque) · Import documents from personal or team books in Yuque.
- [GitHub](/en/docs/data-source-github) · Sync Markdown from selected GitHub branches and folders.
- [GitLab](/en/docs/data-source-gitlab) · Sync Markdown from selected GitLab branches.
- [DingTalk Docs](/en/docs/data-source-dingtalk) · Import online documents from DingTalk knowledge bases as Markdown.
- [Tencent ima](/en/docs/data-source-ima) · Import notes, web articles, and files from Tencent ima knowledge bases.
- [RSS / Atom](/en/docs/data-source-rss) · Import articles from RSS or Atom feeds into your knowledge base.
- [Apify](/en/docs/data-source-apify) · Import website Markdown or structured results from an Actor.
- [API Request](/en/docs/data-source-api) · Fetch JSON from an API and import selected fields into daily Markdown files.

See [Scheduled sync](/en/docs/data-source-scheduled-sync) to set a schedule for connections that support it.

## Third-party apps

Under **Online sources**, use **Third-party apps** to import notes from [Evernote](/en/docs/import-evernote), [Google Keep](/en/docs/import-google-keep), or [Apple Notes](/en/docs/import-apple-notes).
