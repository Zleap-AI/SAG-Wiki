## 1. インストールして開く

[インストールガイド](/ja/docs/installation)で OS に合うインストーラーを選びます。初回起動時にはチュートリアルが表示されます。再表示するには、**設定 → 一般** からクイックスタートの項目を開きます。

初期化時には `Documents/sag-wiki/clippings` が作成され、`Documents/sag-wiki` がフォルダー管理に追加されます。既存のライブラリはそのまま使えます。

## 2. フォルダーを追加する

サイドバーのフォルダー管理の横にある **+** を押し、検索したい資料のフォルダーを選びます。インデックスはバックグラウンドで作成され、処理済みのファイルから検索できます。詳しくは[フォルダーとインデックス](/ja/docs/folders)を参照してください。

## 3. ファイルを検索する

**検索** で資料のファイル名や本文に含まれる語句を入力します。結果を選ぶと、該当箇所が強調された原文を確認できます。

## 4. 質問で探す

複数の資料から根拠を探したい場合は、モデル設定で Jev のエンドポイントとモデルを設定します。サービスで必要な場合は API キーを入力し、[詳細検索](/ja/docs/search#詳細検索)を試します。

回答も必要な場合は、回答モデルを設定して[質問応答](/ja/docs/chat)を開きます。回答に付いた引用を開いて原文を確認します。質問の対象を絞るには `@` でファイルを指定します。
