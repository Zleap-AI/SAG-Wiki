CLI 与网页共用当前飞牛用户的索引、Jev 配置和目录排除规则。关闭网页后仍可使用；SAG Wiki 应用需要保持运行。每次文件访问都检查飞牛授权，其他用户的索引和密钥不会共用。

## 电脑远程接入

电脑上的 Codex 可以通过远程 MCP 搜索、列出和读取 NAS 知识库，无需安装 NAS 版 CLI 或手动 SSH。远程接入沿用当前飞牛用户的索引、Jev 配置及文件权限，只提供读取工具。

1. 点击主界面右上角 **接入 Agent**，开启 **启用 CLI**，选择 **电脑远程接入**。
2. 在 **电脑远程接入** 中填写电脑可访问的地址，例如 `http://192.168.1.100:15679/mcp`。这里应填写 NAS 局域网或 VPN 地址；飞牛网页登录地址不能直接作为远程 MCP 地址。公网接入需配置 HTTPS 反向代理，将 `/mcp` 转发到 NAS 的 `15679` 端口。
3. 点击 **生成访问密钥**，再点击 **复制 Codex 配置**。
4. 将配置加入电脑上的 `~/.codex/config.toml`，保留已有内容。
5. 点击 **下载远程 Skill**，解压后将整个 `sag-fnos` 文件夹放到电脑的 `~/.agents/skills/`；然后新开 Codex 会话。页面同时列出 Claude Code 和 OpenCode 的 Skills 目录，这两个工具需在各自 MCP 设置中配置连接。

```toml
[mcp_servers.sag_fnos]
url = "http://192.168.1.100:15679/mcp"
http_headers = { Authorization = "Bearer <ACCESS_TOKEN>" }
startup_timeout_sec = 30
tool_timeout_sec = 600
```

配置含访问密钥，请勿分享。密钥只在生成时提供，服务器只保存摘要。重新生成密钥后，旧配置立即失效；**关闭远程接入** 可撤销密钥，关闭 **启用 CLI** 也会阻止远程调用。其他飞牛用户拥有独立的密钥和知识库。

在 Codex 中提问，例如：

> 使用 sag_fnos 搜索知识库，整理资料中的验收要求，并注明文件来源。

工具返回的是 NAS 文件路径，后续读取仍使用 `sag_fnos` 的 `read` 工具。不要尝试在电脑本地打开这些路径。SAG Wiki 应用需保持运行，网页可以关闭。

## NAS 本机 CLI 与 Skill

在 **接入 Agent → NAS 本机 CLI** 中，选择已授权的工作目录，点击 **安装 CLI**，再按使用的 Agent 点击 **安装**。Codex、Claude Code、OpenCode 各自提供安装、卸载和命令复制按钮；操作结果显示实际 CLI 输出和退出码。这些操作安装到当前 NAS 用户的主目录。

**下载 CLI Skill** 提供完整 `sag` 文件夹及参数、安装和忽略规则参考，可接入其他运行在 NAS 上的 Agent。页面的 **CLI 使用指南** 默认展开，说明目录添加、索引检查、语义搜索、移除恢复和配置命令。

![NAS 本机 Agent Skill 安装](/images/fnos-cli-skills.png)


管理员开启 SSH 并为登录账号启用 SSH 权限后，在 NAS 终端执行：

```sh
/var/apps/sag-desktop-fnos/target/bin/sag install cli
```

重新打开终端，执行 `sag --version`。命令安装在当前用户的 `~/.local/bin`，启动器使用应用包内的 CLI，随应用一起更新。`sag uninstall cli` 只移除本用户的命令入口，应用与索引保留。

也可以先在下方网页测试中执行 `sag install cli`。如果飞牛尚未创建当前账号的主目录，应用会在安装时创建该目录；已有主目录及其权限保持不变。之后新开 SSH 会话即可使用 `sag`。

## 网页测试

点击主界面右上角 **接入 Agent**，或打开 **设置 → 接入 Agent → NAS 本机 CLI**。选择已授权的工作目录，输入以 `sag` 开头的命令，点击 **执行命令**。页面显示实际 CLI 的标准输出、错误输出和退出码。参数支持引号，不执行 Shell 管道、重定向或其他程序。需要交互输入密钥的配置命令请在 SSH 终端执行。

## 命令

| 命令 | 用途 |
| --- | --- |
| `sag status` | 查看服务、CLI 开关与 Jev 配置状态 |
| `sag list --json` | 列出当前用户的索引目录 |
| `sag check [目录] --json` | 检查索引覆盖、就绪状态和文件数 |
| `sag add [目录] --types md,txt,html,py,ts,json,yaml` | 添加目录并指定原生文本格式 |
| `sag remove [目录] --json` | 移除索引范围，保留原文件 |
| `sag config --if-needed` | 复用现有 Jev 配置；缺少配置时引导填写 |
| `sag config --enable` | 开启当前用户的 CLI 接入 |
| `sag service status` | 查看本用户服务状态 |
| `sag service stop` | 停止本用户共享服务；其他用户不受影响 |
| `sag service restart` | 重启本用户共享服务 |
| `sag install codex` | 安装 Codex Skill |
| `sag install claude-code` | 安装 Claude Code Skill |
| `sag install opencode` | 安装 OpenCode Skill |

安装命令对应的 `sag uninstall` 可移除由 SAG 管理的入口或 Skill，用户修改过的文件不会被覆盖或删除。停止服务后，下一次搜索、目录管理或网页操作会重新启动本用户服务。内部诊断命令 `sag service serve` 在前台等待，按 Ctrl+C 停止。

添加目录前，先在飞牛中把该目录授权给 SAG Wiki。`--types` 只用于原生文本和代码；PDF/Office 自动转换沿用网页的文件夹配置。省略 `--types` 会保留已有设置。

## 搜索与匹配

```sh
sag "这些资料对验收时间有什么要求？" /vol1/1000/File -m 5 --json
sag -F "fnosnativeverification20261021" /vol1/1000/File --json
sag -E "fnosnativeverification[0-9]+" /vol1/1000/File -i
```

语义搜索使用已配置的 Jev，也能检索 PDF/Office 转换结果；`-E` 正则匹配和 `-F` 固定字符串匹配处理原始文本文件，遵循忽略规则，不调用模型。默认返回完整原文片段。`-m` 控制结果数，范围 1–100；`--timeout` 控制等待时间。

匹配支持 `-i` 忽略大小写、`-w` 完整单词、`-x` 完整行、`-v` 反向匹配、`-A/-B/-C` 上下文、`-l` 文件列表、`--count` 计数、`-o` 匹配部分、`-q` 静默判断、重复 `-e/-f` 模式和 `--include/--exclude` 文件过滤。使用 `sag --help` 查看完整参数。

`check` 就绪并有内容时退出码为 0，未就绪为 1，错误为 2。`-q` 匹配时为 0，无匹配为 1，错误为 2。Ctrl+C 返回 130。

密钥优先通过终端隐藏输入或 `sag config --key-stdin` 配置。配置与状态输出不包含密钥。
