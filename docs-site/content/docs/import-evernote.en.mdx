---

Evernote is a note-taking app that lets you organize notes in notebooks and export them as ENEX files. [Evernote website](https://evernote.com/)

1. In the Evernote desktop app, right-click the notebook you want to export, choose **Export notebook**, then select **ENEX (.enex)** and save the file.

   ![Select ENEX when exporting a notebook in the Evernote desktop app](/images/evernote-export-enex.jpg)

   Screenshot source · [OneNoteGem](https://en.onenotegem.com/a/documents/onenote-batch/2019/1122/829.html)

2. In SAG Wiki desktop, [open Data sources](/en/docs/data-sources#open-data-sources) and choose **Import notes** next to **Evernote**.
3. Click **Choose files** and select one or more ENEX files. Check the destination and click **Import**. SAG converts the notes to Markdown and adds them to your knowledge base.

![Select an Evernote ENEX export](/images/product-source-evernote-en.png)
