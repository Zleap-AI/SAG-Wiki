## Búsqueda rápida

Abre **Búsqueda** y escribe un término del nombre o del contenido de un archivo. La **Búsqueda rápida** usa el índice local y funciona sin una clave de API de un modelo. Selecciona un resultado para abrir el original y resaltar las coincidencias.

Mientras la aplicación de escritorio esté abierta, puedes abrir **Búsqueda rápida** con un atajo aunque estés trabajando en otra aplicación. El atajo predeterminado es **⌘⇧Espacio** en macOS y **Ctrl+Mayús+Espacio** en Windows. Consulta [Configuración](/es/docs/preferences) para cambiarlo.

## Búsqueda profunda

Configura Jev en **Configuración → Modelos** y selecciona **Búsqueda profunda**. Describe lo que buscas para encontrar, en varios archivos, fragmentos relacionados con el significado de tu consulta. Compara los fragmentos de los resultados con las fuentes originales.

Selecciona las carpetas si necesitas delimitar la búsqueda. Para obtener además una respuesta que reúna la evidencia, abre [Preguntas y respuestas](/es/docs/chat).
