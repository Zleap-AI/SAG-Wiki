## 빠른 검색

**검색**을 열고 파일 이름이나 본문에 들어 있는 단어를 입력합니다. 빠른 검색은 로컬 인덱스를 사용하므로 모델 API 키가 필요하지 않습니다. 결과를 선택하면 원문이 열리고 일치하는 부분이 강조됩니다.

데스크톱 앱이 실행 중이면 다른 앱을 사용하는 동안에도 **단축키 검색**을 열 수 있습니다. 기본 단축키는 macOS에서 **⌘⇧Space**, Windows에서 **Ctrl+Shift+Space**입니다. [설정 가이드](/ko/docs/preferences)에서 변경하는 방법을 확인하세요.

## 심층 검색

질문의 의미를 바탕으로 여러 자료에서 근거를 찾으려면 **모델 설정**에서 Jev를 설정하고 검색 화면에서 **심층 검색**을 선택합니다. 찾고 싶은 내용을 구체적으로 입력한 뒤 결과의 발췌문과 원문을 비교하세요.

검색할 폴더를 지정하면 범위를 줄일 수 있습니다. 근거를 종합한 답변도 필요하면 [질의응답](/ko/docs/chat)을 사용하세요.
