---

## 1. 설치하고 열기

[설치 가이드](/ko/docs/installation)에서 운영체제에 맞는 설치 프로그램을 선택합니다. 처음 시작할 때는 사용 안내가 열립니다. 다시 보려면 **설정 → 일반 → 빠른 시작**을 엽니다.

처음 설정할 때 `Documents/sag-wiki/clippings`가 생기고 `Documents/sag-wiki`가 관리 폴더에 추가됩니다. 기존 라이브러리는 계속 사용할 수 있습니다.

## 2. 폴더 추가하기

사이드바의 폴더 관리 옆에서 **+**를 누르고 검색할 자료가 있는 폴더를 선택합니다. 백그라운드에서 인덱싱이 진행되며 처리된 파일부터 검색할 수 있습니다. 자세한 내용은 [폴더와 인덱싱](/ko/docs/folders)을 참고하세요.

## 3. 파일 검색하기

**검색**에서 파일 이름이나 본문에 들어 있는 단어를 입력합니다. 결과를 선택하면 원문이 열리고 일치하는 부분이 강조됩니다.

## 4. 질문하기

여러 자료에서 근거를 찾으려면 **모델 설정**에서 Jev 엔드포인트와 모델 이름을 설정합니다. 서비스에서 요구하는 경우 API 키를 입력한 다음 [심층 검색](/ko/docs/search#심층-검색)을 해 보세요.

답변이 필요하면 답변 모델을 설정한 뒤 [질의응답](/ko/docs/chat)을 엽니다. 답변의 인용을 선택해 근거가 된 원문을 확인할 수 있습니다. 검색 범위를 좁히려면 질문에 `@`를 입력하고 파일을 지정하세요.
