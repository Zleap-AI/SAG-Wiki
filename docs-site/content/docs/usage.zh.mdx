## 授权与添加

在“添加文件夹”中点击“选择并授权文件夹”。飞牛桌面中调用原生选择器；独立浏览器中跳转到飞牛授权页面，完成后返回应用。授权后可以从列表添加目录，也可以点击“刷新授权状态”同步变化。飞牛目录授权每次只能选择一个目录。

“飞牛设置”中的授权目录按列表显示文件夹图标、名称和可读路径；长路径在列表内换行。目录名称通过 `trim.file.convertPath` 转换。在飞牛桌面内，“打开应用设置”调用原生设置页；独立网页显示“打开飞牛桌面”，并提示进入“应用中心 → 已安装 → SAG Wiki → 设置”，避免调用独立网页不支持的桌面接口。

展开“索引选项”可为本次添加设置文件类型和自动转换；内容较多时列表滚动，底部操作按钮保持可见。

## 搜索和问答

选择“搜索”，切换“快速”，输入关键词即可检索。深入检索与问答在“设置 → 模型设置”配置 Jev 和问答模型后使用。点击结果查看原文，点击“打开文档”进入编辑器。

启用内置 SAG 搜索工具后，知识性问题先检索本地资料，再根据原文回答，即使问题没有提到文件。已知路径可直接读取，精确文字可使用 grep。问候、翻译或改写已提供的完整文本，以及明确要求不检索的请求可以直接回答；计算和时间问题使用对应的已启用工具。工具在“设置 → 问答设置 → 工具绑定”中按模型配置。

![搜索与原文](/images/fnos-search.png)

## 编辑

Markdown 文档修改后点击“保存”。保存前会检查飞牛写入权限，并核对文件版本，避免覆盖外部修改。只读文件可以阅读，保存会返回明确的权限错误。

权限被撤销后，读取和查询会重新检查权限。可在飞牛重新授权，或从知识库移除该目录。移除只清理索引，不删除原文件。

## PDF 与 Office 自动转换

在“设置 → 文件设置 → 其他格式”点击“安装 Docling”，下载运行环境、格式组件和识别模型。可查看进度、取消、重试和卸载；组件可能占用数 GB，扫描件及音视频所需模型可能继续下载。

安装后选择格式和转换并行数，保存设置。新添加文件夹沿用默认选项；已有文件夹可通过自身的索引设置调整格式。转换结果位于原目录内的 `.sag-converted/`，原文件保留；未变化的结果会复用，手动编辑过的结果不会被自动覆盖。

![Docling 格式设置](/images/fnos-docling-formats.png)

扫描 PDF 沿用 PDF 转换选项，组件会先进行 OCR，再生成可索引的 Markdown。已在飞牛实机用无文字层的中文扫描样本验证：中文、日期、数字和表格字段能够检索，问答实际调用搜索并引用识别后的原文。本次样本为清晰的印刷扫描页，未覆盖手写或严重模糊的图像。

![扫描 PDF 的 OCR 问答验证](/images/fnos-ocr-qa.png)

只读目录可读取已有转换结果；新转换需要输出目录写入权限。读取转换文件时仍检查原文件权限；原文件权限撤销后，转换内容也无法读取。

## 本地 MCP

在“设置 → 问答设置 → 工具绑定”添加服务，选择“本地命令（stdio）”，或导入包含 `command` 和 `args` 的 MCP JSON。填写 NAS 上的命令、每行一个参数及所需环境变量，测试连接后为模型选择工具。HTTP 服务、逐次调用确认和工具选择继续可用。

![本地 MCP 设置](/images/fnos-mcp-stdio.png)

本地命令在 NAS 上以当前飞牛用户运行。请使用 NAS 上存在的可执行文件和路径；需要 Node.js 或 Python 的服务应先安装对应运行环境。每个用户的工作目录和配置独立，命令使用该用户的系统文件权限。关闭连接或停止应用会结束相应子进程。

## 数据隔离

不同用户的索引、密钥、会话、草稿和浏览器搜索记录分别保存。应用后端身份来自飞牛网关的 `X-Trim-Userid`，不会使用浏览器提交的用户 ID。
