## デスクトップアプリ

<ReleaseDownloads language="ja" />

macOS では「この Mac について」でチップまたはプロセッサを確認します。M シリーズは Apple Silicon（`arm64`）、Intel プロセッサは Intel（`x86_64`）を選びます。DMG を開き、SAG Wiki を「アプリケーション」フォルダーへドラッグします。

Windows では x64 インストーラーを実行し、画面の案内に従います。インストーラーの表示言語は簡体字中国語、繁体字中国語、英語から選べます。

[最新の安定版とリリースノートを開く](https://github.com/Zleap-AI/SAG-Wiki/releases/latest)

## アプリの表示言語

日本語の表示言語は 0.3.13 以降で使えます。

アプリを起動し、**設定 → 一般** で **表示言語** を **日本語** に変更し、**設定を保存** を選びます。アプリ本体では日本語、簡体字中国語、繁体字中国語、英語、韓国語、スペイン語から選べます。[設定ガイド](/ja/docs/preferences)も参照してください。

インストール後は[クイックスタート](/ja/docs/quick-start)へ進み、最初のフォルダーを追加します。

## CLI のみを使う

Node.js 18 以降が必要です。CLI は Apple Silicon Mac、Intel Mac（`0.3.11` 以降）、Windows x64、および Linux の ARM64／x86_64（Ubuntu 24.04 と Debian 12）に対応します。

```sh
npm install -g @zleap-ai/sag
sag --version
```

CLI はデスクトップアプリとは別に利用できます。[Agent 連携（英語）](/en/docs/agents)や [CLI リファレンス（英語）](/en/docs/cli)を参照してください。

## アプリの更新

**設定 → アプリ情報** から更新を確認できます。新しいバージョンがある場合はダウンロードを開始し、検証が完了してからアプリを再起動して更新します。未保存のドキュメントがある場合は、表示される案内に従って保存してください。

0.3.13 以降、デスクトップアプリは保存済みの表示言語に応じて公式の更新元を選びます。簡体字中国語は Zleap 公式サイトを、それ以外の表示言語は GitHub を利用します。カスタムの更新元は維持されます。

更新に失敗した場合は再確認するか、GitHub から最新の安定版のインストーラーを取得してください。npm でインストールした CLI は `npm install -g @zleap-ai/sag` で更新します。
