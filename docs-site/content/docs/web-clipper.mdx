网页剪藏扩展将当前网页正文保存为本地 Markdown。无需连接码，无需运行 SAG Wiki，也无需安装 Obsidian 或配置模型。

![网页剪藏设置](/images/product-web-clipper-zh.jpg)

## 安装

1. 点击 SAG Wiki 右上角的地球图标 **网页剪藏**，下载对应浏览器的扩展安装包；也可以从 **设置 → 网页剪藏** 打开。悬停在图标上可查看名称。
2. 安装并启用扩展。
3. 在网页上右键选择 **保存为 Markdown**，打开剪藏预览。
4. 核对标题、正文和保存位置，点击 **保存** 后才生成文件。点击 **取消** 或关闭窗口不会保存。

![右上角的网页剪藏与接入 Agent 图标](/images/web-clipper-entry-zh.png)

当前功能尚未正式发布，扩展未上架浏览器商店。源码构建可生成 Chrome / Edge 安装包及 Safari 开发测试包。Safari 正式安装包需要签名和公证；只有构建时附带该安装包，桌面端才显示可用的 Safari 下载按钮。

- **Chrome / Edge（Windows / macOS）**：解压安装包，在浏览器扩展管理页启用 **开发者模式**，点击 **加载已解压的扩展程序**，选择解压后的目录。
- **Safari（macOS）**：打开已公证的 DMG 安装包，将窗口中的 `SAG Web Clipper.app` 拖到旁边的 **Applications（应用程序）** 文件夹，完成复制后从“应用程序”打开，再到 **Safari 设置 → 扩展** 中启用。DMG 提供拖拽安装窗口，仍需由你完成复制和启用。已公证版本无需开启“允许未签名的扩展”。自行构建的未签名测试包仍需要该开发者设置。

打开 Safari 应用后，会显示语言选项及 **已安装 · 已启用** 或 **已安装 · 待启用** 状态。已启用时点击 **完成** 关闭窗口，再回到网页剪藏；待启用时点击 **退出并打开 Safari 设置**。检查期间仍可打开 Safari 设置；超过 8 秒未得到结果时会提示并提供 **重新检查**，不会一直锁定按钮。回到应用会刷新状态。若 Safari 尚未检测到扩展，会明确提示，不会显示“完成”。

![Safari DMG 安装窗口：将应用拖入 Applications](/images/extension-web-clipper-safari-dmg.png)

![Safari 应用启动页](/images/extension-web-clipper-safari-setup-zh.png)

![Safari 未返回状态时仍可打开设置或重新检查](/images/extension-web-clipper-safari-status-zh.png)

桌面端的下载按钮只导出当前构建中已包含的安装包；未包含的浏览器对应按钮不可用。

## 预览并保存

Safari 的“保存为 Markdown”菜单项前显示透明背景的 SAG 小图标。右键菜单打开独立的剪藏窗口，先显示网页标题、来源网址、Markdown 正文预览和保存位置，点击 **保存** 后写入文件。窗口初始尺寸为 520 × 660，默认在当前网页所在的浏览器窗口中央打开；正文较长时在预览区域滚动。保存内容以打开预览时提取的正文为准；之后切换或关闭原网页不会改变这次预览。

工具栏剪藏功能和对应的设置开关已移除，请通过网页右键菜单使用。安装和更新不会调整 Safari 的地址栏或工具栏布局，也不需要将扩展固定在工具栏中。浏览器仍可能保留用于管理扩展的默认图标：Safari 可右键图标选择 **从工具栏移除**；Chrome / Edge 可在扩展菜单中取消固定。

![剪藏预览：确认正文和目录后点击保存](/images/extension-web-clipper-preview-zh.jpg)

## 保存目录

SAG Wiki 在首次创建知识库时，会创建 `Documents/sag-wiki/clippings`，并将 `Documents/sag-wiki` 加入文件夹管理。已有知识库不会自动追加该目录；需要时可点击 **添加剪藏文件夹** 手动选择。

扩展的 **保存到** 默认选择 **默认文件夹（Documents/sag-wiki/clippings）**。Safari 安装并启用后即可保存到该目录，无需先选择文件夹或保存设置；目录不存在时自动创建。macOS 如要求访问“文档”目录，会显示系统提示。预览显示实际完整路径。

Chrome / Edge 使用浏览器的文件夹选择机制：首次点击 **保存** 时选择系统“文档”目录，之后直接使用其中的 `sag-wiki/clippings`。取消选择会保留预览，不生成文件。

需要更换目录时，选择 **选择其他文件夹**，点击 **选择文件夹**。下拉框直接显示 **自定义文件夹（位置）**，点击 **保存设置** 后生效。默认目录与自定义目录分别保存，未保存的修改不会影响实际保存位置。只有更换目录并保存设置后，才显示“选择其他文件夹后，请在 SAG Wiki 的文件夹管理中添加，否则无法检索其中的内容。”；重新打开设置或再次选择同一目录时不重复显示。

Safari 在下拉框中显示完整路径，Chrome / Edge 显示浏览器提供的目录名称；默认目录显示已知的相对位置。若需要重新选择目录，点击 **选择文件夹** 或 **更换文件夹**，再点击 **保存设置**。Safari 使用扩展自带的本地组件记住所选目录，不连接 SAG Wiki。

Windows 使用系统的“文档”目录创建 `sag-wiki\clippings`，无需填写 macOS 路径。保存到其他盘符或含中文、空格的目录时，请用扩展的文件夹选择器选择目录。Windows 安装包附带 Chrome / Edge 扩展；目前已检查打包配置与文件名规则，尚未完成 Windows 实机保存验证。

扩展还保留可选的 **下载目录** 模式：Chrome / Edge 使用浏览器下载目录，并可勾选 **每次选择保存位置**；Safari 使用系统下载目录。此模式默认子文件夹为 `clippings`，可填写其他相对路径或留空。

剪藏窗口会显示保存状态和实际路径。Chrome / Edge 的下载尚未完成时显示保存中，中断时显示错误。

每次保存生成独立的 `.md` 文件，保留标题、来源网址、保存时间和正文，原文件不会被覆盖。图片保留原网址，离线时未必可用。浏览器内部页面和 PDF 不属于当前正文提取范围。

## 加入知识库（可选）

在 SAG Wiki 的网页剪藏设置页点击 **添加剪藏文件夹**，选择实际保存目录，或者从已有的文件夹管理入口添加。默认的 `Documents/sag-wiki` 在新知识库首次启动时已加入。

加入后，SAG Wiki 根据已有的文件类型、排除规则和 **监听文件变化** 设置更新索引。修改扩展保存目录后，需将新目录另外加入；以前的文件不会移动。SAG Wiki 未运行时，扩展仍然可以保存，索引在后台服务运行并检查目录时更新。

## 语言与数据

扩展界面、右键菜单和常见保存错误提示支持简体中文和英语，默认跟随浏览器，也可在扩展设置中切换。Safari 安装后的引导页也提供中英文切换。系统文件选择窗口使用系统语言。

界面采用黑白灰配色，随系统切换浅色和深色显示。设置页正文和按钮为 18px，标题为 26px。右键菜单、预览、设置、安装包及 Safari 应用图标均使用透明背景。图标提供小尺寸专用图片，Safari 应用图标同步放大；按钮、输入框、选中控件和错误提示保持统一配色。

![中文扩展设置：黑白浅色界面](/images/extension-web-clipper-zh.jpg)

![中文扩展设置：黑白深色界面](/images/extension-web-clipper-zh-dark.jpg)

![自选目录直接显示在下拉框中，修改后才出现检索提醒](/images/extension-web-clipper-custom-zh.jpg)

正文提取在浏览器本地完成。扩展不使用本地 HTTP 端口、连接码或模型服务。Safari 的本地保存组件只接收所属扩展的请求，保存范围为默认的 `Documents/sag-wiki`、用户所选目录或系统下载目录。之后在 SAG Wiki 中搜索或问答的模型使用方式遵循现有设置。
