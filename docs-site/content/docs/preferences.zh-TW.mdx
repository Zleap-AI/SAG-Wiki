## 變更介面語言

開啟 **設定 → 一般 → 介面語言**，選擇 **繁體中文** 或其他可用語言。選擇後可以立即預覽，選擇 **儲存設定** 後，重新開啟應用程式仍會使用你的選擇。如果取消設定，會恢復原本的介面語言。

儲存的語言也會套用到 Web 工作區、桌面的快捷搜尋和系統匣選單。Windows 安裝程式的語言在安裝時另外選擇。

![設定中的繁體中文介面語言](/images/product-preferences-zh-TW.png)

## 調整外觀

到 **外觀** 選擇淺色、深色或跟隨系統，也可以調整文件字級。這些選項不會改寫文件內容。

## 設定快捷搜尋

在 **快速鍵** 設定中，可以開啟或修改呼叫快捷搜尋的按鍵組合。macOS 預設為 **⌘⇧Space**，Windows 預設為 **Ctrl+Shift+Space**。點選 **套用快速鍵** 後會立即生效。可試按一次，確認快捷搜尋視窗正常開啟。
