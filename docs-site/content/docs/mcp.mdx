## 入口与生效范围

入口：**设置 → 问答设置 → 工具绑定**。先选择要配置的问答模型。工具绑定和单个工具开关按模型保存；切换模型后应检查它自己的配置。

外部 MCP 服务的连接信息可被多个模型复用。是否启用某个服务、启用哪些工具，由各模型单独决定。

## SAG 内置工具

打开 **SAG（内置 MCP）** 即可使用，无需额外配置连接。可展开工具列表，按需单独开启或关闭。

| 工具 | 作用 |
| --- | --- |
| `search` | 用 SAG2 按自然语言问题查找相关原文，需要 Jev |
| `list` | 查找已接入范围内的文件与目录 |
| `read` | 按已知文件路径和位置读取原文 |
| `grep` | 按关键词或匹配条件查找文件内容 |
| `getTime` | 获取当前时间 |
| `calculate` | 执行计算 |

文件工具受到当前查询范围限制。关闭整个内置工具组后，该模型无法再通过它检索本地知识库。工具可用不代表每次都必须调用。调用次数默认不限制；在问答设置中填写大于 0 的总上限后，所有工具共用该上限。

## 添加外部服务

点击 **添加服务**，或 **添加 DeepWiki 示例** 查看一个预设连接。示例仍需测试连接；使用前检查“调用前确认”开关。

| 字段 | 填写内容 |
| --- | --- |
| 服务名称 | 用于列表显示和区分服务 |
| 连接方式 | 远程 HTTP 或本地命令（stdio） |
| 服务地址 | HTTP 服务实际的 MCP 地址 |
| 启动命令 | stdio 服务的可执行文件或命令，必要时使用完整路径 |
| 启动参数 | 每行一个参数，不把所有参数合并为一行 |
| 请求头 | HTTP 的 JSON 对象，例如认证请求头 |
| 环境变量 | stdio 的 JSON 对象，值为字符串 |
| 调用前确认 | 调用时展示工具名称与参数，由用户决定是否执行 |

请求头或环境变量留空保留已保存值；输入 `{}` 清除已保存的凭据。修改连接信息后需要重新测试并获取工具列表。

## 测试、绑定和选择工具

1. 填写连接后点击 **测试连接**，确认可以取得工具列表。
2. 为当前模型开启该服务的绑定开关。
3. 展开工具列表，只启用需要的工具。
4. 点击底部 **保存设置**。
5. 服务更新工具后，点击 **刷新工具列表**，重新检查启用项。

测试连接成功只说明服务可连接，不保证模型会正确使用每个工具。外部工具可能访问网络或修改外部资源，按实际服务能力配置“调用前确认”。

## 导入 JSON

支持 `mcpServers`、`servers` 或单个服务对象。下面是应用提供的公开示例：

```json
{
  "mcpServers": {
    "DeepWiki": {
      "url": "https://mcp.deepwiki.com/mcp"
    }
  }
}
```

导入不会自动连接。同名服务需要先改名；当前支持 Streamable HTTP 和 stdio，不支持 SSE、`inputs` 或未展开的变量占位符。带密钥的真实 JSON 不应放进公开文档。

## 移除服务

“移除服务”会在保存设置后移除该连接及各模型的绑定。它不会卸载外部 MCP 程序，也不会删除外部系统里的数据。
