## 两类模型的分工

入口：**设置 → 模型设置**。

| 配置 | 用途 | 什么时候需要 |
| --- | --- | --- |
| 问答模型（LLM） | 组织回答、调用工具、生成搜索总结 | 问答、启用自动总结的搜索 |
| Jev 模型 | 判断候选原文是否提供问题所需的证据 | SAG2 深入检索、CLI 语义搜索 |

本地索引与快速搜索不需要这两类模型。只有 Jev 配置也可以进行语义检索；只有问答模型无法完成依赖 Jev 的 SAG2 检索。

## 逐项填写

### 供应商

选择供应商后会填入对应接口地址。问答模型提供 OpenAI、DeepSeek、GLM、OpenRouter、302.AI 和自定义；Jev 提供 302.AI、OpenRouter、Typesafe 和自定义。

问答接口和 Jev 判断接口是两类接口，不能只因供应商相同就互换地址。自定义服务必须兼容对应接口。

### 接口地址

填写供应商提供的 API 基础地址，而非网页聊天地址。预设地址会随供应商选项填写；使用代理或自建服务时，确认路径与服务协议一致。

切换到不同服务来源后，需要填写新供应商的 API Key。应用不会把原供应商密钥直接用于新的来源。

Jev 可填写基础地址（如 `http://127.0.0.1:8000/v1`），也可填写完整的 `/systemone` 或 `/decisions` 接口地址，程序不会重复追加接口路径。

### Jev 鉴权方式

- **API Key**：用于需要密钥的服务，保留已有配置的默认方式。
- **无需鉴权**：用于不要求密钥的本地 Jev 服务。此模式不发送鉴权头，保存后移除已存储的 Jev 密钥。

服务需兼容 Jev 判断接口。CLI 对应命令为 `sag config --url http://127.0.0.1:8000/v1 --model YOUR_MODEL --auth none`；切回密钥服务使用 `--auth bearer --key-stdin`。

### 可选模型与模型名称

问答模型的 **可选模型 · 每行一个** 决定界面里可以切换哪些模型。每行填写一个服务支持的准确模型 ID，不加逗号；去重后保存。连接测试使用列表第一项。

Jev 的 **模型名称** 填写一个 Jev 模型 ID。当前默认配置为 `jev-latest`；服务是否支持该名称，以供应商实际提供的模型为准。

### API 密钥

粘贴对应服务的密钥。输入框默认隐藏，可点击显示或隐藏；已保存时留空会保留原密钥。“移除保存的密钥”会立即删除对应密钥。

两类服务都选择 302.AI 时，填写一个密钥可以自动填入尚未配置的另一项。保存前仍需确认两项服务与密钥都正确。

### 测试连接

分别点击两张配置卡片里的 **测试连接**，检查接口、模型和密钥是否可用。测试成功后点击底部 **保存设置**。测试可能发送验证请求，按供应商规则计费。

![Jev 的独立配置与连接测试入口](/images/product-jev-cn.png)

## 推荐配置顺序

1. 先配置 Jev 并测试，保存后运行一次深入搜索。
2. 再配置支持工具调用的问答模型并测试。
3. 保存后在问答页选择模型，提问并检查引用来源。
4. 需要调整提示词、思考强度或工具权限时，进入[问答设置](/zh/docs/chat#问答设置详解)。

## 连接失败时

- 认证失败：确认密钥对应当前供应商，且尚未过期。
- 模型不存在：核对准确模型 ID 与账号的可用模型。
- 地址错误：确认填写 API 地址及必要路径。
- 超时：核对网络和服务状态；问答请求超时在问答设置中调整。
- 模型不会调用工具：确认模型和所用接口支持工具调用，并检查当前模型的工具绑定。

密钥保存在当前用户的应用数据目录。macOS 使用仅当前用户读写的文件权限；同一账户下的其他程序仍可能读取，因此不要把应用数据目录公开分享。详见[数据与隐私](/zh/docs/privacy)。


## MinerU 文档解析

入口：**设置 → 模型设置 → 文档解析 · MinerU**。默认关闭；服务商默认302.AI，也可选择MinerU官方。只需填写所选服务商的API Key（官方为Token），服务地址自动选择。

启用后，支持的PDF、图片和Office文件优先发送到MinerU；失败后依次尝试适用的内置anydoc与已安装的本地Docling。Markdown、文本和代码继续直接索引，不会自动切换另一家云端服务或安装组件。

![MinerU服务商、密钥与连接测试](/images/product-mineru-cn.png)

点击**测试连接**可使用尚未保存的配置；测试不上传文件、不创建解析任务。服务可达不等于密钥已验证，界面会区分这两种结果。两家服务商分别保存密钥，切换时不会复用另一家的密钥。保存设置后可重新索引失败文件。

高级参数可调整请求超时、任务总时限、轮询间隔、并发、解析模型、OCR、表格及公式识别。PDF按供应商页数和上传大小限制拆分，完整成功后才合并发布，并保留原页号。任务记录支持超时续查；未收到任务编号时保留不确定记录并降级本地，避免盲目重复提交。

启用远程解析会上传原文档，详见[数据与隐私](/zh/docs/privacy)。索引历史提供各引擎、阶段、耗时和失败原因。

## 高级运行参数

模型设置底部可调整失败重试次数、退避间隔和总时限。HTTP499也计入重试，总时限覆盖请求、等待和响应读取。其他分组见[运行参数](/zh/docs/preferences#运行参数)。
