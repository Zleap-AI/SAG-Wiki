## Abrir un archivo

Selecciona una carpeta en la barra lateral y abre un archivo de la lista. También puedes abrir el original desde un resultado de búsqueda o una cita de una respuesta.

La lista se puede filtrar por estado de procesamiento. El contenido disponible para ver o buscar depende del estado de la conversión o del OCR.

## Crear o editar un documento Markdown

Si el documento nuevo conserva el nombre predeterminado `Sin título.md`, el primer clic en **Guardar** abre un campo para cambiarlo. El nombre se solicita aunque hayas cambiado el idioma de la interfaz desde que creaste el documento. Si lo creaste desde la vista general de archivos, también puedes elegir la carpeta de destino.

Los archivos Markdown existentes se abren en modo de edición de forma predeterminada. En **Configuración → General**, cambia **Modo predeterminado del documento** a **Ver** para abrirlos en el lector. Para hacer cambios, selecciona **Editar** en la esquina superior derecha.

Usa **⌘ S** en macOS o **Ctrl S** en Windows para guardar. Al cambiar el idioma de la interfaz, el código y las fórmulas del documento conservan su contenido original.
