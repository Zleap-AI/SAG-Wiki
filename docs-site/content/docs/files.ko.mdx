## 파일 열기

사이드바에서 폴더를 선택한 다음 목록에서 파일을 엽니다. 검색 결과나 질의응답의 인용에서 원문으로 이동할 수도 있습니다.

목록에서는 인덱싱 상태별로 파일을 볼 수 있습니다. 변환이나 OCR이 필요한 파일은 처리 단계에 따라 열거나 검색할 수 있는 범위가 달라집니다.

## Markdown 만들고 편집하기

새 문서의 이름이 기본값인 `제목 없음.md`인 경우, 처음 **저장**을 누르면 파일 이름을 입력할 수 있습니다. 문서를 만든 뒤 표시 언어를 바꿔도 똑같이 이름을 입력합니다. 전체 파일 화면에서 새 문서를 만들었다면 저장할 폴더도 선택합니다.

기존 Markdown 파일은 읽거나 편집할 수 있습니다. 큰 Markdown 파일은 먼저 읽기 모드에서 열립니다. 목차나 문서 내 검색으로 원하는 부분을 찾고, 내용을 바꾸려면 편집 모드를 연 다음 저장합니다.

저장 단축키는 macOS에서 **⌘ S**, Windows에서 **Ctrl S**입니다. 표시 언어를 바꿔도 파일 안의 코드와 수식은 그대로 유지됩니다.
