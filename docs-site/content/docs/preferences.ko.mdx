## 표시 언어 바꾸기

사이드바에서 **설정 → 일반**을 열고 **표시 언어**에서 **한국어**를 선택합니다. 선택하는 즉시 미리 볼 수 있으며 **설정 저장**을 누르면 앱을 다시 열 때도 같은 언어가 적용됩니다. 취소하면 저장하기 전의 언어로 돌아갑니다.

저장한 언어는 데스크톱 앱과 웹 작업 공간, 데스크톱의 단축키 검색과 트레이 메뉴에도 적용됩니다. Windows 설치 프로그램의 언어는 설치할 때 별도로 선택합니다.

![설정의 한국어 표시 언어](/images/product-preferences-ko.png)

## 화면 모양 바꾸기

**화면 모양** 설정에서 밝은 테마, 어두운 테마, 시스템 테마를 선택할 수 있습니다. 읽을 때 편하도록 문서의 글자 크기도 바꿀 수 있습니다. 화면에 표시되는 크기를 바꿔도 원본 문서의 서식은 그대로 유지됩니다.

## 단축키 검색 설정하기

**단축키** 설정에서 **단축키 검색**을 켜거나 키 조합을 변경합니다. 기본 조합은 macOS에서 **⌘⇧Space**, Windows에서 **Ctrl+Shift+Space**입니다. **단축키 적용**을 누르면 변경 사항이 즉시 반영됩니다. 단축키를 눌러 검색 창이 열리는지 확인하세요.
