## 快速搜尋

開啟 **搜尋** 並輸入檔案名稱或內文中的字詞。快速搜尋會使用本機索引，不需要模型 API 金鑰。選取結果即可開啟原文，相符的內容會以醒目標記顯示。

SAG Wiki 桌面應用程式執行時，即使目前正在使用其他應用程式，也可以叫出 **快捷搜尋**。macOS 預設按 **⌘⇧Space**，Windows 預設按 **Ctrl+Shift+Space**。可在[設定](/zh-TW/docs/preferences)中修改。

## 深入搜尋

如果要根據問題的語意從多份資料尋找依據，請先在 **模型設定** 中設定 Jev，再到搜尋畫面選擇 **深入搜尋**。盡量描述清楚想知道的事情，接著比對結果片段與原文。

可以選擇資料夾限定搜尋範圍。若還需要整合資料產生回答，請使用[問答](/zh-TW/docs/chat)。
