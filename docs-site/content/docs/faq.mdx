## 没有 API Key 可以使用吗？

可以建立索引、浏览文件并使用本地快速搜索。深入语义检索需要 Jev；生成回答需要回答模型配置。

## 原文件会被复制或上传吗？

添加目录不会移动原文件。索引和元数据保存在本机；深入检索与问答会将所需问题和片段发送给你配置的服务。文档转换组件的行为以对应组件说明为准。

## 为什么搜不到文件？

先确认文件夹已添加且索引就绪，再检查文件类型开关、忽略规则和已移除的子目录。CLI 可运行：

```sh
sag list
sag check
```

目录存在但已索引文件数为零时，没有可搜索内容。

## 为什么 CLI 提示找不到 sag？

先确认 Node.js 和 npm 已安装，再运行 `npm install -g @zleap-ai/sag`。重新打开终端后检查 `sag --version`。当前 npm 包支持 macOS Apple Silicon 和 Windows x64。

## 桌面关闭后 CLI 还能使用吗？

可以。两者共用独立后台服务，普通操作会按需启动或连接服务。`sag service status` 只查看状态，不会启动服务。

## 如何反馈问题？

在 [GitHub Issues](https://github.com/Zleap-AI/SAG-Wiki/issues) 中提供系统、应用或 CLI 版本、复现步骤、预期行为和实际结果。截图中请隐藏密钥及敏感文件内容。
