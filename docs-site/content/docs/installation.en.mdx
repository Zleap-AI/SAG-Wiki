## Desktop app

<ReleaseDownloads language="en" />

On macOS, open the DMG and drag SAG Wiki into Applications. On Windows, run the installer and follow its steps. The installer offers Simplified Chinese, Traditional Chinese and English.

[Open the latest stable release for installers and release notes](https://github.com/Zleap-AI/SAG-Wiki/releases/latest)

## CLI only

Node.js 18 or later is required. The standalone CLI supports macOS Apple Silicon, Windows x64, and Linux ARM64/x86_64 (Ubuntu 24.04 and Debian 12). No Rust toolchain or source build is needed.

```sh
npm install -g @zleap-ai/sag
sag --version
```

Installing the CLI does not install the desktop app. Continue with [Agent integration](/en/docs/agents) or the [CLI reference](/en/docs/cli).

## Updates

Use in-app updates or download a newer desktop installer. Launch the updated app to update its managed `sag` command, then run `sag --version` to check it. Update an npm-managed CLI with `npm install -g @zleap-ai/sag`.

<Callout title="Files and settings">Upgrades normally preserve original files, knowledge base settings and conversations. Before removing data, distinguish the index from your original documents.</Callout>

## About and software updates

![Installed version and software updates](/images/product-about-en.png)

Location: **Settings → About**. This page shows the installed version and links to the open-source project and developer.

The app checks for updates at startup and every 8 hours while it stays running. Select **Check updates** to check manually. When notified of a new version, select **Download update** and wait for verification. The action then becomes **Restart and update**.

- Expand **Release notes** to read version changes with headings, lists, bold text and links.
- Continue using the app during download; closing Settings does not interrupt it.
- Handle unsaved documents before installation, following the save or cancel prompt.
- Exiting the whole app requires an unfinished download to start again.
- Failures display an error. Recheck or download the full installer from GitHub.
- Updates replace application files while preserving the knowledge base, conversations and originals.

![Formatted headings, lists and bold text in release notes](/images/product-release-notes-en.png)

About shows the installed program version. This page reads the latest stable version, installer URLs and actual sizes from GitHub when opened.

## Windows local service startup failure

If the app cannot connect to its local SAG service and the log reports access denied while saving the connection record, keep the full error and application version. Builds containing the account-permission fix protect the record using the process user's SID, independent of computer and account names. Update, restart and check again. Do not grant everyone access to the entire data directory. This fix is not included in the official 0.2.7 package.
