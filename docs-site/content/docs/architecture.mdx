SAG Wiki 是本地文件知识库。桌面界面与 CLI 连接同一个独立后台服务，原始文件保留在用户目录中。索引、文件浏览和本地匹配可离线运行；语义检索与问答调用用户配置的模型服务。

## 模块结构

| 路径 | 职责 |
| --- | --- |
| `src/` | Svelte 界面、状态、编辑器和文档渲染 |
| `src/components/ui/` | 本地界面组件，结合 Bits UI 使用 |
| `src-tauri/src/lib.rs` | Tauri 命令适配、事件转发与窗口生命周期 |
| `core/src/explore.rs` | 文档关联、图谱数据与关联证据 |
| `core/src/store.rs` | SQLite、文件元数据、索引读写与缓存 |
| `core/src/text.rs`、`document_text.rs` | 文本解码、切片、分词与原文位置 |
| `core/src/indexer.rs`、`ignore_rules.rs` | 索引队列、文件变更与忽略规则 |
| `core/src/retrieval.rs`、`sag2_v10.rs` | SAG2 召回、扩展与最终排序 |
| `core/src/models.rs`、`agent.rs` | 模型连接、问答与工具调用循环 |
| `core/src/sag_mcp.rs`、`mcp.rs` | 内置工具和外部 MCP 接入 |
| `core/src/service.rs`、`server.rs` | 共享业务、索引监听与本机服务 |
| `protocol/` | 独立请求、响应、事件与构建身份 |
| `client/` | 服务发现、认证、长连接、分块传输与取消 |
| `core/src/cli_service.rs` | CLI 业务操作，共享服务内核 |
| `cli/src/` | 命令参数、独立运行、终端输出、安装与 Skill |
| `scripts/` | 构建、安装和发布脚本 |

桌面使用 Tauri 2，前端使用 Svelte。SQLite FTS5 承担本地全文检索。运行发布产物不要求安装 Node.js、Python 或 Rust。

## 进程关系

```text
桌面界面 → Tauri → sag-client ─┐
                               ├→ sag service serve → sag-core
sag 命令 → sag-client ─────────┘      └→ SQLite / 文件监听 / 模型
```

每个数据目录只有一个服务持有数据库、索引监听、检索缓存和模型客户端。桌面和 CLI 需要时自动启动服务；关闭或退出桌面后，服务继续运行。普通 CLI 命令只连接服务，不在自身进程重新初始化内核。

本机服务仅监听 `127.0.0.1`，使用随机端口与令牌，连接记录为用户数据目录下的 `sag-service.json`。单帧上限 128 KiB，完整消息上限 64 MiB，大文档分块传输。令牌不显示在诊断信息中。

协议版本、构建身份、开发或正式渠道、服务 PID 和执行文件位置可通过 `sag service status` 查看。不同构建不会静默混用；同渠道升级先停止旧服务，开发与正式渠道使用独立数据目录。实现进度与验收见[迁移计划](https://github.com/Zleap-AI/SAG-Wiki/blob/main/docs/zh-CN/SAG独立后台服务与桌面统一内核实施计划.md)。

## 数据存储

默认数据目录由操作系统的用户数据目录和应用标识 `com.sag.desktop` 确定。`SAG_DATA_DIR` 可以指定独立的数据目录。

| 数据 | 保存方式 |
| --- | --- |
| 原始文档 | 保留在用户添加的本地目录 |
| 目录与文件信息 | SQLite 保存路径、文件名、修改时间、大小与哈希 |
| 切片位置 | SQLite 保存标题、字节范围和行列位置 |
| 全文检索 | FTS5 使用 `content=''`，保存检索词项和索引，不保存原文正文副本 |
| 检索准备数据 | 保存词表等派生信息，复用统计与查询缓存 |
| 文档关联 | 保存派生词项摘要，用于本地相似度计算 |
| 用户设置 | 保存在应用数据目录 |
| 模型与 MCP 凭据 | 使用当前用户私有文件；Unix 文件权限为 0600 |
| 问答记录、引用和草稿 | 保存应用会话内容，与文件索引分开管理 |

读取检索结果时，根据保存的位置访问原文件，并核对文件哈希。原文件已变化时提示重新索引，避免将旧位置对应到新正文。会话中的引用保留生成时使用的内容。

## 文件接入与索引

1. 添加目录，规范化路径并处理父子目录的重复覆盖。
2. 注册目录并提交后台索引任务。桌面界面接收真实进度与错误事件。
3. 按文件类型、目录排除设置、`.gitignore` 和 `.sagignore` 筛选文件。
4. 对未变化的文件跳过处理；需要时读取原文并校验哈希。
5. 解码、切片、分词并生成派生信息，批量写入 SQLite。
6. 文件监听将后续变更合并为增量任务，索引版本变化时使相关缓存失效。

Markdown、普通文本、RTF、Office、表格、EPUB 与文本型 PDF 默认可纳入索引；代码与配置文件按类型开关启用。内置 anydoc 优先解析文档，结果保存在 `.sag-converted`。需要 OCR 或内置解析器不支持时，可使用另行安装的 Docling；不会自动安装。符号链接不允许扩大访问范围。

正文切片以约 512 字符为默认目标，保留完整句子；代码保留完整行。超长句子或行允许超过目标。片段保存标题路径，相邻片段保留约 80 字符的句子或行重叠。用户自定义长度保存在检索设置中。HTML 中的 Base64 图片数据排除在索引和词表之外。

从知识库移除目录只清理索引和接入关系。移除子目录会保存排除状态；再次添加可恢复。原文件始终保留。

## 检索与问答

### 快速搜索

使用本地 FTS5 BM25，按文件合并命中并分页。每页显示 20 个文件，不调用模型。数据库查询与原文件校验分开处理；仅还原需要返回的候选内容。

### SAG2 语义检索

通过 BM25 召回候选，由 Jev 判断证据相关性，按配置扩展词项并进行后续检索，最后进行本地多样性排序。复用统计、查询和词频缓存；缓存按索引版本失效。候选超出单次模型请求预算时分批处理，保持片段完整。

问答使用配置中的候选与返回数量；桌面深入搜索使用独立的文件展示上限。CLI 的 `-m` 控制最终输出数量。它们共享底层检索实现。

### 问答与工具

回答模型按需调用内置 `search`、`list`、`read`、`grep` 或配置的外部 MCP 工具。每轮共用上下文预算；工具调用次数默认不限制，也可设置共用上限。工具结果携带稳定来源编号，答案引用对应原文来源。

请求失败、上下文超限、文件变化和索引未就绪均返回明确状态，不静默切换算法。更多协议见[SAG 内置 MCP 工具](https://github.com/Zleap-AI/SAG-Wiki/blob/main/docs/zh-CN/SAG内置MCP工具.md)。

## 界面与文档显示

- 文件浏览与查询范围分别管理；浏览目录不会隐式改变问答范围。
- Markdown 使用按需加载的编辑器，保存前检查外部修改冲突。
- 搜索结果列表显示命中附近的短片段；选中文档后，右侧渲染 Markdown 或 HTML，并高亮命中。打开全文后保留定位，返回时回到搜索。
- HTML 使用隔离视图渲染，避免将大段图片编码作为正文排版。
- 关联图在前端绘制，数据与证据由本地后端提供，详见[文件管理视图设计](https://github.com/Zleap-AI/SAG-Wiki/blob/main/docs/zh-CN/文件管理视图设计.md)。

## 并发与生命周期

索引准备可并行执行，SQLite 写入使用事务。检索使用只读连接与有界缓存；文件哈希启用平台支持的加速。具体并行数、请求上限和默认参数以配置及协议定义为准。

服务支持 20 路检索并发。请求、超时和取消相互独立；同一会话的写入按会话协调。工具授权只发给发起请求的连接。断开连接会取消对应任务，其他连接继续运行。

窗口关闭时隐藏桌面，退出桌面也保留后台服务。`sag status` 和 `sag service status` 只查看状态，不启动服务；`sag service stop` 停止服务，`sag service restart` 重启服务。桌面重连后重新读取文件、设置和历史状态。

## 依赖与分发

内核只链接进 `sag` 可执行文件；桌面仅依赖协议和客户端。桌面包附带同一批原生 CLI；npm 包只分发 CLI 启动入口和已构建的原生程序。构建流程见[开发指南](/zh/docs/development)，发布流程见[npm 发布](https://github.com/Zleap-AI/SAG-Wiki/blob/main/docs/zh-CN/npm发布说明.md)。依赖许可证保存在 `src-tauri/licenses/`。
