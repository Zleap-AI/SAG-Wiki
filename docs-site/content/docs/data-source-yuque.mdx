title: "语雀"
description: "导入语雀个人或团队知识库中的文档。"
---

语雀是在线文档和知识管理平台，可以用知识库组织个人或团队文档。[语雀官网](https://www.yuque.com/)

1. 在 [语雀账号的 Token 设置](https://www.yuque.com/settings/tokens) 创建 API Token，使用能读取目标个人或团队知识库的账号。如果没有创建入口，请核对账号的 API 使用权限。
2. 在 **设置 → 数据源 → 语雀 → 配置** 填写名称和 Token，点 **测试连接**，选择知识库。若导入团队知识库，先展开对应团队。
3. 点击 **保存并导入**。在保存位置核对文档和目录层级，并在 **同步记录** 检查失败项。
