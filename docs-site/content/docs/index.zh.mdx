SAG Wiki 飞牛版是独立项目 `sag-desktop-fnos`。应用使用飞牛统一网关和原生文件授权，保留 SAG 的文件索引、快速搜索、SAG2 检索、引用问答和 Markdown 编辑。

## 使用要求

- 飞牛 fnOS 1.2.0401 或更新版本；移动端相关能力要求飞牛 App 1.34.0 或更新版本。
- 根据 NAS 处理器选择 x86 或 ARM 的 FPK 安装包。
- 快速搜索不需要模型密钥。SAG2 需要 Jev；问答需要配置问答模型。

## 支持范围

支持 Markdown、纯文本、RTF、代码和配置文件。PDF、Word、Excel、PowerPoint、OpenDocument 和 EPUB 内置转换后建立索引；图片识别、扫描件 OCR 和音视频转写通过 Docling 组件按需安装。MCP 支持远程 HTTP 和本地 stdio 命令，保留工具选择和调用前确认。应用升级、启停及桌面入口由飞牛管理。

索引、设置、模型密钥和问答历史按飞牛用户 UID 分开保存。用户仍需在飞牛选择器中授权文件夹。
