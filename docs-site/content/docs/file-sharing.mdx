---
title: "文件分享"
description: "通过分享码发送和接收 Markdown 文档与图片。"
---

文件分享可以将 Markdown 文档、文件夹和引用的图片一起发送给他人。对方通过分享码下载后，即可将内容加入自己的知识库，无需注册账号。

文件在上传前完成加密，并以加密形式临时保存。接收方凭分享码下载查看，分享 1 小时后自动过期。

## 分享文件

桌面端右键点击 Markdown 文件或文件夹，选择 **分享**。程序会打包 Markdown 和正文引用的本地图片；分享文件夹时保留目录结构，跳过其他文件和未引用图片。大小按 B、KB 或 MB 显示。确认文档数、图片数和大小后点击 **分享**，复制 `SAG-XXXXXXXX` 分享码发送给对方。

![分享 Markdown 与引用图片](/images/product-share-cn.png)

点击 **复制分享码** 会复制分享码和下载指引，方便直接发送给对方：

```text
分享码：SAG-XXXXXXXX
复制此分享码，打开SAG-Wiki即可下载对应文件内容
```

## 接收分享

复制对方发来的分享码，再打开或切回 SAG Wiki，程序会自动识别剪贴板并弹出接收窗口。可以复制 `SAG-XXXXXXXX`，也可以直接复制包含“分享码：”和下载指引的整段分享文字。将整段文字粘贴到分享码输入框时，会自动只保留分享码；说明文字在同一行或分行均可。确认保存位置后点击 **下载**，文件才会开始下载。此功能默认开启。

分享码由 8 位字母和数字组成，输入时可带 `SAG-` 前缀。

在添加文件夹窗口切换到 **接收分享**，或右键文件页空白区域选择 **接收分享**。右键入口直接打开独立的接收弹窗，不显示标签切换，填写分享码即可下载。也可从 **设置 → 数据源 → 分享 → 填写分享码** 打开。从文件夹内右键打开时，保存位置使用当前文件夹；从总览或其他入口打开时，使用设置中的默认保存位置（系统文档目录下的 `sag-wiki/share/分享名称/`）。可在下载前更改，本次选择不修改默认设置；同名目录自动编号，已有文件保留。下载完成后自动加入知识库。

![接收分享与保存位置](/images/product-receive-cn.png)

## 默认保存位置与剪贴板

**设置 → 数据源 → 分享** 可更改默认接收位置，也可关闭或重新开启 **识别剪贴板分享码**。这些设置更改后立即保存。

## 分享记录与取消

点击分享弹窗左下角的 **分享记录**，或在 **设置 → 数据源 → 分享 → 分享记录 → 查看** 中查看本机分享的名称、分享码、分享时间和到期时间。记录保存在本机；过期后自动删除，下次启动也会清理已过期记录。此功能只能记录启用后从本机发起的分享。

有效分享可点击 **取消分享**。确认后，分享码立即失效，服务端删除对应的 OSS 文件后返回成功。删除失败时显示错误并可重试。已经下载的副本不受影响。取消成功后，本地记录立即删除，列表同步移除；取消失败则保留记录，方便重试。

## 有效期

分享有效期为 1 小时，有效期内可多次下载；到期停止下载，服务器随后清理文件。无需注册账号。分享码持有人均可下载，请只发给需要接收的人。

## 加密

桌面端和 CLI 在上传前自动加密，下载后自动解密，无需设置密码，分享码仍为 8 位。服务器临时解密校验文件后，只将加密包保存到存储服务；解密密钥也会加密保存，并随分享过期清理。仅有存储下载地址无法解密，持有分享码的人可以下载并打开文件。请使用支持加密分享的新版客户端。

## 支持的内容

先将实际纳入的 Markdown 和有效引用图片打包为 ZIP，同一图片只打包一次。界面显示 ZIP 的实际大小；超过 50 MB 时提示错误，不上传。压缩前的文件总大小不受 50 MB 限制，最多包含 2000 个条目。图片支持 PNG、JPEG、GIF、WebP、AVIF；网络图片保留链接。无法读取、目录外或不支持的图片会自动跳过，不影响分享；Markdown 中的原始引用保持不变。上传前请保存文档，分享使用磁盘上的内容。

## 通过 CLI 分享与接收

```sh
sag share ./notes
sag download SAG-ABCDEFGH
```

使用 `sag download SAG-ABCDEFGH --output ./received` 可指定本次保存位置。详细参数见 [CLI 命令](/zh/docs/cli#分享与下载)。
