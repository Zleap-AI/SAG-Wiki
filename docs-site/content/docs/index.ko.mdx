## 필요한 기능 선택하기

| 작업 | 가이드 | 준비 사항 |
| --- | --- | --- |
| 파일 이름이나 본문 검색하기 | [검색](/ko/docs/search) | 폴더 등록 |
| 여러 파일에서 질문의 근거 찾기 | [심층 검색](/ko/docs/search#심층-검색) | Jev 설정 |
| 출처가 포함된 답변 받기 | [질의응답](/ko/docs/chat) | 답변 모델 설정, 의미 검색을 하려면 Jev도 필요 |
| 파일 읽고 편집하기 | [파일 읽기와 편집](/ko/docs/files) | 폴더 등록 |

원본 파일은 기존 위치에 그대로 남습니다. 빠른 검색에는 클라우드 모델을 사용하지 않습니다. 심층 검색과 질의응답에서는 처리에 필요한 질문이나 본문의 일부가 설정한 서비스로 전송될 수 있습니다.

## 문서 언어

한국어 문서는 설치와 주요 기능을 안내합니다. 한국어로 번역되지 않은 페이지에서 한국어로 전환하면 이 문서 홈이 열립니다. 번역이 준비되지 않은 내용은 영어 문서에서 확인할 수 있습니다.
