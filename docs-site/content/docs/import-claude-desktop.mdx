## 导入聊天记录

1. 在桌面端[打开数据源](/zh/docs/data-sources#打开数据源)，点击 **Claude Desktop** 旁的 **导入聊天记录**。SAG 读取本机留存的 Chat 和 Cowork 会话。
2. 搜索或按项目筛选，预览并勾选会话，然后点击 **导入**。每个会话保存为一份 Markdown，默认放在系统文档目录的 `sag-wiki/agent-history/claude desktop/` 下。

可以在聊天记录文件夹中输入其他路径并点击 **读取**，也可以在保存位置旁点击 **更改**。**展示工具调用过程**和**定时同步**默认关闭。

## 导入产物

点击 **Claude Desktop** 旁的 **导入产物**。在 macOS 上，SAG 会查找会话的 `outputs` 文件夹。未检测到交付目录时，点击 **选择目录**。

筛选文件类型、勾选文件后点击 **导入**。桌面端默认归档到系统文档目录的 `sag-wiki/agent-artifacts/claude-desktop/`。开启 **自动同步** 后，SAG 会继续导入新增和更新的文件。也可以在[网页端选择服务器上的交付目录](/zh/docs/data-sources#在网页端选择交付目录)。
