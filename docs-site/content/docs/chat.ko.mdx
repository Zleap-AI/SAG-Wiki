## 질문하기

**모델 설정**에서 답변 모델의 엔드포인트, 모델 이름, API 키를 설정한 다음 **질의응답**을 엽니다. 의미 검색을 사용할 경우 Jev도 설정하세요.

알아보고 싶은 내용을 입력해 전송합니다. 특정 자료를 질문에 포함하려면 `@`를 입력해 파일을 선택합니다. 검색과 생성이 진행되면 답변이 화면에 표시됩니다.

## 인용 출처 확인하기

답변의 인용을 선택하면 원문의 관련 부분이 표시됩니다. 답변을 활용하기 전에 원문에도 같은 정보가 있는지 확인하세요. 필요하면 질문에 조건을 추가하거나 범위를 좁혀 다시 질문합니다.

답변 언어는 질문에서 지정할 수 있습니다. **표시 언어** 설정은 화면의 메뉴와 버튼에 적용됩니다.
