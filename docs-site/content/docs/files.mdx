## 浏览文件

进入顶部的 **文件** 页面，选择已添加的文件夹。列表显示当前层级的文件与子目录，点击已索引的文件可阅读内容；**返回上层** 用于回到父目录。

![项目资料示例文件列表](/images/product-files-cn.png)

问答或搜索中打开的原文会保留来源页面，阅读后点击返回可以继续之前的会话或搜索。

### 按索引状态筛选

进入文件夹后，点击文件数量旁的筛选按钮，在 **全部**、**已索引** 和 **未索引** 之间切换。筛选只影响当前层级的文件，子目录仍会显示，便于继续浏览。

文件夹标题、文件数量和筛选栏固定在列表顶部，滚动文件时仍可查看和操作。

![滚动文件列表时保留顶部标题与筛选栏](/images/product-files-sticky-cn.png)

未索引文件以灰色显示，点击后会提示检查文件格式与转换设置。可从 **去设置** 打开文件设置，核对已启用的类型；索引失败时，在[索引详情](/zh/docs/folders#重新索引与索引历史)中查看原因。筛选不会修改索引范围或删除文件。

## 新建文档

在 **文件** 页面点击 **新建文档**，直接进入空白 Markdown 编辑器，可以先填写内容。新文档仍为“未命名”时，第一次点击 **保存** 会显示文件名输入框，并选中默认名称，输入新名称即可替换；未输入 `.md` 后缀时会自动补上。已在编辑器中修改名称的文档，保存时不会再次要求输入名称。在 **已索引文件** 总览页新建时，还需要选择保存文件夹，默认选中第一个已添加的文件夹。保存位置使用文件夹树，只显示文件夹名称，可展开并选择子文件夹。尚未添加文件夹时，也可以先写内容，保存时再添加文件夹。

![新文档首次保存时设置名称和文件夹](/images/product-new-document-cn.png)

确认名称和保存位置后，文档写入所选文件夹并更新索引。取消保存会保留已输入的文件名和正文，可以继续编辑。在文件夹内新建的文档保存到当前文件夹：未命名时先输入名称，已命名时直接保存。已经保存过的文档再次保存时直接更新原文件。

## 阅读与编辑 Markdown

点击列表中的 Markdown 文件，在同一窗口阅读和编辑。上方工具栏可以设置标题、加粗、列表、引用和代码块。修改后点击 **保存**，或按 `⌘ S` / `Ctrl S`。

点击文件名左侧的文件夹名称，可以查看和选中复制完整文件夹路径。点击空白处或按 `Esc` 关闭路径浮层。

![查看文档所在文件夹的完整路径](/images/product-document-path-cn.png)

![Markdown 原文与编辑工具栏](/images/product-markdown-cn.png)

保存会修改本地原文件。发现外部修改冲突时，按界面提示处理，避免覆盖其他程序中的修改。HTML 文档以阅读方式展示；搜索和引用可以定位到相应内容。

### 对当前文档提问

点击文档页右下角的 **问答**，在“对当前文档想问些什么？”单行输入框中填写问题，点击最右侧的发送按钮或按 `Enter`。程序会新建会话、切换到问答页，并自动引用当前文件，将本轮范围限定为该文件。

![在文档页直接输入问题并引用当前文件](/images/product-document-question-cn.png)

当前模型通过 SAG 文件工具按需读取正文，引用文件不会自动将全文一次性加入上下文。已有文档包含未保存修改时，会先确认是否保存；新文档须先保存，才能引用实际文件。取消保存会保留已输入的问题。

### 文档目录

Markdown 编辑器左侧提供标题目录，按一至六级标题缩进显示。点击标题会跳到对应段落，滚动正文时会标示当前章节；编辑标题后，目录自动更新。没有标题的文档不显示目录。

![Markdown 文档左侧的标题目录](/images/product-document-outline-cn.png)

阅读区域足够宽时，目录默认展开在正文左侧的留白中，并随可用空间适当加宽，让较长的标题显示得更完整。展开和收起都不改变正文的居中位置与宽度。较窄时只显示展开按钮；手动展开后，空间不足时会收窄正文，避免目录遮挡内容。当前文档会保留你的展开或收起选择。目录导航不会修改正文或产生未保存提示。

### Mermaid 图表

Markdown 中标记为 `mermaid` 的代码块会通过 [Pele](https://github.com/obsidianmd/pele) 在本地渲染为 SVG，支持流程图、时序图、类图、状态图、实体关系图和饼图等。文档编辑器默认显示图表；搜索预览、引用原文和问答内容中也会显示图表。

````markdown
```mermaid
flowchart LR
  A[添加文件夹] --> B[建立索引]
  B --> C[提问]
  C --> D[查看原文]
```
````

![Mermaid 图表及编辑入口](/images/product-mermaid-cn.png)

将鼠标移到图表上，点击 **编辑** 切换为源码；修改后点击 **预览** 返回图表。通过键盘 Tab 也可以定位编辑按钮。保存仍写入原来的 Markdown 代码块。语法错误或内容超过渲染限制时显示错误信息，源码保留，可继续编辑修正。图表内的外部图片和跳转链接不会加载或启用。

## 阅读转换后的文档

Office、PDF、电子书等完成解析和索引后，可以直接点击文件列表中的原文件。程序会打开对应的 Markdown 转换结果，原文件也会计入 **已索引** 筛选，无需手动查找转换目录。

转换结果保存在已添加根目录的 `.sag-converted/` 中，并保留原有子目录结构。编辑并保存转换结果只修改这份 Markdown，原始 Office、PDF 等文件保持不变。格式范围和组件要求见[文件格式与转换](/zh/docs/folders#其他格式与转换组件)。

## 进入探索模式

在文件夹页面点击 **探索模式**，查看当前范围中文档的关联总览。每个节点代表一份文档，连线表示内容相似；上方显示文档和关联数量。

![文档关系总览](/images/product-explore-cn.png)

- **查找文档**：在图上方输入文件名的一部分，例如 `发布`，从结果中选择文档。
- **预览内容**：点击节点，右侧显示原文预览、相关文档和关联词；点击相关文档可继续查看。
- **调整视图**：拖动空白处平移，滚轮或右下角按钮缩放，点击 **适应** 让图重新适合窗口。将指针移到节点上可查看文件名。
- **关联强度**：调整右上角滑块，筛选显示的连线。阈值更高时，仅显示较强关联。

图谱根据本地词项统计生成，不调用 Jev 或回答模型。连线用于发现相关内容，不表示文档互引或因果关系。

## 查看局部关系

选中文档后，点击右侧 **查看局部**，或双击图中的文档节点，缩小到它的局部关联范围。

![发布流程文档的局部关联与相关文档列表](/images/product-explore-local-cn.png)

1. 先从总览选中要阅读的文档，例如 `发布流程.md`。
2. 进入局部后，从右侧相关文档继续查看；**依据** 可查看这条关联对应的内容与词项。
3. 点击 **返回上一步** 撤回一次探索跳转；点击 **关系总览** 回到整个文件夹。
4. 需要完整阅读时点击 **打开文档**；需要浏览文件列表时点击 **返回文件树模式**。

同一份文档在不同范围、不同强度设置下，显示的邻近文档可能不同。
