## 浏览文件

进入顶部的 **文件** 页面，选择已添加的文件夹。列表显示当前层级的文件与子目录，点击已索引的文件可阅读内容；**返回上层** 用于回到父目录。

![项目资料示例文件列表](/images/product-files-cn.png)

问答或搜索中打开的原文会保留来源页面，阅读后点击返回可以继续之前的会话或搜索。

### 按索引状态筛选

进入文件夹后，点击文件数量旁的筛选按钮，在 **全部**、**已索引** 和 **未索引** 之间切换。筛选只影响当前层级的文件，子目录仍会显示，便于继续浏览。

文件夹标题、文件数量和筛选栏固定在列表顶部，滚动文件时仍可查看和操作。

![滚动文件列表时保留顶部标题与筛选栏](/images/product-files-sticky-cn.png)

未索引文件以灰色显示，点击后会提示检查文件格式与转换设置。可从 **去设置** 打开文件设置，核对已启用的类型；索引失败时，在[索引详情](/zh/docs/folders#重新索引与索引历史)中查看原因。筛选不会修改索引范围或删除文件。

## 新建文档

在 **文件** 页面点击 **新建文档**，直接进入空白 Markdown 编辑器，可以先填写内容。新文档仍为“未命名”时，第一次点击 **保存** 会显示文件名输入框，并选中默认名称，输入新名称即可替换；未输入 `.md` 后缀时会自动补上。已在编辑器中修改名称的文档，保存时不会再次要求输入名称。在 **已索引文件** 总览页新建时，还需要选择保存文件夹，默认选中第一个已添加的文件夹。保存位置使用文件夹树，只显示文件夹名称，可展开并选择子文件夹。尚未添加文件夹时，也可以先写内容，保存时再添加文件夹。

![新文档首次保存时设置名称和文件夹](/images/product-new-document-cn.png)

确认名称和保存位置后，文档写入所选文件夹并更新索引。取消保存会保留已输入的文件名和正文，可以继续编辑。在文件夹内新建的文档保存到当前文件夹：未命名时先输入名称，已命名时直接保存。已经保存过的文档再次保存时直接更新原文件。

## 导入笔记

桌面端点击侧栏 **+ → 导入数据**，或打开 **设置 → 数据导入**，在对应来源旁点击 **导入笔记**。

| 来源 | 导入方式 |
| --- | --- |
| Notion | 在 Notion 中导出 HTML，包含子页面，选择导出的 ZIP。Markdown 与 CSV 导出包暂不支持。 |
| Evernote | 选择 ENEX 导出文件，可同时选择多个笔记本。 |
| Google Keep | 使用 Google Takeout 导出 Keep，选择 ZIP。默认包含已归档笔记，可关闭；已删除笔记不导入。 |
| Apple Notes | 仅限 macOS，读取本机已下载的备忘录，选择需要导入的文件夹。 |

笔记转换为 Markdown，保留可转换的正文格式、内部链接和附件。默认保存到系统“文档”目录下的 `sag-wiki/notes/来源/`；点击 **更改** 可选择本次导入的保存位置。按 Notion、Evernote、Google Keep、Apple Notes 建立来源子文件夹，不再按导入时间创建目录。再次导入时跳过已有笔记，相同附件复用，不覆盖已有内容。完成后自动加入知识库并开始索引。

Apple Notes 使用只读数据库快照，不修改备忘录。首次读取如果受系统权限限制，弹窗会显示授权引导。点击 **打开系统设置**，在 **隐私与安全性 → 完全磁盘访问权限** 中开启当前应用。返回后自动重新检查，也可点击 **重新检查**；如果系统要求重启应用，请重启后重试。使用预览版时，请授权 **SAG Wiki Preview**。也可以点击 **选择数据文件夹** 选择包含 `NoteStore.sqlite` 和附件目录的备忘录数据副本。锁定笔记需要先在备忘录中解除锁定，尚未下载到本机的附件无法导入。

![Apple Notes 的完全磁盘访问权限引导](/images/product-apple-notes-permission-cn.png)

结果显示笔记与附件数量；无法转换的项目列出原因，其他成功项目仍可导入。全部笔记转换失败时显示“导入失败”，不会保存失败笔记的空文件。此功能只读取本地文件，不连接来源账号，不调用模型，不持续同步。

![从导出文件导入笔记](/images/product-note-import-cn.png)

## 导入聊天

在桌面端点击侧栏 **+ → 导入数据**，或打开 **设置 → 数据导入**，在 **Claude Code** 或 **Codex** 一行点击 **导入聊天记录**，可将对应的本地聊天记录转换为 Markdown 并加入知识库。

![设置中的数据导入入口](/images/product-data-import-cn.png)

1. 弹窗直接显示所选来源的聊天记录。程序自动读取默认的本地记录目录，也可以输入其他记录文件夹后点击 **读取**。
2. 在左侧按项目筛选或搜索标题，筛选范围包含全部记录。列表每页 50 条，可通过底部按钮翻页，跨页勾选会保留；“全选本页”仅作用于当前页。打开时自动预览第一条聊天，但不会勾选；点击标题切换预览，勾选需要导入的聊天。

   Codex 优先读取本地会话目录，完整正文仅在预览或导入时读取。没有兼容的会话目录时，会从记录文件读取列表信息。
聊天标题优先使用已有名称；名称为空或仅含系统信息时，提取第一条实际提问。图片附件描述不会作为标题；只有图片时使用“图片对话 · 日期”。长标题在列表中省略显示，预览与导出保留完整标题。分支聊天的内部边界说明不导入。

3. **展示工具调用过程** 默认关闭，预览和导入仅包含问题和回答；开启后，切换聊天时也会展示工具调用参数与结果，导入时一并保存，不作固定长度截断。系统提示词、环境与页面上下文、内部通知、续接摘要、思考过程和自动注入的 Skill 正文不导入。用户的提问、回答、Skill 引用和代码示例保留；选项问答只保留问题与所选回答。
4. 点击 **导入**。程序自动保存到系统“文档”目录下的 **sag-wiki/agent-history** 文件夹，并按来源建立 **codex** 和 **claude code** 子文件夹，加入知识库。保存位置显示当前来源的子文件夹。点击位置旁的 **更改** 可选择其他文件夹，程序会记住该位置，之后的导入继续使用它；已有文件保持原位置。中英文界面使用同一名称，首次导入时自动创建。

![选择聊天并预览导入内容，工具调用过程默认关闭](/images/product-chat-import-cn.png)

每个聊天生成一份 Markdown。再次导入时，未变化的内容跳过，新增内容更新同一文件；如果你已编辑导入文件，会提示冲突并保留你的修改。内嵌图片保存到同目录的 `chat-assets/`，外部图片链接保留，遵循阅读器不自动加载外部图片的规则。

支持 Claude Code 的 JSONL 记录与跨文件续接，以及 Codex 的普通和 `.jsonl.zst` 压缩记录。同一 Codex 会话的多个记录文件合并导入。记录损坏、尚未写完或缺少续接文件时显示原因，可修正或等聊天完成后重新读取。原始记录不会被修改；导入过程不调用模型。此功能目前只在桌面端提供，不自动持续同步聊天。

## 阅读与编辑 Markdown

点击列表中的 Markdown 文件，在同一窗口阅读和编辑。上方工具栏可以设置标题、加粗、列表、引用和代码块。修改后点击 **保存**，或按 `⌘ S` / `Ctrl S`。

点击文件名左侧的文件夹名称，可以查看和选中复制完整文件夹路径。点击空白处或按 `Esc` 关闭路径浮层。

![查看文档所在文件夹的完整路径](/images/product-document-path-cn.png)

![Markdown 原文与编辑工具栏](/images/product-markdown-cn.png)

### 按需折叠

右下角 **问答** 上方的 **折叠** 按钮提供 **全文、简述、关键句、要点、卡片、导图** 六个一级标签。打开 Markdown 文件时不调用模型；点击 **折叠** 后，才使用已配置的问答模型生成各层级。简述直接提取原文句子，更短的层级由 AI 生成。原文中的代码块、表格和图片保留，按阅读层级收起；切回全文可查看完整内容。阅读界面直接复用 TextFold 原版阅读器：共同文字平移，其余文字淡入淡出，也支持拖动选择条和双指捏合连续缩放；系统开启减少动态效果时，关闭位移动画。

折叠不会写回原文，折叠后显示底部横向层级选择条，右侧按钮变为 **关闭**；点击 **关闭** 可返回原文继续编辑，正在进行的处理会在后台继续，完成后保存缓存，再次点击 **折叠** 即可查看。处理进度条右侧的 **×** 用于停止本次处理；停止后再次折叠会复用已完成批次的缓存。处理期间仍可阅读原文；失败时显示原因并可重试。如果处理期间修改了正文，需要重新折叠更新后的内容。

正文和层级切换动画沿用阅读器字体与明暗背景，动画过程中保持一致。

处理时，选择条上方显示当前阶段、进度条和百分比。等待模型返回时，显示进度会缓慢前进，逐渐放慢，最多模拟到 **90%**；收到真实进度后向前衔接，不会倒退。真实进度可超过 90%，全部结果返回后才显示 **100%**。显示值结合了真实完成量和等待期间的模拟进度，不表示剩余耗时。

![折叠处理阶段和百分比进度](/images/product-document-fold-progress-cn.png)

生成结果保存在应用数据目录。再次打开相同内容并点击 **折叠** 时直接复用缓存，重启应用或更换模型也不会重复生成。正文变化后，下次点击才重新处理。只有主动点击 **折叠**，才会将文档正文发送给已配置的模型服务。折叠请求不额外指定输出 token 上限，实际输出长度遵循模型服务的默认限制。

生成流程参考 [TextFold 的章节层级实现](https://github.com/chenxiachan/textfold/blob/84427249f932e05e781539c0f3960658ffcbe966/textfold/ladder.py)：按章节处理，每批最多包含 40 个段落、列表项或图注，最多同时请求模型 4 次。请求会提供文档标题、存在时的摘要或开头、目录和当前章节的表格内容。层级生成关闭额外推理，不沿用问答的高强度思考。每批成功后立即缓存，失败重试会复用已完成的部分。若服务截断输出，该批会进一步拆分；拆分后的章节会另行生成章节概括。

**卡片** 将整篇内容组织为章节卡片，显示章节标题、概括和主题词；**导图** 显示同一份内容的思维导图。两者直接在一级标签中切换，不再显示单独的子标签栏。卡片内较长的标签和链接省略显示，避免覆盖相邻卡片；链接地址保持不变。点击段落可局部展开或收起，点击主题词会进入对应内容。操作说明默认收起，点击选择条右侧的 **?** 查看；再次点击、点击其他位置或按 `Esc` 可关闭。

![Markdown 阅读器的卡片视图与六个阅读标签](/images/product-document-fold-cn.png)


保存会修改本地原文件。发现外部修改冲突时，按界面提示处理，避免覆盖其他程序中的修改。HTML 文档以阅读方式展示；搜索和引用可以定位到相应内容。

### 对当前文档提问

点击文档页右下角的 **问答**，在“对当前文档想问些什么？”单行输入框中填写问题，点击最右侧的发送按钮或按 `Enter`。程序会新建会话、切换到问答页，并自动引用当前文件，将本轮范围限定为该文件。

![在文档页直接输入问题并引用当前文件](/images/product-document-question-cn.png)

当前模型通过 SAG 文件工具按需读取正文，引用文件不会自动将全文一次性加入上下文。已有文档包含未保存修改时，会先确认是否保存；新文档须先保存，才能引用实际文件。取消保存会保留已输入的问题。

### 文档目录

Markdown 编辑器左侧提供标题目录，按一至六级标题缩进显示。点击标题会跳到对应段落，滚动正文时会标示当前章节；编辑标题后，目录自动更新。没有标题的文档不显示目录。

![Markdown 文档左侧的标题目录](/images/product-document-outline-cn.png)

阅读区域足够宽时，目录默认展开在正文左侧的留白中，并随可用空间适当加宽，让较长的标题显示得更完整。展开和收起都不改变正文的居中位置与宽度。较窄时只显示展开按钮；手动展开后，空间不足时会收窄正文，避免目录遮挡内容。当前文档会保留你的展开或收起选择。目录导航不会修改正文或产生未保存提示。

### Mermaid 图表

Markdown 中标记为 `mermaid` 的代码块会通过 [Pele](https://github.com/obsidianmd/pele) 在本地渲染为 SVG，支持流程图、时序图、类图、状态图、实体关系图和饼图等。文档编辑器默认显示图表；搜索预览、引用原文和问答内容中也会显示图表。

````markdown
```mermaid
flowchart LR
  A[添加文件夹] --> B[建立索引]
  B --> C[提问]
  C --> D[查看原文]
```
````

![Mermaid 图表及编辑入口](/images/product-mermaid-cn.png)

将鼠标移到图表上，点击 **编辑** 切换为源码；修改后点击 **预览** 返回图表。通过键盘 Tab 也可以定位编辑按钮。保存仍写入原来的 Markdown 代码块。语法错误或内容超过渲染限制时显示错误信息，源码保留，可继续编辑修正。图表内的外部图片和跳转链接不会加载或启用。

## 阅读转换后的文档

Office、PDF、电子书等完成解析和索引后，可以直接点击文件列表中的原文件。程序会打开对应的 Markdown 转换结果，原文件也会计入 **已索引** 筛选，无需手动查找转换目录。

转换结果按[文件设置](/zh/docs/folders#更多文件格式与转换组件)中的存放位置保存，并保留原有子目录结构。点击 **打开原文件** 可用系统默认程序打开原件。编辑并保存转换结果只修改这份 Markdown，原始 Office、PDF 等文件保持不变。格式范围和组件要求见[文件格式与转换](/zh/docs/folders#更多文件格式与转换组件)。

## 进入探索模式

在文件夹页面点击 **探索模式**，查看当前范围中文档的关联总览。每个节点代表一份文档，连线表示内容相似；上方显示文档和关联数量。

![文档关系总览](/images/product-explore-cn.png)

- **查找文档**：在图上方输入文件名的一部分，例如 `发布`，从结果中选择文档。
- **预览内容**：点击节点，右侧显示原文预览、相关文档和关联词；点击相关文档可继续查看。
- **调整视图**：拖动空白处平移，滚轮或右下角按钮缩放，点击 **适应** 让图重新适合窗口。将指针移到节点上可查看文件名。
- **关联强度**：调整右上角滑块，筛选显示的连线。阈值更高时，仅显示较强关联。

图谱根据本地词项统计生成，不调用 Jev 或回答模型。连线用于发现相关内容，不表示文档互引或因果关系。

## 查看局部关系

选中文档后，点击右侧 **查看局部**，或双击图中的文档节点，缩小到它的局部关联范围。

![发布流程文档的局部关联与相关文档列表](/images/product-explore-local-cn.png)

1. 先从总览选中要阅读的文档，例如 `发布流程.md`。
2. 进入局部后，从右侧相关文档继续查看；**依据** 可查看这条关联对应的内容与词项。
3. 点击 **返回上一步** 撤回一次探索跳转；点击 **关系总览** 回到整个文件夹。
4. 需要完整阅读时点击 **打开文档**；需要浏览文件列表时点击 **返回文件树模式**。

同一份文档在不同范围、不同强度设置下，显示的邻近文档可能不同。
