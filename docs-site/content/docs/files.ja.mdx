## ファイルを開く

サイドバーからフォルダーを選び、ファイル一覧の項目を開きます。検索結果や質問応答の引用からも原文を開けます。

一覧では処理状態で絞り込めます。変換や OCR を行うファイルは処理状況に応じて、表示または検索できる範囲が変わります。

## Markdown を作成・編集する

新規ドキュメントの名前が既定の「無題.md」のままなら、最初に **保存** を選ぶと、ファイル名の入力欄が表示されます。作成後に表示言語を変更した場合も同じです。ファイル一覧のトップ画面から作成した場合は、保存先のフォルダーも選びます。既存の Markdown は閲覧や編集ができます。大きい Markdown は先に閲覧モードで開き、目次や文書内検索で目的の箇所へ移動できます。編集する場合は編集操作を選んでから内容を変更し、保存します。

macOS は **⌘ S**、Windows は **Ctrl S** で保存できます。ファイル内のコードや数式は、アプリの表示言語を変えても原文のままです。
