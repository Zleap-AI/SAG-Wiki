桌面端点击侧栏 **+**，在“添加文件夹”窗口切换到 **导入数据**，选择来源。也可在 **已索引文件** 总览页的空白处右键选择 **导入数据**，或打开 **设置 → 数据导入**。

![添加文件夹窗口中的导入数据入口](/images/product-add-data-cn.png)

## 导入笔记

在对应来源旁点击 **导入笔记**。Notion 的 ZIP 导入入口在 **Notion → 配置 → 从导出文件导入**。

| 来源 | 导入方式 |
| --- | --- |
| Notion | 在 Notion 中导出 HTML，包含子页面，选择导出的 ZIP。Markdown 与 CSV 导出包暂不支持。 |
| Evernote | 选择 ENEX 导出文件，可同时选择多个笔记本。 |
| Google Keep | 使用 Google Takeout 导出 Keep，选择 ZIP。默认包含已归档笔记，可关闭；已删除笔记不导入。 |
| Apple Notes | 仅限 macOS，读取本机已下载的备忘录，选择需要导入的文件夹。 |

笔记转换为 Markdown，保留可转换的正文格式、内部链接和附件。默认保存到系统“文档”目录下的 `sag-wiki/notes/来源/`；点击 **更改** 可选择本次导入的保存位置。按 Notion、Evernote、Google Keep、Apple Notes 建立来源子文件夹，不再按导入时间创建目录。再次导入时跳过已有笔记，相同附件复用，不覆盖已有内容。完成后自动加入知识库并开始索引。

Apple Notes 使用只读数据库快照，不修改备忘录。首次读取如果受系统权限限制，弹窗会显示授权引导。点击 **打开系统设置**，在 **隐私与安全性 → 完全磁盘访问权限** 中开启当前应用。返回后自动重新检查，也可点击 **重新检查**；如果系统要求重启应用，请重启后重试。使用预览版时，请授权 **SAG Wiki Preview**。也可以点击 **选择数据文件夹** 选择包含 `NoteStore.sqlite` 和附件目录的备忘录数据副本。锁定笔记需要先在备忘录中解除锁定，尚未下载到本机的附件无法导入。

结果显示笔记与附件数量；无法转换的项目列出原因，其他成功项目仍可导入。全部笔记转换失败时显示“导入失败”，不会保存失败笔记的空文件。此功能只读取本地文件，不连接来源账号，不调用模型，不持续同步。

![从导出文件导入笔记](/images/product-note-import-cn.png)

## 导入聊天

在 **Claude Code** 或 **Codex** 一行点击 **导入聊天记录**，可将对应的本地聊天记录转换为 Markdown 并加入知识库。

1. 弹窗直接显示所选来源的聊天记录。程序自动读取默认的本地记录目录，也可以输入其他记录文件夹后点击 **读取**。
2. 在左侧按项目筛选或搜索标题，筛选范围包含全部记录。列表每页 50 条，可通过底部按钮翻页，跨页勾选会保留；“全选本页”仅作用于当前页。打开时自动预览第一条聊天，但不会勾选；点击标题切换预览。预览会自动滚到底部，显示最新消息。勾选需要导入的聊天。

   Codex 优先读取本地会话目录，完整正文仅在预览或导入时读取。没有兼容的会话目录时，会从记录文件读取列表信息。
聊天标题优先使用已有名称；名称为空或仅含系统信息时，提取第一条实际提问。图片附件描述不会作为标题；只有图片时使用“图片对话 · 日期”。长标题在列表中省略显示，预览与导出保留完整标题。分支聊天的内部边界说明不导入。

3. **展示工具调用过程** 默认关闭，预览和导入仅包含问题和回答；开启后，切换聊天时也会展示工具调用参数与结果，导入时一并保存，不作固定长度截断。系统提示词、环境与页面上下文、内部通知、续接摘要、思考过程和自动注入的 Skill 正文不导入。用户的提问、回答、Skill 引用和代码示例保留；选项问答只保留问题与所选回答。
4. 点击 **导入**。程序自动保存到系统“文档”目录下的 **sag-wiki/agent-history** 文件夹，并按来源建立 **codex** 和 **claude code** 子文件夹，加入知识库。保存位置显示当前来源的子文件夹。点击位置旁的 **更改** 可选择其他文件夹，程序会记住该位置，之后的导入继续使用它；已有文件保持原位置。中英文界面使用同一名称，首次导入时自动创建。

![选择聊天并预览导入内容，工具调用过程默认关闭](/images/product-chat-import-cn.png)

每个聊天生成一份 Markdown。再次导入时，未变化的内容跳过，新增内容更新同一文件；如果你已编辑导入文件，会提示冲突并保留你的修改。内嵌图片保存到同目录的 `chat-assets/`，外部图片链接保留，遵循阅读器不自动加载外部图片的规则。

支持 Claude Code 的 JSONL 记录与跨文件续接，以及 Codex 的普通和 `.jsonl.zst` 压缩记录。同一 Codex 会话的多个记录文件合并导入。记录损坏、尚未写完或缺少续接文件时显示原因，可修正或等聊天完成后重新读取。原始记录不会被修改；导入过程不调用模型。聊天记录导入在桌面端提供。

### 定时导入

点击 **Claude Code** 或 **Codex** 旁的 **导入聊天记录**。弹窗底部的 **定时同步** 默认关闭，此时仅手动导入。打开后可选 **每 30 分钟**、**每小时**、**每 6 小时**、**每 12 小时** 或 **每天**。选择 **每天** 后可指定执行时间。两种来源各自设置，改动自动保存。定时同步共用同一窗口中的聊天记录文件夹和 **展示工具调用过程** 设置。更换来源文件夹时，输入新路径并点击 **读取**。

![设置 Codex 每天的导入时间](/images/product-chat-import-schedule-cn.png)

设置间隔时，从启用、切换频率或上次执行起计时。**每天** 按运行 SAG 的电脑的本地时间执行。后台服务恢复运行时，已到期的间隔任务会执行一次；每日任务只补跑当天。每次处理该来源目录中的会话，沿用手动导入的保存位置和子文件夹。没有变化的会话跳过，新增内容更新原 Markdown，手动修改过的文件保留。鼠标停在定时同步上可查看上次执行结果。

## 接收分享

添加文件夹窗口顶部提供独立的 **接收分享** 标签页，可直接填写分享码和保存位置。设置中的 **数据导入 → 分享** 提供默认位置和剪贴板设置。剪贴板分享码识别默认开启，也可在此关闭或更改接收位置。默认保存到系统文档目录下的 `sag-wiki/share`。位置和识别开关更改后立即保存。

![接收分享标签页](/images/product-receive-tab-cn.png)

详细操作见[分享与接收](/zh/docs/file-sharing)。

## 连接在线数据源

在桌面端打开 **设置 → 数据导入**，找到 **分享** 上方的 **在线数据源**。点击来源名称旁的小时钟或右侧 **配置**。点击弹窗标题旁的 **配置教程**，可查看当前来源的步骤，返回后继续填写。是否启用定时同步在连接内查看。

![数据导入中的在线来源与定时同步入口](/images/product-online-import-cn.png)

### 飞书 [#feishu]

1. 在[飞书开放平台](https://open.feishu.cn/app) 创建或打开一个**企业自建应用**。按下方的知识库或云盘选项复制权限 JSON。
2. 进入 **开发配置 → 权限管理 → 批量处理 → 批量导入/导出权限 → 导入**，粘贴 JSON，确认权限添加到 **用户身份权限**。
3. 在 **安全设置 → 重定向 URL** 添加 `http://127.0.0.1:24682/feishu/oauth/callback`。确认登录账号可以使用该应用，再到 **版本管理与发布** 发布，等待所需审批。
4. 从 **凭证与基础信息** 复制 App ID 和 App Secret。在 **设置 → 数据导入 → 飞书** 选择导入类型并填入凭据，点 **使用飞书账号授权**。授权后返回 SAG，勾选范围，点 **保存并导入**。

如果定时同步因月度额度耗尽而暂停，额度恢复后点 **立即同步**。

#### 知识库 [#feishu-wiki]

勾选页面时，也会导入你有权读取的子页面。

```json
{
  "scopes": {
    "tenant": [],
    "user": [
      "wiki:space:retrieve",
      "wiki:node:retrieve",
      "wiki:node:read",
      "docx:document:readonly",
      "drive:drive:readonly",
      "drive:export:readonly",
      "offline_access"
    ]
  }
}
```

### Lark [#lark]

1. 在 [Lark 开放平台](https://open.larksuite.com/app) 创建或打开 **企业自建应用**。复制下方对应的权限 JSON。
2. 在 **权限管理 → 批量导入/导出权限 → 导入** 粘贴 JSON，确认权限添加到 **用户身份权限**。
3. 在 **安全设置 → 重定向 URL** 添加 `http://127.0.0.1:24682/lark/oauth/callback`。若页面有用户凭证续期选项，将其开启。确认登录账号可以使用该应用，然后发布版本。
4. 在 **SAG → 数据导入 → Lark** 选择导入类型，填入 App ID 和 App Secret，点 **使用 Lark 账号授权**。授权后选好范围和同步频率，再点 **保存并导入**。

### Notion [#notion]

1. 在 [Notion 集成设置](https://www.notion.so/my-integrations) 为目标工作区新建 **内部集成**，启用 **Read content**，复制内部集成的 API Token。[Notion 官方设置说明](https://www.notion.com/zh-cn/help/create-integrations-with-the-notion-api)
2. 打开要导入的页面，在右上角 **⋯ → 连接** 中添加刚建的集成。回到 **SAG → Notion → 配置 → 添加连接**，填写名称和 Token，点 **测试连接**。
3. 勾选已授权的页面，再点 **保存并导入**。支持可转换的 Markdown 和附件。如果页面被截断或缺少内容，同步记录会报错并保留上一次的完整副本。离线 ZIP 可通过 **从导出文件导入** 单独导入。

### 语雀 [#yuque]

1. 在 [语雀账号的 Token 设置](https://www.yuque.com/settings/tokens) 创建 API Token，使用能读取目标个人或团队知识库的账号。如果没有创建入口，请核对账号的 API 使用权限。
2. 在 **SAG → 语雀 → 配置** 填写名称和 Token，点 **测试连接**，选择知识库。若导入团队知识库，先展开对应团队。
3. 点击 **保存并导入**。在保存位置核对文档和目录层级，并在 **同步记录** 检查失败项。

### RSS / Atom [#rss]

1. 在 **SAG → RSS / Atom → 配置** 新建连接时，中文界面会预填[智跃博客中文订阅](https://zleap.com/blog/rss.xml)，其他语言界面会预填[英文订阅](https://zleap.com/en/blog/rss.xml)。你可以换成其他订阅地址，再点 **测试连接**。
2. 核对订阅名称和保存位置，点 **保存并导入**。导入文件保留原文链接，并使用订阅提供的正文或标明为摘要的内容。

### 定时同步 [#scheduled-sync]

每条连接可以单独选择 **仅手动**、**每 30 分钟**、**每小时**、**每 6 小时**、**每 12 小时**或**每天**。选择每天时可指定本机时间。

1. 先保持 **仅手动**，完成一次导入。在测试来源中新增一条内容，或修改一篇已导入的文档。
2. 打开该连接的 **配置 → 同步计划**，选 **每天**，设在本机当前时间几分钟之后并保存。检查列表显示的 **下次同步** 时间。
3. 保持后台服务和电脑运行，等到设定时间后查看 **同步记录**。应出现一条新记录，新增或修改的内容应出现在原保存目录。设置后可以关闭窗口，后台仍在运行时会继续同步。

每条连接可独立暂停定时同步，仍可点 **立即同步**。后台恢复运行时，每条连接最多补跑一次。

文件默认落到系统文档目录的 `sag-wiki/data-sources/平台/连接/`，添加连接时可更改。成功保存后加入索引。同步跳过未变化的条目；冲突时保留本地编辑，失败项可以重试。移除连接和源端删除都不会删除本地副本，SAG 不向来源回写。
