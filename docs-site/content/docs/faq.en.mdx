## Can I use it without an API key?

Yes, for indexing, browsing and local quick search. Semantic retrieval needs Jev configuration; generating answers needs an answer model.

## Are my original files copied or uploaded?

Adding a directory does not move original files. Indexes and metadata are stored locally. Deep search and Q&A send the required question and passages to configured services. Check the relevant component documentation for optional conversion behavior.

## Why is a file missing from search?

Confirm the folder is registered and indexing is ready. Then check file-type settings, ignore rules and excluded subfolders. From the CLI:

```sh
sag list
sag check
```

A directory with zero indexed files has no searchable content.

## Why does indexing progress appear after an upgrade or restart?

The background service checks files against existing indexes at startup. The file total describes what is being checked, not how many files were rebuilt. Unchanged indexes and compatible successful conversions are reused. In [indexing details](/en/docs/folders#reindex-and-history), use Checked, Reused, Updated and Failed to distinguish checking from actual updates. Older history without this summary retains its original processed counts.

Changed content, settings that affect parsed text, or a required parsing or index migration can still update affected documents. Keep indexes and the `.sag-converted` directory to retain reusable data.

## What if the database was created by a newer version?

Keep the data directory and continue using the newer application that created it, or install a compatible newer version. Applications with the version guard reject a newer database schema before running migrations. Previously shipped older binaries do not gain this protection. Do not downgrade the application or delete indexes and conversion caches to resolve the message.

## Why is the sag command missing?

Check that Node.js and npm are installed, then run `npm install -g @zleap-ai/sag`. Reopen your terminal and check `sag --version`. The npm package supports macOS Apple Silicon, Windows x64 and Linux ARM64/x86_64.

## Can the CLI work after the desktop app closes?

Yes. Both use the same independent local service. Normal operations connect to or start it when required. `sag service status` only checks status and does not start it.

## How do I report an issue?

Include your OS, app or CLI version, reproduction steps, expected behavior and actual result in [GitHub Issues](https://github.com/Zleap-AI/SAG-Wiki/issues). Hide keys and sensitive file contents in screenshots.
