## フォルダーを登録する

サイドバーのフォルダー管理の横にある **+** を押し、資料のフォルダーを選びます。完了したファイルから検索できます。元のファイルは移動されません。

PDF では先に抽出できた文字が検索可能になります。OCR や表認識はバックグラウンドで続く場合があります。画像だけのページは認識とインデックス作成が終わってから検索できます。

## 検索範囲を調整する

特定のフォルダーだけを検索するには、検索画面から対象を指定します。設定のファイル関連項目では、インデックス対象の種類や除外するフォルダー名を変更できます。個別のフォルダーに対しても、そのフォルダーのインデックス設定を確認できます。

## インデックスの進捗や失敗を確認する

処理中はサイドバーの状態表示を確認します。**ファイル設定** で **インデックスの詳細を表示する** を有効にすると、ファイル一覧からも進捗を確認できます。処理に失敗したファイルは、インデックス履歴から理由を確認し、再処理できます。
