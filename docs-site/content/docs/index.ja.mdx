SAG Wiki は、手元のドキュメント、メモ、コードを整理して検索できるナレッジベースです。フォルダーを登録し、検索結果や質問への回答から根拠となる原文を確認できます。

## 利用方法を選ぶ

| やりたいこと | 参照先 | 必要なもの |
| --- | --- | --- |
| ファイルの名前や本文を検索する | [検索](/ja/docs/search) | フォルダーの登録 |
| 複数のファイルから質問の根拠を探す | [詳細検索](/ja/docs/search#詳細検索) | Jev の設定 |
| 引用付きの回答を生成する | [質問応答](/ja/docs/chat) | 回答モデル。セマンティック検索には Jev も必要 |
| ファイルを閲覧、編集する | [ファイルの閲覧と編集](/ja/docs/files) | フォルダーの登録 |

元のファイルは手元に残ります。通常のクイック検索ではクラウドモデルを利用しません。詳細検索や質問応答では、処理に必要な質問や本文の一部が設定したサービスへ送信される場合があります。
