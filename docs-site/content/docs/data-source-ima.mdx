title: "腾讯 ima"
description: "导入腾讯 ima 知识库里的笔记、网页和文件。"
---

ima 是腾讯推出的 AI 工作台，可以用知识库收集笔记、网页和文件。[腾讯 ima 官网](https://ima.qq.com/)

1. 在 [腾讯 ima 开放接口](https://ima.qq.com/agent-interface)获取 **Client ID** 和 **API Key**。在 **设置 → 数据源 → 腾讯 ima → 配置** 填入凭据并点 **测试连接**。
2. 勾选有权读取的知识库，再点 **保存并导入**。同步会遍历所选知识库的子目录，导入笔记、可获取正文的网页，以及 PDF、Office、Markdown、TXT、HTML 和 EPUB 文件。
