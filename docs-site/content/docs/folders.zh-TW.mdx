## 新增資料夾

選擇側邊欄「資料夾管理」旁的 **+**，接著選取存放資料的資料夾。已完成索引的檔案即可搜尋，原始檔案會留在原位。

PDF 中可直接擷取的文字會先納入索引。OCR 和表格辨識可能繼續在背景執行。全部是圖片的頁面會在辨識和索引完成後開放搜尋。

## 調整搜尋範圍

如果只想搜尋特定資料夾，可以在搜尋畫面選擇範圍。在 **檔案設定** 中可變更要建立索引的檔案類型或排除的資料夾名稱，也可以查看個別資料夾的索引設定。

## 查看索引進度與錯誤

索引進行中可查看側邊欄的狀態。在 **檔案設定** 啟用 **顯示索引詳情** 後，也能從檔案清單查看進度。若發生錯誤，到 **索引歷史** 查看原因並重新處理失敗的檔案。
