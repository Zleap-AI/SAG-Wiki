## 1. 安裝並開啟

到[安裝指南](/zh-TW/docs/installation)選擇適合你的作業系統和處理器的安裝程式。第一次開啟時會出現使用教學。要重新查看，可以前往 **設定 → 一般 → 快速入門**。

初次設定會建立 `Documents/sag-wiki/clippings`，並將 `Documents/sag-wiki` 加入資料夾管理。既有的知識庫可以繼續使用。

## 2. 新增資料夾

選擇側邊欄「資料夾管理」旁的 **+**，加入要搜尋的資料夾。SAG Wiki 會在背景建立索引。已處理的檔案可以先搜尋，詳見[資料夾與索引](/zh-TW/docs/folders)。

## 3. 搜尋檔案

開啟 **搜尋**，輸入檔案名稱或內文中的字詞。選擇搜尋結果後，可以查看原文與醒目標記的相符位置。

## 4. 開始問答

如果要從多份資料尋找依據，先在 **模型設定** 中設定 Jev 的端點和模型名稱。如果服務要求驗證，再輸入 API 金鑰。接著試用[深入搜尋](/zh-TW/docs/search#深入搜尋)。

如果還需要產生回答，請設定問答模型並開啟[問答](/zh-TW/docs/chat)。選擇回答中的引用可檢視原文。若要把問題限定在特定檔案，可輸入 `@` 選取檔案。
