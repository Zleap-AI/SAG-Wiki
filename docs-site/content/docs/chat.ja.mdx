## 質問する

モデル設定で回答モデルのエンドポイント、モデル名と API キーを設定し、**チャット** を開きます。セマンティック検索を使う場合は、モデル設定で Jev も設定します。

調べたいことを入力して送信します。特定の資料を質問に含めるときは `@` でファイルを選びます。回答は生成される途中から順次表示されます。

## 引用元を確認する

回答内の引用を選択すると、関連する箇所が原文で表示されます。回答を利用する前に、引用元に同じ情報があるか確認してください。必要に応じて質問の条件や対象範囲を追加し、もう一度尋ねます。

回答に使う言語は、質問で指定できます。画面の表示言語はメニューや操作ボタンに適用されます。
