## 表示言語を変更する

サイドバーから **設定 → 一般** を開き、**表示言語** で **日本語**、**简体中文**、**繁體中文**、**English**、**한국어**、**Español** のいずれかを選択します。変更は選択時にプレビューされます。**設定を保存** を選ぶと、アプリを開き直したときにも選択した言語が使われます。キャンセルすると未保存の変更は元に戻ります。

保存した言語は、デスクトップアプリと Web 画面、デスクトップのショートカット検索やトレイメニューにも適用されます。Windows インストーラーでは、インストール時に別の言語を選びます。

![日本語の表示言語設定](/images/product-preferences-ja.png)

## 外観を変更する

外観の設定から、ライト、ダーク、またはシステムに従うテーマを選べます。ドキュメントの文字サイズも変更できます。表示サイズを変えても、元の文書の書式は変わりません。

## ショートカット検索を設定する

設定のショートカット項目で、ショートカット検索を有効にしたり、キーの組み合わせを変更したりできます。macOS の既定は **⌘⇧Space**、Windows は **Ctrl+Shift+Space** です。**ショートカットを適用** を選ぶと、変更がすぐに反映されます。キーを押して検索ウィンドウが開くことを確認してください。
