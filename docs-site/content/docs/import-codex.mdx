Codex 是 OpenAI 的编程助手，可以协助编写、修改和审查代码。[Codex 官网](https://openai.com/codex/)

1. 在桌面端[打开数据源](/zh/docs/data-sources#打开数据源)，点击 **Codex** 旁的 **导入聊天记录**。
2. SAG 默认从 `~/.codex` 读取会话。若设有 `CODEX_HOME`，则使用该目录。支持普通 `.jsonl` 和压缩的 `.jsonl.zst` 记录。要读取其他位置，输入聊天记录文件夹的完整路径，再点击 **读取**。
3. 按项目筛选或搜索标题，勾选需要的会话，预览后点击 **导入**。同一会话的多份记录会合并为一份 Markdown，默认保存在系统文档目录的 `sag-wiki/agent-history/codex/` 下。点击 **更改** 可选择其他位置。

## 导入选项

**展示工具调用过程** 默认关闭。开启后，预览和导入都会包含工具调用的参数和结果。

**定时同步** 默认关闭。打开后可选同步频率，也可设为每天固定时间。再次导入会跳过未变化的会话，只更新有新内容的文件。已手动修改的文件会保留，并提示冲突。
