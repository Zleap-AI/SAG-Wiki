## 桌面端

<ReleaseDownloads language="zh" />

每个正式版本同时提供 Windows x64、Apple Silicon 和 Intel 安装包；GitHub Release 正文的下载表列出各平台入口。

macOS：根据“关于本机”中的芯片或处理器选择安装包：M 系列芯片选 Apple Silicon（`arm64`），Intel 处理器选 Intel（`x86_64`）。上表仅显示最新正式版实际提供的安装包；若未显示 Intel 行，说明该版本尚未提供 Intel 包。打开 DMG，将 SAG Wiki 拖入 Applications，然后启动应用。Windows：运行安装器，按提示完成安装。安装器提供简体中文、繁体中文和英文。

启动应用后，在 **设置 → 通用** 中选择简体中文、繁体中文、英文、日语、韩语或西班牙语。Windows 安装器语言在安装时单独选择。详见[通用与外观设置](/zh/docs/preferences)。日语、繁体中文、韩语和西班牙语界面从 0.3.13 起提供。

[打开最新正式版，查看安装包与更新说明](https://github.com/Zleap-AI/SAG-Wiki/releases/latest)

## 只安装 CLI

需要 Node.js 18 或更高版本，无需 Rust 或源码编译。独立 CLI 支持 Apple Silicon Mac、Intel Mac（从 `0.3.11` 起）、Windows x64，以及 Linux ARM64 / x86_64（Ubuntu 24.04、Debian 12）。

```sh
npm install -g @zleap-ai/sag
sag --version
```

安装 CLI 不会安装桌面端。继续阅读 [Agent 接入](/zh/docs/agents)或 [CLI 命令](/zh/docs/cli)。

## 更新

桌面端可通过应用内更新获取对应架构的后续版本，也可手动下载新安装包。启动新版桌面端后，由桌面端管理的 `sag` 会同步更新。可用 `sag --version` 确认版本。npm 安装的 CLI 通过 `npm install -g @zleap-ai/sag` 更新。

<Callout title="文件与配置">升级通常保留原文件、知识库配置和会话记录。卸载或清理前，请确认操作的是索引数据还是原始文档。</Callout>

## 关于与软件更新

入口：**设置 → 关于**。这里显示当前安装版本，并提供开源项目与开发公司链接。

![关于页面的版本号与软件更新入口](/images/product-about-cn.png)

应用启动时检查更新，持续运行期间每隔 8 小时再检查一次，也可以点击 **检查更新** 手动查询。发现新版本后会提示，由你选择 **下载更新**；下载完成并通过校验后，按钮变为 **重启并更新**。

从 0.3.13 起，桌面端按已保存的界面语言选择官方更新源。简体中文通过 Zleap 官网检查和下载更新，英文、繁体中文、日语、韩语和西班牙语通过 GitHub 更新。已有默认官方更新配置在升级时迁移一次，自定义更新源保持原样。独立安装的旧版 CLI 可参阅 [CLI 与桌面端共用](/zh/docs/cli#与桌面端共用)。

- 展开 **更新说明** 查看版本变化，支持标题、列表、加粗和链接。
- 下载期间可以继续使用应用，关闭设置页不会中断下载。
- 如果保存界面语言后官方更新源发生切换，且当前下载失败，「关于」页会保留失败提示，并自动检查切换后的更新源。
- 重启安装前先处理未保存文档，按界面提示保存或取消。macOS 上，旧进程退出后会自动从原安装位置重新打开应用。
- 退出整个应用后，未完成的下载需要重新开始。
- 更新失败时会显示错误，可重新检查或前往 GitHub 下载完整安装包。
- 更新替换应用文件，保留知识库、会话及本地原文件。

![更新说明中的标题、列表和加粗文字](/images/product-release-notes-cn.png)

关于页显示的是当前安装程序版本。本页打开时读取 GitHub 最新正式版的版本号、安装包地址和实际大小。

## Windows 本地服务启动失败

若提示“无法连接本地 SAG 服务”，且日志出现保存连接记录时“拒绝访问”，请保留完整错误和应用版本。包含账户权限修复的版本按当前进程用户 SID 设置连接记录权限，不依赖电脑名称或用户名；更新后重启应用再检查。不要将整个数据目录授权给所有用户。此修复尚未包含在 0.2.7 正式包中。
