## 選擇適合的功能

| 我想做什麼 | 功能 | 需要準備 |
| --- | --- | --- |
| 依檔案名稱或內文搜尋 | [快速搜尋](/zh-TW/docs/search) | 加入資料夾 |
| 從多份資料找出問題的依據 | [深入搜尋](/zh-TW/docs/search#深入搜尋) | 設定 Jev |
| 產生附有引用的回答 | [問答](/zh-TW/docs/chat) | 設定問答模型，語意搜尋需設定 Jev |
| 檢視或編輯檔案 | [檔案與編輯](/zh-TW/docs/files) | 加入資料夾 |

原始檔案會留在電腦上。快速搜尋不會呼叫雲端模型。深入搜尋和問答可能將處理所需的問題與部分原文送往你設定的服務。
