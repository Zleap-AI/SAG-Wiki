title: "Yuque"
description: "Import documents from personal or team books in Yuque."
---

Yuque is a platform for writing online documents and organizing personal or team knowledge in books. [Yuque website](https://www.yuque.com/)

1. Create an API token in [Yuque token settings](https://www.yuque.com/settings/tokens) using an account with read access to the target personal or team book. If the option is unavailable, check the account's API access.
2. In **Settings → Data sources → Yuque → Configure**, enter the connection name and token. Click **Test connection** and choose the book. For a team book, expand the relevant team first.
3. Click **Save and import**. Check the documents and folder structure at the save location and review any failures in **Sync history**.
