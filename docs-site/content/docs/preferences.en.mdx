## Saving settings

Open **Settings** from the lower-left corner, choose a category, make your changes and select **Save settings**. **Cancel** discards ordinary unsaved changes. Language changes are previewed immediately and reverted on cancellation.

Testing a connection does not save its configuration. Removing a key, installing or removing a Skill, restoring directories and clearing data are separate actions that run immediately or request their own confirmation.

## General

Location: **Settings → General**.

| Setting | Purpose | Default or choices |
| --- | --- | --- |
| Start page | The first page shown when the app opens | Q&A by default; Q&A or Search |
| Interface language | Language of menus, controls and messages | Simplified Chinese by default; Simplified Chinese or English |
| After closing the window | Shows the window-close behavior | Continue running in the background |
| Quick start | Reopen the folder, search and Q&A tutorial | Select View tutorial |

Reopen the app from the system tray or menu bar. The desktop UI and local service are separate; closing the desktop does not stop the CLI service.

## Appearance

Location: **Settings → Appearance**.

| Setting | Purpose | Default or choices |
| --- | --- | --- |
| Theme | Application color scheme | Light by default; Light, Dark or System |
| Document font size | Reading size, with a preview in settings | 15 px by default; 14, 15, 16 or 18 px |

Document font size changes the reading display, not the original document. System mode follows the operating system theme.

![Theme, document font size and preview](/images/product-appearance-en.png)

## Keyboard shortcuts

Location: **Settings → Shortcuts**. Customize or disable the global Quick Search shortcut here, and view the other keyboard controls.

Quick Search defaults to **⌘⇧Space on macOS** or **Ctrl+Shift+Space on Windows**. Click the shortcut field, press a combination, and choose **Apply shortcut** to save and activate it immediately. Conflicts are reported as errors. Use **Open Quick Search** to try the popup. See [Quick Search popup](/en/docs/search#quick-search-popup).

After turning the switch on or off, choose **Apply shortcut** to save the change.

![Quick Search switch, global shortcut and action buttons](/images/product-quick-search-settings-en.png)

## Runtime settings

File, Model, Search and Q&A settings each expose their runtime parameters. Common controls are visible directly; workers, memory, batches and caches are under **Advanced runtime settings**. Each group can reset to backend-defined defaults, with server-side range and consistency validation.

![Conversion timeouts and advanced runtime settings](/images/product-runtime-en.png)

| Page | Controls |
| --- | --- |
| File settings | Built-in/Docling timeout, input/output limits, threads, OCR/table options and batches, page limits, memory, text limits and watcher debounce |
| Model settings | Retry count, initial/maximum backoff, total deadline; separate MinerU parsing controls |
| Search settings | JEV concurrency/context, local query workers and query/corpus caches |
| Q&A settings | Folding concurrency and units per batch |

Built-in conversion defaults to 120 seconds; Docling defaults to 1800 seconds with 60 extra seconds for process cleanup. Converted text defaults to 16 MiB, matching the downstream indexing input limit. Raise the output, index input, decoded/prepared text and total preparation budget together when larger text is needed. Memory per job set to 0 means automatic. Actual concurrency also respects conversion workers and reserved memory.

Changes apply to new tasks. Running tasks retain their startup settings. Timeout, concurrency and cache changes do not rebuild indexes. OCR, table, page and parser changes refresh the relevant conversions on subsequent scans. An anydoc timeout discards the result while its native worker may run until the library returns; Docling terminates its process tree on timeout.
