---

## 1. 安装并打开

前往[下载安装](/zh/docs/installation)，选择适合系统的安装包。只希望给 Agent 使用的用户，可直接前往 [Agent 接入](/zh/docs/agents)，无需安装桌面端。

首次创建知识库时，程序会建立 `Documents/sag-wiki/clippings`，并将 `Documents/sag-wiki` 加入文件夹管理。可直接用它保存笔记和网页剪藏，也可以继续添加其他目录；已有知识库不受影响。

## 2. 添加一个文件夹

点击左侧“文件夹管理”旁的 **+**，选择文档所在文件夹。等待索引完成后开始搜索。添加文件夹不会移动原文件。

![添加文件夹后的界面](/images/product-folders-cn.png)

本页使用 HowToLiveBetter 的 Markdown 文件夹作为示例，也可以选择你自己的文档目录。

## 3. 搜索资料

进入“搜索”，输入文档中的词语，用快速搜索确认结果。点击结果可查看原文及高亮位置。

## 4. 按问题查找

在设置的模型配置中填写 Jev 服务、模型和 API Key，然后选择深入搜索，输入完整问题，例如：

```text
这个项目如何处理登录与权限？
```

## 5. 根据资料提问

配置回答模型后，进入“问答”。提出问题，等待检索和回答完成，再点击引用核对原文。输入 `@` 可指定文件。

<Callout title="成功标志">文件夹完成索引；快速搜索能找到原文；配置模型后，深入检索或问答能返回相关来源。</Callout>
