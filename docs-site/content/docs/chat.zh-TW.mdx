## 提出問題

在 **模型設定** 中輸入問答模型的端點、模型名稱與 API 金鑰，再開啟 **問答**。若要使用語意搜尋，也要設定 Jev。

輸入問題並送出。要將問題限定在特定資料，可以輸入 `@` 選擇檔案。搜尋和產生進行時，回答會逐段顯示。

## 核對引用

選擇回答中的引用即可查看相關原文。使用回答前，請先核對引用來源是否支持回答。如果結果不夠精確，可以加上條件或縮小資料範圍後再問一次。

你可以在問題中指定希望使用的回答語言。介面語言只影響選單、按鈕及提示。
