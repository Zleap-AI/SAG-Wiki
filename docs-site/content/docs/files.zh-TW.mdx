## 開啟檔案

在側邊欄選擇資料夾，再選取檔案清單中的項目。也可以從搜尋結果或問答引用開啟原文。

檔案清單可以依處理狀態篩選。需要轉換或 OCR 的檔案，可檢視與搜尋的範圍會隨處理進度改變。

## 建立和編輯 Markdown

選擇 **新增文件** 可建立 Markdown 草稿。如果仍使用預設的 `未命名.md`，首次選擇 **儲存** 時會顯示檔案名稱欄位。若在建立草稿後切換過介面語言，仍會提示命名。從檔案總覽建立的文件還需要選擇要儲存的資料夾。

既有的 Markdown 預設以編輯模式開啟。在 **設定 → 一般** 將 **文件預設開啟方式** 設為 **檢視** 後，可透過目錄或文件內搜尋找到段落。要修改時，請點擊右上角的 **編輯**。

macOS 可按 **⌘ S**，Windows 可按 **Ctrl S** 儲存。切換介面語言不會改動使用者檔案內的程式碼或公式。
