## 网页服务

1. 使用桌面端时，打开 **设置 → 远程服务**，开启 **网页服务**。
2. 在本机点击地址旁的打开按钮，或在同一局域网的其他设备上打开显示的局域网地址。
3. 点击 **复制访问码**，将访问码粘贴到浏览器登录页。登录成功后，同一浏览器再次打开同一地址时会自动连接。点击 **退出** 可清除记住的访问码。

首次登录页按浏览器首选语言显示，支持简体中文、繁体中文、英语、日语、韩语和西班牙语，其他语言使用英语。已连接过的网页在当前页面上退出或需要重新连接时，会沿用知识库的界面语言。

点击 **更换访问码** 并确认后，旧码立即失效，已登录的浏览器需要重新输入新码。网页服务保持开启，API Key 不受影响。关闭网页服务也会使旧码失效。

![远程服务设置中的网页地址和访问码](/images/product-remote-services-cn.png)

在 **API 和 MCP** 下方的 **连接配置** 中，选择 **仅本机** 可限制为本机访问。选择 **本机与局域网** 后，同一局域网的其他设备也可连接。若无法修改连接配置，请先关闭正在运行的远程服务。

## 网页功能

网页用于日常使用：浏览文件、新建和编辑 Markdown、搜索、问答、保存笔记和查看索引进度。网页与桌面端共用文件、索引和问答历史。添加或移除知识库目录、配置模型和管理服务需要在运行 SAG Wiki 的电脑上完成；网页不提供从知识库移除目录或文件的操作。

手机窄屏默认隐藏侧栏。点击左上角按钮展开，点击侧栏外或收起按钮关闭。侧栏展开时覆盖页面，正文宽度保持不变。

进入会话或搜索结果后，顶部居中显示 **问答** 或 **搜索**。打开文档时使用文档工具栏。点击左上角的箭头返回上一层。搜索时，关键词和搜索按钮在第一行，搜索范围和模式在第二行。提交搜索或发送问题后，键盘会自动收起。

在侧栏打开 **设置** 后，可在全屏页面顶部切换 **通用** 和 **外观**。点击底部的 **保存设置** 应用更改，或点击左上角的箭头返回。

如果网页提示缺少模型，请联系管理员在服务端配置。快速搜索无需配置模型。

持有访问码即可查看知识库和编辑文件。内置 HTTP 连接不加密，请在可信局域网内使用。服务端电脑和后台服务需保持运行，桌面窗口可以关闭。

## 通过 CLI 开启

支持 `sag api web` 的独立 CLI 可在 **Windows x64、macOS Apple Silicon 和 Linux** 上运行网页服务。Linux 支持 Ubuntu 24.04 和 Debian 12（x86_64 / ARM64）。

在运行 CLI 的电脑上打开终端，运行 `sag add` 并指定本机文件夹路径，将目录加入知识库并建立索引。用 `sag list` 查看索引状态；用 `sag remove` 并指定目录路径可取消接入，原文件会保留。完整用法见 [CLI 命令](/zh/docs/cli#命令)。

运行 `sag api web start` 开启网页服务，运行 `sag api web code` 查看访问码。用 `sag api status` 查看地址。选择局域网访问时，在同一局域网的另一台设备上打开显示的地址，然后输入访问码。运行 `sag api web stop` 关闭网页服务。

## 通过公网 IP 或域名访问

如果公网 IP 映射到内网 IP，请在主机上用 `sag api web external-url` 保存浏览器实际打开的完整地址。

```sh
sag api web external-url http://203.0.113.10:24681
```

把示例 IP 换成实际地址。保存后可用 `sag api status` 查看。保存地址不会开启网页服务，也不会更改访问码开关或放行防火墙端口。需要网页服务时再运行 `sag api web start --host 0.0.0.0`，并在防火墙和云安全组中仅对需要访问的来源放行端口。

地址必须包含 `http://` 或 `https://`；非默认端口要写明。通过 HTTPS 反向代理访问时，填入浏览器使用的 HTTPS 地址；代理负责 HTTPS，并须保留原始请求的主机名和端口。其他外部地址仍会被拒绝，本机和局域网地址仍可使用。

运行 `sag api web external-url --clear` 可清除外部地址。
