## 网页服务

1. 使用桌面端时，打开 **设置 → 远程服务**，开启 **网页服务**。
2. 在本机点击地址旁的打开按钮，或在同一局域网的其他设备上打开显示的局域网地址。
3. 点击 **复制访问码**，将访问码粘贴到浏览器登录页。登录成功后，同一浏览器再次打开同一地址时会自动连接。点击 **退出** 可清除记住的访问码。

点击 **更换访问码** 并确认后，旧码立即失效，已登录的浏览器需要重新输入新码。网页服务保持开启，API Key 不受影响。关闭网页服务也会使旧码失效。

![远程服务设置中的网页地址和访问码](/images/product-remote-services-cn.png)

在 **API 和 MCP** 下方的 **连接配置** 中，选择 **仅本机** 可限制为本机访问。选择 **本机与局域网** 后，同一局域网的其他设备也可连接。若无法修改连接配置，请先关闭正在运行的远程服务。

## 网页功能

网页用于日常使用：浏览文件、新建和编辑 Markdown、搜索、问答、保存笔记和查看索引进度。网页与桌面端共用文件、索引和问答历史。添加服务器目录、配置模型和管理服务需要在运行 SAG Wiki 的电脑上完成。

如果网页提示缺少模型，请联系管理员在服务端配置。快速搜索无需配置模型。

持有访问码即可查看知识库和编辑文件。内置 HTTP 连接不加密，请在可信局域网内使用。服务端电脑和后台服务需保持运行，桌面窗口可以关闭。

## 通过 CLI 开启

支持 `sag api web` 的独立 CLI 可在 **Windows x64、macOS Apple Silicon 和 Linux** 上运行网页服务。Linux 支持 Ubuntu 24.04 和 Debian 12（x86_64 / ARM64）。

在运行 CLI 的电脑上打开终端，运行 `sag add` 并指定本机文件夹路径，将目录加入知识库并建立索引。用 `sag list` 查看索引状态；用 `sag remove` 并指定目录路径可取消接入，原文件会保留。完整用法见 [CLI 命令](/zh/docs/cli#命令)。

运行 `sag api web start` 开启网页服务，运行 `sag api web code` 查看访问码。用 `sag api status` 查看地址。选择局域网访问时，在同一局域网的另一台设备上打开显示的地址，然后输入访问码。运行 `sag api web stop` 关闭网页服务。
