## 开始一个会话

进入“问答”，输入问题并发送。输入 `@` 可指定文件；范围选择决定可检索哪些资料。

![带有引用的回答](/images/product-chat-cn.png)

生成期间，思考过程、中途文字和工具调用按发生顺序展示。最终回答开始出现后，这些内容自动折叠，回答上方只保留一行用时和分割线；点击用时可重新展开查看详情。

本地服务连接临时失败时会显示错误并继续重连，恢复后新发起的问答仍会逐段显示内容和工具进度。

生成内容时，页面自动跟随最新内容。手动向上滚动后会暂停跟随，即使只滚动很小的距离，也会保留当前阅读位置；滚回底部后恢复跟随。

![最终回答上方自动折叠的处理过程](/images/product-answer-process-cn.png)

回答支持 Markdown 标题、表格、引用块、有序和无序列表、任务列表、链接及代码块。宽表格和代码块可横向滚动，引用编号仍可点击查看原文。

![回答中的 Markdown 表格、引用块与列表](/images/product-answer-markdown-cn.png)

回答中的 `mermaid` 代码块会在本地显示为图表。语法错误时保留源码并显示错误信息。支持范围和示例见 [Mermaid 图表](/zh/docs/files#mermaid-图表)。

## 查看引用

点击答案中的引用编号，侧栏会打开完整文档，自动定位并高亮相关段落。支持 HTML 和 Markdown。

文件名下方显示灰色文件路径。较长的路径会省略显示，悬停可查看完整路径。

![引用对应的完整原文](/images/product-citation-cn.png)

引用提供核对依据；如果资料不足或存在矛盾，请查看原文上下文再判断。进入独立文档页后，返回操作会回到原来的会话。

## 管理会话

返回会话列表可以切换历史会话或创建新会话。新会话从独立上下文开始，历史记录保留在列表中。

同一会话继续提问时，尚未总结的历史包含之前的问题、最终回答和精简工具记录。每次工具调用保留名称、状态及结果的前 500 个字符；思考过程、调用参数和中途文字不带入下一轮。界面中仍可查看完整记录。

每次继续请求模型前都会检查上下文预算，包括工具调用过程中。内容过多时，应用使用当前问答模型生成摘要，保留任务、用户约束、已确认事实与证据、已完成工作、未完成事项和下一步。摘要替代较早的内容，预算允许时保留最近一轮问答和最近一次完整工具调用。

特别长的历史会分批总结并合并，已生成的摘要随会话保存，后续追问继续使用。总结会产生额外模型请求，不占工具调用次数。摘要生成失败时显示错误并保留原始记录。完整问题、回答、工具记录及引用原文仍保存在本地，不会被摘要覆盖。

## 配置回答模型

在模型设置中填写服务地址、模型与 API Key。需要语义检索时，同时配置 Jev。Jev 用于查找证据，回答模型用于组织最终答案。

## 问答设置详解

入口：**设置 → 问答设置**。先在“问答模型”中选中要配置的模型。

![按模型配置思考强度与系统提示词](/images/product-chat-settings-cn.png)

### 按模型保存的设置

| 设置 | 用途 | 注意事项 |
| --- | --- | --- |
| 思考强度 | 调整模型提供的思考档位 | 可用值由模型与服务决定。更高档位通常更慢；不支持时使用默认。 |
| 系统提示词 | 指定回答角色、语言、风格或任务要求 | 仅影响当前模型。留空使用内置提示词；清空可恢复内置提示词。 |
| SAG 内置工具 | 允许模型检索本地文件、读取、匹配、获取时间和计算 | 可关闭整个工具组或单个工具。语义搜索还需要 Jev。 |
| 外部 MCP 绑定 | 选择该模型可用的外部服务与工具 | 服务连接配置可共用，绑定与工具选择按模型保存。 |

思考强度以界面实际可选值为准，部分模型提供关闭、低、中、高或极高。出现“未适配”时不要把它理解为模型完全不能使用；它表示当前服务与模型组合尚未适配强度参数，可恢复默认。

系统提示词不会替代模型连接配置，也不能让不支持工具调用的模型获得工具能力。工具的添加、测试与调用确认见 [MCP 与工具绑定](/zh/docs/mcp)。

### 所有模型共用的请求设置

| 设置 | 默认值 / 范围 | 用途与影响 |
| --- | --- | --- |
| 每轮工具调用上限 | 10 / 0–100 | 默认 10 次；0 表示不限制次数；设置为 1–100 时，限制同一轮问答中 SAG 与外部 MCP 工具的总调用次数。达到指定上限后根据已有结果回答，并说明尚未确认的部分。 |
| 回答上下文预算（tokens） | 65536 / 最小 4096 | 控制问题、历史、工具记录和引用等输入规模。没有固定最大值，应按模型实际上下文能力填写；超预算时应用会缩减可用历史或材料。 |
| 请求超时 | 120 秒 / 10–600 秒 | 控制等待服务请求的时间。太短可能中断较慢模型，太长会延长失败前等待。 |

上下文预算不等于输出长度设置，输出长度由模型服务决定。填入超过服务上限的值，不会提高模型能力，反而可能导致请求失败。

工具调用上限与 SAG2 扩展轮数也不同：一次 `search` 工具调用内部可以包含多轮检索及多次 Jev 请求。

### 保存与验证

保存后新发一条问题，检查所选模型、工具是否出现、引用是否能打开。改变模型时，重新确认该模型的提示词、思考强度和工具绑定，而非假设沿用上一个模型的配置。
