## 开始一个会话

进入“问答”，输入问题并发送。输入 `@` 可指定文件；范围选择决定可检索哪些资料。

侧栏直接显示文件夹管理和文件树。问答首页保留欢迎区、提问框和会话列表。要添加资料，点击侧栏「文件夹管理」旁的 **+**。

桌面端的问答图标会在静置或鼠标悬停时随机播放一个小动作。开启系统的减少动态效果后会暂停动效。

![问答首页的会话列表与文件夹侧栏](/images/product-ask-home-cn.png)

![带有引用的回答](/images/product-chat-cn.png)

生成期间，思考过程、中途文字和工具调用按发生顺序展示。最终回答开始出现后，这些内容自动折叠，回答上方只保留一行用时和分割线；点击用时可重新展开查看详情。

本地服务连接临时失败时会显示错误并继续重连，恢复后新发起的问答仍会逐段显示内容和工具进度。

生成内容时，页面自动跟随最新内容，包括从检索过程切换到正文的阶段。使用滚轮或触控板向上滚动会暂停跟随并保留当前阅读位置。滚回底部后恢复跟随。

![最终回答上方自动折叠的处理过程](/images/product-answer-process-cn.png)

## SAG Wiki 助手

助手首页的会话列表和搜索仅显示助手问答。切回我的文件后，可以在问答首页查看和搜索知识库会话。

在问答首页的输入框下方，点击 **SAG Wiki 助手**。输入框会显示一个示例问题。留空时，按 Enter 直接发送示例，或按 Tab 填入后再编辑。

助手用 SAG2 检索随应用内置的 SAG Wiki 使用文档和中英文更新日志。可以直接问“0.4.0 更新了什么？”。配置回答模型后，由模型调用 `sag2_search` 查找原文，并在证据不足时补查。回答以流式方式输出。未配置回答模型时，应用直接运行 SAG2 并显示相关原文。配置 Jev 后，由 Jev 判断证据相关性。未配置 Jev 时，使用本地排序和扩展检索。

点击左下角的问号，可在浏览器打开当前界面语言的在线文档。

内置更新日志提供简体中文和英文。使用其他界面语言时，助手也可以查阅英文更新日志。点击日志里的站内链接可打开官网对应页面。

点击回答中的引用编号，可在应用右侧查看完整文档并定位到引用的章节。在助手首页，点击输入框下方的 **切回我的文件** 可返回问答首页。进入助手对话后，点击左上角的返回箭头回到助手会话列表。

## 查看研究步骤

展开回答上方的处理过程，可以查看分组展示的检索、阅读资料和工具耗时。

![展开后的研究步骤](/images/product-research-steps-cn.png)

回答支持 Markdown 标题、表格、引用块、有序和无序列表、任务列表、链接及代码块。宽表格和代码块可横向滚动，引用编号仍可点击查看原文。

![回答中的 Markdown 表格、引用块与列表](/images/product-answer-markdown-cn.png)

回答中的 `mermaid` 代码块会在本地显示为图表。语法错误时保留源码并显示错误信息。支持范围和示例见 [Mermaid 图表](/zh/docs/files#mermaid-图表)。

回答中的数学公式在本地渲染：行内使用 `$…$` 或 `\(…\)`，独立公式使用 `$$…$$` 或 `\[…\]`。货币金额、`$HOME` 这类写法、代码和行内代码保持原样；无法解析的公式显示错误提示并保留源码，方便复制。公式同样适用于知识库文档的阅读视图。文档转换保留的上下标按原格式显示；PDF 公式要显示为 TeX，需要解析器提供 LaTeX（例如开启 MinerU 公式识别）。

公式渲染所需的字体随应用提供，离线可用，不依赖 CDN。

以 `$…$` 包裹的孤立上下标片段（例如 `V$_{0}$` 中的 `$_{0}$`）保留为文本。带有底数的前置上下标（例如 `$_{2}^{3}He$`）和转义下划线（例如 `$x\_$`）仍按公式渲染。

命令或路径包含多个 `$` 符号时，请使用行内代码，例如 `$HOME/$USER`，以保持原样。

## 查看引用

点击答案中的引用编号，侧栏会打开完整文档，自动定位并高亮相关段落。支持 HTML 和 Markdown。

文件名下方显示灰色文件路径。较长的路径会省略显示，悬停可查看完整路径。

![引用对应的完整原文](/images/product-citation-cn.png)

引用提供核对依据；如果资料不足或存在矛盾，请查看原文上下文再判断。进入独立文档页后，返回操作会回到原来的会话。

## 保存为笔记

回答完成后，点击回答下方的“保存为笔记”，可以把这条回答保存为知识库里的 Markdown 文件。首次保存会打开保存面板：文件名由问题生成，默认保存到“文稿 / sag-wiki / notes”，该文件夹不存在时自动创建并加入知识库；也可以在面板里选择其他已加入的文件夹，并勾选“记住此位置”。关闭 **设置 → 问答设置 → 笔记 → 每次询问保存位置** 后，后续保存直接写入记住的目录；按住 Option（macOS）或 Alt（Windows）点击保存可再次打开面板。默认文件夹也可在该设置分组中修改。

笔记文件的开头保存了问题、时间、模型、范围，以及每条引用对应的文件路径、文件哈希、字节与行范围和保存时的原文。正文是回答本身，只保留正文实际引用到的来源并按出现顺序重新编号；文末附“依据”列表。这些信息随笔记文件保存；复制或同步后，仍需确保引用路径能找到原文，且来源已加入当前知识库。

## 核对引用

打开笔记时，编辑器顶部会显示笔记状态。每条引用按当前文件内容判定为以下状态之一：

| 状态 | 含义 |
| --- | --- |
| 一致 | 来源文件未变 |
| 位置已更新 | 文件变了，但引用的段落完整出现在新位置；行号自动更新 |
| 原文已改 | 引用的段落被修改；可查看保存时与当前内容的词级对照 |
| 来源缺失 | 文件被删除，或当前文件里找不到相近的段落 |
| 未核对 | 来源不在知识库中、无法读取，或笔记格式无法解析 |

来源文件被索引或删除时，状态随之更新；点击“重新检查”可立即按磁盘内容核对。展开引用列表后，可以打开原文、查看对照或保存时的原文；“重新提问”会用笔记的问题和范围新建会话。文件列表中，笔记旁显示状态点，文件夹显示需要关注的笔记数量，筛选器可只看“待核对笔记”。核对不调用任何模型。

## 管理会话

在问答首页的“会话列表”中打开历史记录，点击搜索图标可搜索标题和回答内容。打开会话后，点击顶部返回箭头回到列表并开始新问题；已有会话仍保留。生成期间返回按钮禁用，需先停止生成。侧栏始终用于浏览文件夹。

同一会话继续提问时，尚未总结的历史包含之前的问题、最终回答和精简工具记录。历史工具调用按模型接口原生的工具调用与工具结果消息回放：每次调用保留名称、参数、状态及结果的前 500 个字符，最终回答以纯文本放在其后；思考过程和中途文字不带入下一轮。这样模型不会把内部记录格式当成回答格式模仿。模型服务拒绝这种回放形式时（HTTP 400 或 422），应用会把同样的记录改写成纯文本附在上一轮回答之后重发一次。界面中仍可查看完整记录。

模型偶尔仍会把最终回答包装成带 answer 字段的 JSON 对象。对象只含 answer、sources、tool_history 这几个字段时，应用会在校验引用前解包其中的正文，界面只显示正文；sources 编号列表转为可校验的引用标记。用户要求的其他 JSON 结构保持原样。

每次继续请求模型前都会检查上下文预算，包括工具调用过程中。内容接近预算时会提前压缩并预留余量，应用使用当前问答模型生成摘要，保留任务、用户约束、已确认事实与证据、已完成工作、未完成事项和下一步。摘要替代较早的内容，预算允许时保留最近一轮问答和最近一次完整工具调用。

特别长的历史会分批总结并合并，每批输入不超过 32,768 tokens 且不超过回答上下文预算，默认 65,536 的预算通常只需一到两批。摘要优先使用已适配模型的免思考模式，并为已确认支持的模型设置输出上限；其他兼容端点不强加这些参数。摘要长度取服务返回的输出 token 数与本地估算中的较小值，避免把思考 token 计入；服务未返回时只用本地估算。完整摘要随会话保存，后续追问继续使用。总结会产生额外模型请求，不占工具调用次数。

摘要请求在连接、可重试 HTTP 错误、响应正文超时或流式响应未完整结束时，会按高级运行参数中的模型重试次数、间隔和总时限有限重试。第一次重试重新请求当前块；连续失败时进一步缩小当前块。在同一次压缩任务中，已成功处理的分块会保留，重试不会从头总结或重新执行工具操作。界面显示当前分块序号、估算的总分块数和重试进度，例如“正在压缩上下文：第 2/3 块”。取消会停止等待和重试。恢复进度仅保留在当前运行任务中，不跨应用重启或手动重新发起问答保存。

重试仍失败时，本轮不再整体失败：应用只保留最近一轮对话、本轮工具记录和当前问题继续作答，此前已生成的摘要仍随通知一起保留，回答上方提示“本次未能生成上下文摘要”，可展开查看失败原因，回答统计行注明略去的较早轮数。这次退化不会保存为摘要，下一轮追问会再次尝试生成模型摘要。未完整接收的摘要不会用于后续回答。完整问题、回答、工具记录及引用原文仍保存在本地，不会被摘要覆盖。

请求始终将系统提示词放在开头，包括引用检查、空回答检查和工具调用上限提醒后的再次请求。工具结果和引用编号保持不变。

模型的最终回复只有空白时，应用会要求模型重答一次；仍为空则按失败处理并显示“模型没有返回回答内容”，不会把空回答标记为完成。历史记录中已存在的空回答在界面显示占位说明，并提供重新生成入口。某条回答的 Markdown 渲染出错时，该条退化为纯文本显示，不影响其他回答。

同一轮内，模型连续用完全相同的参数调用同一个 SAG 工具时，前两次照常执行；连续第三次不再执行，直接返回“结果不会改变”的说明，该记录在界面标为“已跳过”且不计入调用次数；连续第四次后停止本轮工具调用，要求模型根据已有证据作答。中间出现不同的调用会重新计数。模型服务不遵守停止要求、仍继续发起调用时，本轮以“模型反复发起相同的工具调用”说明和已取得的资料列表结束，不会无限等待。外部 MCP 工具可能有副作用，不做重复判定。模型调用了当前未绑定的工具（例如历史轮次用过、之后被停用的工具）时，应用把“工具未启用”作为该调用的结果返回给模型并继续本轮，不再直接报错终止。

## 配置回答模型

在模型设置中填写服务地址、模型与 API Key。需要语义检索时，同时配置 Jev。Jev 用于查找证据，回答模型用于组织最终答案。

## 跨语言资料

问答会要求模型在同一次自然语言检索中提供中英文等义表述，保留原问题的条件，方便中文提问查找英文资料。中文提问默认用中文回答；也可以在问题中指定其他回答语言。

这一行为由问答提示词引导。展开处理过程可以查看实际检索内容，点击引用可以核对英文原文。精确文字、代码和文件路径不要求翻译。

搜索页和独立 MCP 调用仍按传入的查询检索。使用第三方 MCP 客户端时，由该客户端决定查询语言。

## 问答设置详解

入口：**设置 → 问答设置**。先在“问答模型”中选中要配置的模型。

![按模型配置思考强度与系统提示词](/images/product-chat-settings-cn.png)

### 按模型保存的设置

| 设置 | 用途 | 注意事项 |
| --- | --- | --- |
| 思考强度 | 调整模型提供的思考档位 | 可用值由模型与服务决定。更高档位通常更慢；不支持时使用默认。 |
| 系统提示词 | 指定回答角色、语言、风格或任务要求 | 仅影响当前模型。留空使用内置提示词；清空可恢复内置提示词。 |
| SAG 内置工具 | 允许模型检索本地文件、读取、匹配、获取时间和计算 | 可关闭整个工具组或单个工具。语义搜索还需要 Jev。 |
| 外部 MCP 绑定 | 选择该模型可用的外部服务与工具 | 服务连接配置可共用，绑定与工具选择按模型保存。 |

思考强度以界面实际可选值为准，部分模型提供关闭、低、中、高或极高。出现“未适配”时不要把它理解为模型完全不能使用；它表示当前服务与模型组合尚未适配强度参数，可恢复默认。

系统提示词不会替代模型连接配置，也不能让不支持工具调用的模型获得工具能力。工具的添加、测试与调用确认见 [MCP 与工具绑定](/zh/docs/mcp)。

### 所有模型共用的请求设置

| 设置 | 默认值 / 范围 | 用途与影响 |
| --- | --- | --- |
| 每轮工具调用上限 | 20 / 0–100 | 默认 20；设置为 1–100 时，限制同一轮问答中 SAG 与外部 MCP 工具的总调用次数，被跳过的重复调用不计入。填 0 表示不限制次数。达到指定上限后根据已有结果回答，并说明尚未确认的部分。已保存为 0 的设置保持不限制。 |
| 回答上下文预算（tokens） | 65536 / 最小 4096 | 控制问题、历史、工具记录和引用等输入规模。没有固定最大值，应按模型实际上下文能力填写；超预算时应用会缩减可用历史或材料。 |
| 请求超时 | 120 秒 / 10–600 秒 | 适用于每次问答及摘要模型请求，包含读取响应正文的时间；不是整轮问答的总时限。太短可能中断较慢模型，太长会延长失败前等待。 |

上下文预算不等于输出长度设置，输出长度由模型服务决定。填入超过服务上限的值，不会提高模型能力，反而可能导致请求失败。

工具调用上限与 SAG2 扩展轮数也不同：一次 `search` 工具调用内部可以包含多轮检索及多次 Jev 请求。

### 保存与验证

保存后新发一条问题，检查所选模型、工具是否出现、引用是否能打开。改变模型时，重新确认该模型的提示词、思考强度和工具绑定，而非假设沿用上一个模型的配置。

回答上方出现“本次未能生成上下文摘要”且原因包含超时时，可先把请求超时调至 300 秒（最高 600 秒）再重试。这可缓解客户端时限不足，不能保证解决模型服务或代理先行断开的问题。每个摘要分块及其重试、等待和响应读取，还受高级运行参数中的“模型请求总时限”约束。
