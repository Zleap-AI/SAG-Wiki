## 从本地资料开始

![SAG Wiki 文件管理界面](/images/product-folders-cn.png)

SAG Wiki 直接读取你添加的文件夹，原始文件保留在原处。桌面端与 CLI 共用同一个后台服务、索引和配置；退出桌面端后，CLI 仍可使用。

## 选择适合的使用方式

| 需要做什么 | 从哪里开始 | 配置要求 |
| --- | --- | --- |
| 查找词语、文件和原文 | [搜索](/zh/docs/search) | 添加文件夹，无需模型密钥 |
| 按完整问题查找跨文档证据 | [深入检索](/zh/docs/search#深入检索) | 配置 Jev |
| 根据资料生成带引用的回答 | [问答](/zh/docs/chat) | 配置回答模型；语义检索另需 Jev |
| 让 Agent 搜索项目 | [Agent 接入](/zh/docs/agents) | CLI、Skill 与 Jev 配置 |

## 极速建库，保留原文

建库无需 LLM 或 Embedding。已有性能测试中，每百万字索引约 200 ms；实际耗时随设备、文件数量、格式和转换任务变化。

检索结果保留来源位置。问答中的引用可以打开完整文档，定位并高亮相应段落。

<Callout title="关于数据">原文件保留在本地。深入检索和问答会把所需问题、文档片段或上下文发送给你配置的服务；本地快速搜索无需网络模型。</Callout>
