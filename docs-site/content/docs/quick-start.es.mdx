## 1. Instala y abre SAG Wiki

Elige el instalador apropiado en la [guía de instalación](/es/docs/installation). La primera vez que abras la aplicación verás un tutorial. Para verlo de nuevo, ve a **Configuración → General** y abre **Inicio rápido**.

Durante la inicialización se crea `Documents/sag-wiki/clippings` y se añade `Documents/sag-wiki` a las carpetas administradas. Puedes seguir usando tu biblioteca existente.

## 2. Añade una carpeta

Pulsa **+** junto a **Administrar carpetas** en la barra lateral y selecciona una carpeta que quieras consultar. La indexación se ejecuta en segundo plano. Puedes buscar en los archivos que ya se hayan procesado. Consulta [Carpetas e indexación](/es/docs/folders).

## 3. Busca archivos

Abre **Búsqueda** y escribe un término que aparezca en el nombre o en el contenido de un archivo. Selecciona un resultado para abrir el original y resaltar la coincidencia.

## 4. Haz una pregunta

Para encontrar evidencia en varios documentos, configura el punto de conexión y el modelo de Jev en **Configuración → Modelos**. Introduce la clave de API si el servicio la requiere y prueba la [búsqueda profunda](/es/docs/search#búsqueda-profunda).

Si también quieres generar una respuesta, configura el modelo de respuestas y abre [Preguntas y respuestas](/es/docs/chat). Abre una cita para comprobar la fuente. Escribe `@` para elegir archivos y delimitar la pregunta.
