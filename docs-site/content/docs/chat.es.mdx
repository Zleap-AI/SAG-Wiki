## Hacer una pregunta

En **Configuración → Modelos**, introduce el punto de conexión, el nombre del modelo y la clave de API del modelo de respuestas. Configura también Jev si quieres utilizar la búsqueda semántica. Abre **Preguntas y respuestas**.

Escribe tu pregunta y envíala. Usa `@` para seleccionar archivos concretos. La respuesta se muestra a medida que la aplicación recupera la información y genera el texto.

## Ver las fuentes

Selecciona una cita para abrir la fuente en el fragmento correspondiente. Comprueba que el documento respalda la respuesta antes de usarla. Puedes delimitar el tema o añadir condiciones en una nueva pregunta si necesitas una respuesta más precisa.

Puedes pedir que la respuesta se escriba en un idioma concreto. El idioma de la interfaz se aplica a los menús y controles.
