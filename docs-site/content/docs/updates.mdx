## 0.4.5

- **文档查看模式**可在「设置 → 通用」设为 Markdown 的默认打开方式，初始设置为编辑。在查看模式下点击右上角的「编辑」可原地修改，保存后回到查看模式。长 Markdown 和 PDF 的 Markdown 转换稿也适用。
- **修复 SAG Wiki 助手的回答流式输出**。配置回答模型后，回答会在生成过程中实时显示。

## 0.4.4

- **新增 Agent 产物导入功能**，支持归档 Claude Code、Claude Desktop、Codex 和 WorkBuddy 生成的文件。可按文件类型筛选、勾选文件，并为各应用单独开启自动同步。
- **Linux 网页端**支持从服务器已接入的文件夹导入和自动同步 Agent 产物。可以选择交付目录和归档位置，归档后的文件可在文件页查看。
- **聊天记录导入**新增 Claude Desktop 和 WorkBuddy。可预览和选择会话，再按来源保存为 Markdown。工具调用默认隐藏。
- **设置页**调整侧栏分组、间距和颜色，并将重新索引的提示放到操作旁。

## 0.4.3

- **在线数据源**新增 GitHub、GitLab、钉钉文档、腾讯 ima、API 请求和 Apify。GitHub 和 GitLab 可按分支、目录或单个 Markdown 文件同步。API 请求支持在桌面端和 Linux 网页端通过 GET 或 POST 获取 JSON，选择字段并定时追加到每日 Markdown，可在同一天内按记录 ID 去重，也可选用 AI 清洗。Apify 可在后台运行 Actor，将网页正文或选定字段导入为 Markdown，并按连接设置定时同步。
- **导入入口**统一为「设置 → 数据源」，也可从文件页右键进入。首次在线导入成功后可直达保存目录，默认导入位置在 `sag-wiki/data-sources/` 下按平台和连接组织。
- **网络代理**统一在「设置 → 网络代理」配置和测试。

## 0.4.2

- **快速配置**：未配置回答模型时，问答首页和快速入门提供「快速配置」入口。填入一个 302.AI API Key 并测试通过后，自动配好 qwen3.8-flash 回答模型、jev-latest 决策模型和 302.AI MinerU 解析。新安装的默认回答模型改为 qwen3.8-flash。([PR #188](https://github.com/Zleap-AI/SAG-Wiki/pull/188))
- **网络代理**：新增「设置 → 网络代理」页面，可选跟随系统、自定义或不使用代理。自定义代理支持 SOCKS5 和账号密码，密码只保存在本机；测试连接会报告实际走的线路。([Issue #171](https://github.com/Zleap-AI/SAG-Wiki/issues/171)、[Issue #125](https://github.com/Zleap-AI/SAG-Wiki/issues/125)、[PR #183](https://github.com/Zleap-AI/SAG-Wiki/pull/183))
- **探索模式**：转换结果存放在应用数据目录时，PDF、Office 文档不再从探索视图中消失。([Issue #185](https://github.com/Zleap-AI/SAG-Wiki/issues/185)、[PR #186](https://github.com/Zleap-AI/SAG-Wiki/pull/186))
- **问答回复格式**：多轮追问时不再出现 `{"answer":…}` 形式的 JSON 回答。([PR #177](https://github.com/Zleap-AI/SAG-Wiki/pull/177))
- **上下文压缩**：压缩时显示“第 N/M 块”进度，不再像卡死；摘要失败时继续作答并说明原因，不再整轮失败。
- **空回答**：模型只返回空白时自动重试一次，仍为空则明确报错，不再显示“已完成”却没有正文。
- **工具调用**：同一轮内参数完全相同的重复检索自动跳过；每轮调用上限默认改为 20，已设为 0 的继续不限制。

## 0.4.1

- **SAG Wiki 助手**：内置中英文更新日志。输入完整版本号即可检索该版本的改动，繁体中文、日语、韩语和西班牙语界面也可查阅英文日志。
- **更新日志链接**：从助手的引用打开内置日志后，点击下载安装、文件夹管理等链接会跳转到官网对应页面。
- **帮助入口**：左下角问号打开当前界面语言的在线文档，保留当前会话。问答首页仍可进入 SAG Wiki 助手。

## 0.4.0

- **在线数据导入**：支持连接飞书、Lark、Notion、语雀和 RSS / Atom，按所选范围导入知识库。每个连接可手动或定时同步；未变化的内容会跳过，保留本地编辑。
- **Linux 网页端**：可在浏览器创建文件夹、上传文件或整个目录，上传后自动索引。网页设置支持配置模型、连接在线数据源，以及管理 API、MCP 和密钥。
- **PDF 和图片识别**：可选用支持图片输入的问答模型解析 PDF、PNG 和 JPEG，分别设置 PDF 和图片提示词。现有 Docling 和 MinerU 解析方式继续可用。
- **网页远程访问**：CLI 可配置公网 IP 或 HTTPS 反向代理的外部地址，并控制网页访问码。Linux 新配置默认关闭访问码，已有设置保留；远程使用时可开启验证。
- **聊天记录导入**：Claude Code 和 Codex 可分别设置定时导入，默认关闭。新增消息更新原 Markdown，未变化的会话会跳过。预览自动定位到最新消息。
- **应用数据位置**：桌面端可迁移索引、配置、问答记录和应用内转换结果，并保留旧目录作为备份。桌面端与 CLI 共用新位置；远程服务自启和文件夹授权随迁移更新，数据目录不可用时可在启动时选择已有数据目录。([PR #176](https://github.com/Zleap-AI/SAG-Wiki/pull/176))
- **SAG Wiki 助手**：可在问答首页直接查询内置使用指南，点击引用可定位原文。未配置回答模型时仍可检索并查看相关章节。
- **统一代理**：问答模型、Jev、MinerU、应用更新、组件下载、分享和远程 HTTP MCP 共用代理设置。支持指定直连地址和在保存前测试连接。
- **Linux 文件监听**：达到监听上限时，CLI 和索引详情提示调高 inotify 配额并重启后台服务；已索引内容仍可搜索。([Issue #174](https://github.com/Zleap-AI/SAG-Wiki/issues/174), [PR #175](https://github.com/Zleap-AI/SAG-Wiki/pull/175))

## 0.3.13

- **桌面更新源**：官方更新源随已保存的界面语言切换。简体中文使用 Zleap 官网，其余界面语言使用 GitHub。升级时迁移默认官方更新设置，并保留自定义更新源。
- **多语言支持**：在通用设置中可选择新增的日语、繁体中文、韩语和西班牙语，适用于桌面主界面、网页界面、快捷搜索和托盘。文档站提供这四种语言的安装、入门、文件、搜索和问答指南。
- **问答滚动**：修复流式回答偶尔停止自动跟随的问题，滚回底部后可继续跟随新内容。

## 0.3.12

- **大文档解析提速**：长 PDF 分段并发调用 MinerU，并行数跟随文档解析设置，默认 2，所有文档共享总并发上限；显示已完成和正在处理的分段，失败重试复用成功段，结果按原页顺序合并。([PR #165](https://github.com/Zleap-AI/SAG-Wiki/pull/165))

## 0.3.11

- **项目文件夹授权**：MCP 与 HTTP API 的 Key 可绑定多个知识库根目录或子目录，不同项目使用各自的 Key，仅搜索和浏览授权范围，公共目录可同时授权给多个项目。([PR #159](https://github.com/Zleap-AI/SAG-Wiki/pull/159))
- **存量升级兼容**：已有 Key、MCP 地址、客户端配置和工具调用保持兼容，继续访问全部知识库及以后新增的目录；只有主动设置文件夹范围的 Key 才受限。
- **范围管理与配置复制**：远程服务设置和 CLI 支持创建、编辑文件夹范围；多个可复制 Key 时明确选择项目凭据。范围修改取消该 Key 的运行中及排队请求，失效目录不会回退为全库访问。
- **文内查找**：修复文本包含连字或全角字符时，希腊语词尾 Sigma 无法匹配的问题，并保留正确的原文高亮位置。 ([PR #155](https://github.com/Zleap-AI/SAG-Wiki/pull/155))

## 0.3.10

- **发布耗时优化**：前端资源只构建一次，复用原生输入未变时已通过的原生 Rust 测试，移除 Safari 开发包、重复未签名 DMG 和重复端到端验证；保留三平台安装包验证与 Mac 签名公证。
- **平台下载入口**：发布页直接列出 Windows x64、Apple Silicon 和 Intel 安装包下载链接，每次正式发布继续包含三个平台。

## 0.3.9

- **Intel Mac 公证连接**：在 Intel 签名任务中让 Apple 公证票据请求使用 TCP，避免运行器 HTTP/3 连接中断；保留签名、公证及票据验证。
- **发布任务恢复**：失败任务重跑时复用未重新执行的成功构建及其原始 checkpoint，避免 attempt 编号变化造成产物缺失；无需重复编译。
- **发布兼容性验证**：修正 Windows 换行格式导致的发布回归测试失败，以及 Intel Mac 更新验证中固定使用 Apple Silicon 目标的测试清单；保留原有安装包、签名和公证检查。

## 0.3.8

- **Intel Mac 安装包**：发布流程新增 Intel Mac（`x86_64`）独立安装包与应用内更新包，与 Apple Silicon（`arm64`）和 Windows x64 包分别构建。两种 Mac 架构并行签名与公证，并复用现有构建缓存。
- **按架构下载**：中英文安装页说明 Mac 芯片与安装包的对应关系，仅在正式版本实际包含 Intel 安装包时显示下载入口。

## 0.3.7

- **分享记录**：分享弹窗和数据导入设置新增分享记录，查看本机发起的分享名称、分享码、分享时间和到期时间；过期记录自动清理。
- **取消分享**：支持取消本机创建的有效分享，成功后分享码失效、服务器文件删除，本地列表同步移除；失败时保留记录以便重试，已下载的副本不受影响。
- **CLI 分享管理**：新增 `sag share-history` 和 `sag cancel-share` 命令，支持以 JSON 查看分享记录，并同步更新 Agent Skill 使用说明。

## 0.3.6

- **文件分享**：支持分享 Markdown 文件或文件夹，自动打包正文引用的本地图片并保留目录结构。确认后上传并生成分享码，可复制分享码和接收指引。
- **接收分享**：添加文件夹窗口新增“接收分享”标签页，文件页空白处右键也可接收。支持从剪贴板识别分享码，确认保存位置后下载并加入知识库；默认接收到文档目录下的 `sag-wiki/share`，可更改位置或关闭剪贴板识别，同名文件夹自动编号。
- **CLI 分享与下载**：新增 `sag share` 和 `sag download` 命令，无需启动桌面端或配置模型；支持指定下载位置，并同步补充 Agent Skill 使用说明。
- **索引详情显示**：文件设置新增“显示索引详情”开关，默认关闭；开启并保存后显示文件页的索引状态与详情入口。关闭后仍可通过索引历史查看进度和失败原因。
- **索引状态操作**：侧栏状态卡片标题旁提供暂停、继续和关闭按钮。处理期间关闭卡片不影响后台索引，同一轮任务刷新时保持隐藏。
