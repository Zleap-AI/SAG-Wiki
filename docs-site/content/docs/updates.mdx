## 0.2.0

以下为相对 0.1.9 的更新。

### 新功能与改进

- **内置文档转换**：文本型 PDF、Word、PowerPoint、Excel/CSV、OpenDocument 和 EPUB 无需下载转换组件。扫描件仍需 OCR 组件，其他格式按需安装。见[文件格式与转换](/zh/docs/folders#其他格式与转换组件)。
- **网页剪藏**：预览网页正文后保存本地 Markdown，可将保存目录加入知识库。支持 Chrome / Edge；Safari 导出取决于桌面构建是否附带已签名、公证的扩展安装包。见[网页剪藏](/zh/docs/web-clipper)。
- **文档阅读与编辑**：新增标题目录、当前文档问答、首次保存命名与目录选择，并改善转换后文档的打开和编辑。见[文件与编辑](/zh/docs/files)。
- **Mermaid 与问答展示**：文档、搜索、引用及回答可在本地显示 Mermaid 图表；问答处理过程自动折叠并显示用时。
- **长会话摘要**：超出上下文预算时使用当前模型生成并保存摘要，完整历史保留；工具调用仍默认每轮 10 次，可设为 0 取消次数限制。见[问答](/zh/docs/chat)。
- **MCP 工具绑定**：添加服务和导入 JSON 使用独立弹窗，明确显示连接与当前模型启用状态，新增移除确认与撤销。见[MCP 与工具绑定](/zh/docs/mcp)。
- **双语帮助**：新增中英文操作指南与界面截图，覆盖桌面、CLI 和 Agent 接入。

### Bug 修复

- 未配置模型时默认使用本地快速搜索，跳过需要回答模型的自动摘要；语义检索和问答分别提示所需配置。
- 后台服务连接失败时显示错误并重连，恢复后清除临时错误；事件消费者落后时不再直接断开事件流。
- 索引跳过不可读子目录；无法读取 `.sagignore` 时停止该范围扫描，避免忽略规则失效。
- 检索跳过失效原文和超过 Jev 单项输入预算的候选，避免单份文档中断查询；搜索数量扣除当前页跳过的失效项。
- 修复 Windows 转换输出编码与 uv 目录联接处理，并调整 8 GiB 设备的转换内存预算。
- 转换组件安装显示实际进度，模型下载源不可达时及时报错；其他格式默认不预选。
- 内置转换缓存纳入 anydoc 版本，后续索引时更新旧缓存，保护用户编辑及原文未变时已有的有效转换结果，避免原文变化后继续使用旧结果。
- 外部链接在系统浏览器中打开；手动上滚阅读回答后，生成完成不再跳回底部。
- 已关闭的相同索引失败提示不再重复出现，新的失败仍会提醒，并改善 Windows 索引路径显示。
