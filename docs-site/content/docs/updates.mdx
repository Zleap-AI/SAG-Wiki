本页按时间倒序整理主要功能变化，包含开发版汇总、正式版本和早期开发记录。日期使用北京时间。历史条目描述当时行为，当前用法以对应功能文档为准。

标注“已发布”的版本附有正式发布说明；开发版汇总不表示其中每项功能都在当天首次实现，也不表示已包含在最新安装包中。

## 2026-10-23 · 0.2.0 开发版

状态：开发中，尚未正式发布。

### 新增功能

- **Mermaid 图表**：文档、搜索预览、引用原文和问答中可以显示图表。编辑器默认显示 SVG，悬停后点击“编辑”修改源码，再点击“预览”查看结果。详见 [Mermaid 图表](/zh/docs/files#mermaid-图表)。
- **文档目录**：Markdown 编辑器按标题生成目录，支持点击跳转、随滚动标示当前章节，并在编辑标题后同步更新。详见[文档目录](/zh/docs/files#文档目录)。
- **网页剪藏**：浏览器扩展可将网页正文保存为本地 Markdown，支持 Chrome、Edge 和 macOS Safari。授权保存目录后，无需运行 SAG Wiki 即可保存；将目录加入知识库后可检索内容。当前提供本地测试安装包，Windows 实机保存尚未验证。详见[网页剪藏](/zh/docs/web-clipper)。

### 功能调整

- **Markdown 与状态栏显示**：补全问答中的表格边框、引用块、列表和任务列表样式；索引状态文字可换行，避免与关闭按钮重叠。
- **常用文档内置解析**：Word、PowerPoint、Excel、OpenDocument、RTF、CSV、EPUB 和文本型 PDF 由内置 anydoc 本地解析，无需先安装转换组件。扫描 PDF 和其他格式可按需安装 Docling。详见[文件格式与转换](/zh/docs/folders#其他格式与转换组件)。
- **文件列表与索引状态**：文件夹内可切换“全部”“已索引”“未索引”，保留对子目录的浏览。已转换文档的原文件会被识别为已索引，点击后打开对应的 Markdown；编辑转换结果不改动原始 Office 或 PDF 文件。详见[文件管理](/zh/docs/files)。
- **新建文档的保存位置**：在文件夹内新建时保存到当前文件夹；从“已索引文件”总览新建时先选择保存位置。点击“保存”后才写入文件并更新索引。详见[新建文档](/zh/docs/files#新建文档)。
- **按文件夹设置索引**：可单独选择文件类型和转换格式，作用于当前目录及没有独立设置的子目录。设置保留已有忽略规则；重新索引只重建所选文件夹的索引。详见[文件夹索引设置](/zh/docs/folders#单个文件夹的索引设置)。
- **分阶段索引与转换**：先处理直接支持的文本，再并行转换其他文档并索引转换结果。已完成索引的内容可以先行搜索；索引详情可查看阶段、当前文件、失败记录，并暂停或继续任务。详见[索引进度与历史](/zh/docs/folders#重新索引与索引历史)。

## 2026-10-22 · 0.1.9

状态：已发布。[正式发布说明](https://github.com/Zleap-AI/SAG-Wiki/releases/tag/v0.1.9)

- **本地 Jev 接入**：支持基础地址和完整接口地址，修复重复拼接 `/systemone` 导致连接失败的问题。
- **无需鉴权模式**：Jev 新增“无需鉴权”选项，桌面端和 CLI 均可连接不要求 API Key 的本地服务；旧配置继续使用 API Key 鉴权。
- **密钥配置保护**：保留跨供应商密钥隔离，修复无效配置保存时可能删除已有 Jev 密钥的问题。
- **Windows CLI 修复**：修复启动后台服务后命令输出不结束，以及子目录搜索结果路径不完整的问题。
- **索引与转换改进**：改善文件索引的资源占用、转换组件安装和进度显示。
- **更新签名迁移**：新增 macOS、Windows 集中签名发布流程。0.1.8 及更早版本需要手动安装一次 0.1.9，之后从新签名通道继续应用内更新；旧更新通道保留在 0.1.8。

## 2026-10-18 · 共享后台与问答

以下为早期开发记录，不对应单独的正式版本。

- **共享后台服务**：桌面端和 CLI 统一使用独立 SAG 服务，共用索引与配置；CLI 可以在桌面窗口关闭后继续工作。
- **工具调用过程**：显示并保存工具执行耗时，折叠卡片显示检索阶段；知识库问题优先使用 SAG 工具，首轮保留已启用工具。
- **回答显示顺序**：先完成首次工具需求判断，再展示正式回答；保留工具调用前后的流式文字，思考过程按事件顺序显示。
- **原文引用**：引用可以打开完整文档并返回原会话；合并重复文档引用，只显示实际引用来源，编号保持连续。
- **会话导航**：历史会话移入主工作区，阅读文档和查看会话后可通过返回操作继续原流程。
- **检索调整**：桌面端默认候选数调整为 50、扩展轮数为 1；改善保留句子边界的切分和排序词项处理；精确匹配跳过无命中文档的额外准备。

## 2026-10-17 · 独立 CLI 与检索调整

- **独立 CLI**：CLI 可独立运行并与桌面端共用内核，支持首次配置引导和 npm 分发。命令从早期的 `sgrep` 更名为 `sag`。
- **本地匹配**：增加正则表达式、固定字符串匹配，以及忽略大小写、整词、上下文等 grep 风格选项。
- **Agent 使用说明**：Skill 按需加载参考文档，补充语义搜索、精确匹配跟进、问题拆分和忽略规则的使用方式。
- **检索片段**：默认切分目标调整为 512 字符，改善章节、表格上下文及词项初始化处理。

## 2026-10-16 · 模型、后台运行与文件管理

### 模型与问答

- **供应商选择**：回答模型提供 OpenAI、DeepSeek、GLM、OpenRouter、302.AI 和自定义接口；Jev 提供 302.AI、OpenRouter、Typesafe。选择后填入对应地址，并保留各供应商独立的密钥。
- **302.AI 密钥补齐**：回答模型和 Jev 均选择 302.AI 时，可自动补齐另一项空白且未保存的密钥；已保存或手动编辑的密钥保持独立。
- **默认接口与请求格式**：新配置的 Jev 默认使用 302.AI 的专用接口及 `jev-latest`；回答模型预设统一使用 Chat Completions 格式，工具和思考参数按模型能力处理。
- **追问工具流程**：需要资料时先调用工具，再生成正式回答，修复先显示临时回答、随后清空重写的问题。
- **流式回答**：改善 Markdown 连续渲染和滚动稳定性，保留手动上滚暂停跟随、回到底部恢复跟随的行为。

### 后台运行与知识库

- **关闭窗口后继续运行**：Windows 使用系统托盘，macOS 使用菜单栏图标，后台问答、索引和文件监听继续工作；可从菜单恢复窗口或真正退出。
- **退出与图标修复**：修复 Windows 关闭窗口所需权限，完善未保存文档的退出确认，并更新桌面、开始菜单和安装器图标。
- **文件夹移除与恢复**：CLI 可添加、授权和移除项目目录；移除保留原文件，子目录排除状态可恢复。
- **忽略规则**：索引和搜索遵循项目及子目录中的 `.gitignore`、`.sagignore`，保留目录层级与规则优先级。
- **本地文档探索**：增加文档关系图、关联词、原文依据、局部探索及导航，支持缩放、拖动与返回；关系计算不调用回答模型。
- **CLI 与工具设置**：加入原生 CLI 和 Agent 接入设置，完善终端 PATH、安装位置记录和连接检查；问答提示词、模型连接和工具权限分别管理。

## 2026-10-15 · 搜索分页、引导与 MCP

- **快速搜索分页**：按文件合并命中，每页显示 20 个文件，显示完整结果数量；仅加载当前页正文，翻页失败或停止时保留已有结果。
- **深入搜索分页**：按已排好的文件顺序分页，同文件片段先合并；翻页不重新检索或调用模型。
- **首次使用引导**：加入文件接入、SAG2 检索、原文引用和开始使用四步引导，支持鼠标、触控板与键盘操作；完成后记住状态，可从设置重新查看。
- **性能与评测说明**：引导中补充建库速度的测试依据和适用范围，论文评测说明可展开查看。
- **内置 MCP 工具**：在原有检索入口基础上提供 `search`、`list`、`read`、`grep`，可按模型独立选择，共用范围控制、引用编号、调用次数和上下文预算。
- **模型与外部工具设置**：支持按模型保存提示词和 MCP 绑定，工具列表可展开配置，调用卡片保留参数、结果和错误。
- **结果与上下文提示**：无命中时明确显示未找到内容；有命中时显示来源与原文，材料被省略时说明数量及原因。回答上下文预算取消 128000 的固定上限，保留最小 4096、默认 65536 的设置。

## 2026-10-14 · 首版本地知识库

- **本地资料接入**：提供独立桌面应用、SQLite 索引、目录树、文件夹范围选择和文件变化监听，移除接入目录保留原文件。
- **快速搜索与深入检索**：普通关键词搜索改为本地 BM25，无需模型密钥；主动选择深入搜索后运行 SAG2。深入检索停止或失败时保留已有本地结果。
- **文档编辑**：支持 Markdown 编辑、新建后保存、草稿保留及外部修改冲突检查；长文本和代码检索保留对应原文范围，引用可定位到具体内容。
- **问答与历史**：支持模型切换、流式回答、停止生成、`@` 指定文件、引用查看，以及历史会话重命名、恢复等操作。
- **模型工具调用**：由回答模型选择检索问题，保留多次工具调用、稳定引用编号及上下文预算控制，改善 Jev 长请求分批处理。
- **输入法修复**：确认中文输入法候选时不再误发送问题；普通回车发送和 Shift+Enter 换行继续可用。
- **模型配置与凭据**：提供连接测试、模型设置与密钥管理，改用本地凭据文件，避免开发版反复触发系统密码授权。
