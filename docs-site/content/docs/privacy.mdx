## 数据保存在哪里

入口：**设置 → 数据与隐私 → 应用数据位置 → 打开目录**。

应用数据目录保存 SQLite 索引、目录信息、设置、模型密钥、问答记录、引用、工具日志和草稿。不同安装方式可能使用不同目录；请从当前正在使用的应用打开目录。

原始文件保留在你添加的文件夹中。Markdown 编辑并保存会修改原文件；移除索引和卸载程序与编辑文件是不同操作。

## 更改应用数据位置

桌面端进入 **设置 → 数据与隐私 → 应用数据位置**，可以查看完整路径、打开目录或点击 **更改位置**。选择已存在的空文件夹，核对新旧位置后点击 **迁移并重启**。

应用会先停止共享后台服务，再复制索引、设置、密钥、问答记录、草稿以及保存在应用数据目录中的转换结果，校正内部路径后保存新位置并自动重启。目录内的资料随之复制，目录外的资料与转换结果留在原处，无需重新索引。桌面端与支持此功能的新版 CLI 共用新位置。已启用的远程服务自启会改用新位置，MCP 与 API Key 的文件夹授权继续有效。

旧数据目录保留为备份，会继续占用磁盘空间。请预留足够空间，迁移期间保持应用运行；本页未保存的设置不会保留。复制或校验失败时不会切换位置，错误会显示在确认窗口中；目标目录必须为空，也不能与旧目录互相包含。

如果启动时保存的位置不可用，例如移动硬盘未连接，先重新连接原磁盘。也可以在启动提示中选择包含现有 SAG 数据库的旧目录。选择旧备份后，迁移以来的新记录仍保存在原数据位置，不会合并到旧备份。

如果启动时设置了 `SAG_DATA_DIR` 或 `SAG_DESKTOP_DATA_DIR`，这些环境变量优先，界面会显示提示并禁用更改位置；先移除环境变量并重启。网页端不提供此操作。

## 哪些操作发送网络请求

| 操作 | 数据流向 |
| --- | --- |
| 原生文本索引、快速搜索、文件浏览、本地关联图 | 本地处理，无需回答模型或 Jev |
| SAG2 深入检索、CLI 语义搜索 | 问题、候选原文及必要上下文发送到配置的 Jev 服务 |
| 问答 | 问题、相关历史、工具结果与引用发送到配置的回答模型；检索部分另用 Jev |
| 搜索自动总结 | 问题与选中的搜索结果发送到所选总结模型 |
| 外部 MCP | 按该工具的参数与服务实现访问对应本地或远程资源 |
| 启用MinerU后的文档解析 | 原文档发送到所选302.AI或MinerU官方，结果下载到本地；测试连接不上传文件 |
| 更新、转换组件与识别模型下载 | 从对应下载服务获取文件 |
| 文档分享 | 用户确认后，选中的 Markdown 与引用图片上传至临时分享服务；分享码持有人在有效期内可下载 |

密钥以当前用户可访问的本机文件保存，不代表同账户下所有程序都无法读取。分享日志或应用数据前，需要移除密钥和敏感内容。

## 清理操作的区别

| 操作 | 删除什么 | 保留什么 |
| --- | --- | --- |
| 清空所有对话 | 全部对话、思考过程和工具调用日志，包括此前删除的对话 | 本地原文件、知识库与索引、模型设置和密钥 |
| 移除所有文件夹 | 全部已添加目录的接入记录和索引 | 本地原文件、会话、草稿、模型设置 |
| 清除所有数据 | 对话、文件夹与索引、搜索记录、模型设置、密钥、草稿；设置恢复默认 | 本地原文件 |
| 卸载文档转换组件 | SAG Wiki 安装的 Docling、运行环境、识别模型及下载缓存 | 原文件、转换结果与已有索引 |

前三项都位于“数据与隐私”，执行前有单独确认。卸载转换组件位于 **文件设置 → 更多文件格式**。确认执行的清理不能通过取消设置撤回。

## 索引文件占用空间

SQLite 索引与日志文件位于应用数据目录。移除所有文件夹会触发索引空间回收；原文目录与会话独立管理。清理后重新添加目录，需要重新索引。

不要在应用或共享服务正在写入时，直接手动删除数据库及日志文件。需要清理时使用对应的应用操作。

## 减少不必要的数据访问

只添加需要检索的目录，用 `.sagignore` 排除敏感文件；提问时缩小查询范围。对外部 MCP，只为需要使用的模型绑定必要工具。详见[文件夹与索引](/zh/docs/folders)和 [MCP 与工具绑定](/zh/docs/mcp)。

笔记导入在本机处理 Notion、Evernote、Google Keep 的导出文件；Apple Notes 使用本机只读数据库快照。导入过程不上传笔记，不修改来源数据；导入后的 Markdown 与附件按知识库规则保存。
