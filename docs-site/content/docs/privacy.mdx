## 数据保存在哪里

入口：**设置 → 数据与隐私 → 应用数据位置 → 打开目录**。

应用数据目录保存 SQLite 索引、目录信息、设置、模型密钥、问答记录、引用、工具日志和草稿。不同安装方式可能使用不同目录；请从当前正在使用的应用打开目录。

原始文件保留在你添加的文件夹中。Markdown 编辑并保存会修改原文件；移除索引和卸载程序与编辑文件是不同操作。

## 哪些操作发送网络请求

| 操作 | 数据流向 |
| --- | --- |
| 原生文本索引、快速搜索、文件浏览、本地关联图 | 本地处理，无需回答模型或 Jev |
| SAG2 深入检索、CLI 语义搜索 | 问题、候选原文及必要上下文发送到配置的 Jev 服务 |
| 问答 | 问题、相关历史、工具结果与引用发送到配置的回答模型；检索部分另用 Jev |
| 搜索自动总结 | 问题与选中的搜索结果发送到回答模型 |
| 外部 MCP | 按该工具的参数与服务实现访问对应本地或远程资源 |
| 更新、转换组件与识别模型下载 | 从对应下载服务获取文件 |

密钥以当前用户可访问的本机文件保存，不代表同账户下所有程序都无法读取。分享日志或应用数据前，需要移除密钥和敏感内容。

## 清理操作的区别

| 操作 | 删除什么 | 保留什么 |
| --- | --- | --- |
| 清空所有对话 | 全部对话、思考过程和工具调用日志，包括此前删除的对话 | 本地原文件、知识库与索引、模型设置和密钥 |
| 移除所有文件夹 | 全部已添加目录的接入记录和索引 | 本地原文件、会话、草稿、模型设置 |
| 清除所有数据 | 对话、文件夹与索引、搜索记录、模型设置、密钥、草稿；设置恢复默认 | 本地原文件 |
| 卸载文档转换组件 | SAG Wiki 安装的 Docling、运行环境、识别模型及下载缓存 | 原文件、`.sag-converted` 转换文件与已有索引 |

前三项都位于“数据与隐私”，执行前有单独确认。卸载转换组件位于 **文件设置 → 其他格式**。确认执行的清理不能通过取消设置撤回。

## 索引文件占用空间

SQLite 索引与日志文件位于应用数据目录。移除所有文件夹会触发索引空间回收；原文目录与会话独立管理。清理后重新添加目录，需要重新索引。

不要在应用或共享服务正在写入时，直接手动删除数据库及日志文件。需要清理时使用对应的应用操作。

## 减少不必要的数据访问

只添加需要检索的目录，用 `.sagignore` 排除敏感文件；提问时缩小查询范围。对外部 MCP，只为需要使用的模型绑定必要工具。详见[文件夹与索引](/zh/docs/folders)和 [MCP 与工具绑定](/zh/docs/mcp)。
