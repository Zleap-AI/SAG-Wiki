Evernote 是一款笔记应用，可用笔记本整理笔记，并将笔记导出为 ENEX 文件。[Evernote 官网](https://evernote.com/)

1. 在 Evernote 桌面端右键点击要导出的笔记本，选择 **导出笔记本**，再选择 **ENEX (.enex)** 格式并保存。

   ![Evernote 桌面端导出笔记本时选择 ENEX 格式](/images/evernote-export-enex.jpg)

   截图来源 · [OneNoteGem](https://en.onenotegem.com/a/documents/onenote-batch/2019/1122/829.html)

2. 在 SAG Wiki 桌面端[打开数据源](/zh/docs/data-sources#打开数据源)，点击 **Evernote** 旁的 **导入笔记**。
3. 点击 **选择文件**，可一次选择多个 ENEX 文件。确认保存位置后点击 **导入**。笔记会转换为 Markdown 并加入知识库。

![选中 Evernote 导出的 ENEX 文件](/images/product-source-evernote-cn.png)
