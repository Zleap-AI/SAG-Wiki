## Añadir una carpeta

Pulsa **+** junto a **Administrar carpetas** en la barra lateral y selecciona la carpeta que contiene tus documentos. Puedes buscar en los archivos a medida que se indexan. Los originales permanecen donde estaban.

El texto que se extrae directamente de un PDF puede estar disponible antes de que terminen el OCR y el reconocimiento de tablas. Las páginas que solo contienen imágenes se pueden buscar cuando termina su reconocimiento e indexación.

## Ajustar el alcance de una búsqueda

Selecciona las carpetas que quieras consultar desde la pantalla de búsqueda. En **Configuración → Archivos**, puedes cambiar los tipos de archivo que se indexan y los nombres de las carpetas que se excluyen. También puedes revisar la configuración de indexación de una carpeta concreta.

## Consultar el progreso y los fallos

Durante la indexación, consulta el estado en la barra lateral. En **Configuración → Archivos**, activa **Mostrar detalles de indexación** para ver también el progreso en la lista de archivos. Si un archivo no se procesa, puedes ver la causa en el historial de indexación y volver a intentarlo.
