## 设置如何保存

在侧栏打开 **设置**，从左侧选择分类，修改后点击 **保存设置**。单栏布局中，从顶部下拉菜单选择分类。点击 **取消** 或左上角返回箭头可放弃未保存的普通设置；界面语言会在选择时预览，退出时恢复。

设置侧栏分为「应用」「知识库」「搜索与问答」「连接与服务」和「其他」。「其他」包含「数据与隐私」和「关于」。

测试连接只验证当前填写的配置，不等于保存。移除密钥、安装或卸载 Skill、恢复目录、清理数据等独立操作会立即执行或单独要求确认，不依赖底部的保存按钮。

## 通用

入口：**设置 → 通用**。

| 设置 | 作用 | 默认或可选值 |
| --- | --- | --- |
| 启动页面 | 下次打开应用时首先显示哪个页面 | 默认问答；可选问答、搜索 |
| 文档默认打开方式 | 设置打开已有 Markdown 文件时的模式 | 默认编辑。选择查看后，点击右上角的 **编辑** 进入编辑器。 |
| 界面语言 | 调整应用菜单、按钮和提示的语言 | 默认简体中文，可选简体中文、繁體中文、English、日本語、한국어、Español |
| 关闭窗口后 | 显示关闭窗口后的运行方式 | 后台继续运行 |
| 快速入门 | 重新查看文件接入、搜索与问答教程 | 点击“查看教程” |

关闭窗口后可以从托盘或菜单栏重新打开应用。在 Windows 上再次点击桌面快捷方式，会恢复已有窗口，不会启动第二个桌面实例。在 macOS 上，按 **⌘Q** 或选择 **退出 SAG Wiki** 只退出桌面客户端，后台继续运行，CLI 和 MCP 可继续使用。在 Windows 上，选择 **退出 SAG Wiki** 会先停止独立后台并等待清理完成，再退出客户端；CLI 和 MCP 连接会断开。之后重新打开桌面或执行需要服务的 CLI 命令时会按需启动后台。停止失败时会显示错误并保留客户端。

保存后的界面语言也适用于 Web 工作区、快捷搜索和桌面托盘菜单。文档站提供[繁体中文](/zh-TW/docs)、[日语](/ja/docs)、[韩语](/ko/docs)和[西班牙语](/es/docs)核心指南。

## 网络代理

在 **设置 → 网络代理** 选择代理模式。问答模型、Jev、MinerU、应用更新、Docling 组件下载、分享服务和远程 HTTP MCP 共用此设置，使用同一数据目录的 CLI 分享也会读取已保存的配置。在线数据导入及其账号授权不使用这份设置。

| 代理模式 | 行为 |
| --- | --- |
| 跟随系统代理（默认） | 读取 Windows「设置 → 网络和 Internet → 代理」或 macOS「系统设置 → 网络 → 代理」中手动配置的 HTTP/HTTPS 代理，以及 `HTTP_PROXY`、`HTTPS_PROXY`、`ALL_PROXY`、`NO_PROXY` 环境变量，环境变量优先。暂不支持 PAC 脚本和自动发现 |
| 自定义代理 | 使用指定的代理服务器，直连地址除外 |
| 不使用代理 | 始终直接连接，忽略系统代理和环境变量 |

选择自定义代理后填写：

- **代理地址**：支持 `http://`、`https://`、`socks5://` 和 `socks5h://`，例如 `http://10.0.0.8:3128`。只写主机和端口时按 HTTP 代理处理。粘贴形如 `http://用户:密码@主机:端口` 的地址时，账号和密码会自动移入认证字段。
- **代理需要认证**：打开后填写用户名和密码，以 Basic 方式发送给代理服务器。密码与 API 密钥一样只保存在本机应用数据目录，不写入设置数据库，再次打开设置时留空即保持原密码；关闭认证会删除已保存的密码。只填密码不填用户名时无法保存。
- **直连地址**：用逗号、分号或换行分隔，可填写域名（`corp.example.com` 同时匹配其子域名）、以点开头的后缀、IP、网段（`10.0.0.0/8`）或带 `*` 的匹配规则。`localhost` 与回环地址始终直接连接，适合本机或局域网内的模型服务。跟随系统代理时也可以填写直连地址，作为系统绕过规则的补充。

**测试连接** 按当前填写的设置请求已保存的问答模型地址，并报告实际线路，例如“已通过代理 10.0.0.8:3128 连接 api.302ai.cn（HTTP 401）”。收到任何 HTTP 状态都说明代理线路可用，401 或 404 只表示该地址需要密钥或路径不同；跟随系统代理时还会说明是否检测到系统代理。改动任一字段会清除上一次结果，测试不会保存设置。

保存后立即生效，无需重启桌面或后台服务。正在进行的请求保持原连接，下一次请求使用新设置。uv、pip、Hugging Face 模型下载以及 stdio 方式启动的 MCP 服务通过 `HTTP_PROXY`、`HTTPS_PROXY`、`NO_PROXY` 环境变量获得同样的代理；MCP 服务自带环境变量中只要包含任一代理变量，就完全按服务自己的配置运行。不使用代理时这些变量会被清除。

## 外观

入口：**设置 → 外观**。

| 设置 | 作用 | 默认或可选值 |
| --- | --- | --- |
| 主题 | 设置应用明暗外观 | 默认浅色；浅色、深色、跟随系统 |
| 文档字号 | 调整文档正文大小，设置页有正文预览 | 默认 15 px；14、15、16、18 px |

文档字号调整的是阅读显示，不修改原文件中的文字。跟随系统会使用系统的明暗主题。

![主题、文档字号与正文预览](/images/product-appearance-cn.png)

## 快捷键

入口：**设置 → 快捷键**。这里可以自定义或关闭快捷搜索的全局快捷键，并查看其他键盘操作。

快捷搜索默认使用 macOS 的 **⌘⇧Space** 或 Windows 的 **Ctrl+Shift+Space**。点击快捷键输入框录入组合键，再点击“应用快捷键”，立即保存并生效。快捷键冲突会显示错误；也可点击“打开快捷搜索”验证弹窗。详见[快捷搜索弹窗](/zh/docs/search#快捷搜索弹窗)。

关闭或启用右侧开关后，同样点击“应用快捷键”保存。

![快捷搜索开关、全局快捷键与操作按钮](/images/product-quick-search-settings-cn.png)

| 操作 | macOS | Windows |
| --- | --- | --- |
| 搜索文件 | ⌘ K | Ctrl K |
| 新建问答 | ⌘ N | Ctrl N |
| 保存文档 | ⌘ S | Ctrl S |
| 发送问题或执行搜索 | Enter | Enter |
| 问题中换行 | Shift Enter | Shift Enter |
| 引用文件 | 输入 `@` | 输入 `@` |

## 运行参数

文件、模型、搜索和问答设置分别提供对应的运行参数，常用项直接展示，线程、内存、批量和缓存位于**高级运行参数**。每组可恢复默认，后端统一校验范围和参数关系。

![转换超时和高级运行参数](/images/product-runtime-cn.png)

| 页面 | 可调整参数 |
| --- | --- |
| 文件设置 | 内置转换和Docling超时、输入/输出大小、线程、OCR/表格开关及批量、页数、内存预算、文本限制、文件变更合并；MinerU 的解析参数位于「配置 MinerU」 |
| 模型设置 | 请求失败重试次数、初始/最大退避间隔、总时限 |
| 搜索设置 | 决策模型并发和上下文预算、本地查询线程、查询/语料缓存 |
| 问答设置 | 文档折叠并发、每批段落数 |

内置转换默认120秒；Docling默认1800秒，外层自动额外预留60秒清理进程。转换正文默认16MiB，与后续索引入口一致；需要更大正文时，一起提高转换输出、索引输入、解码、准备及总预算。单任务内存0表示自动，实际并发还受转换并行数与可用预算限制。

保存后新任务使用新值，正在运行的任务保持启动时参数。超时、并发和缓存变化不重建索引；OCR、表格、页数和解析引擎变化会在后续扫描重算相应转换。anydoc超时后放弃结果，但原生线程可能继续运行到库调用返回；Docling超时会终止子进程树。
