## 设置如何保存

点击左下角“设置”，在左侧选择分类，修改后点击 **保存设置**。点击 **取消** 放弃未保存的普通设置；界面语言会在选择时预览，取消后恢复。

测试连接只验证当前填写的配置，不等于保存。移除密钥、安装或卸载 Skill、恢复目录、清理数据等独立操作会立即执行或单独要求确认，不依赖底部的保存按钮。

## 通用

入口：**设置 → 通用**。

| 设置 | 作用 | 默认或可选值 |
| --- | --- | --- |
| 启动页面 | 下次打开应用时首先显示哪个页面 | 默认问答；可选问答、搜索 |
| 界面语言 | 调整应用菜单、按钮和提示的语言 | 默认简体中文；可选简体中文、English |
| 关闭窗口后 | 显示关闭窗口后的运行方式 | 后台继续运行 |
| 快速入门 | 重新查看文件接入、搜索与问答教程 | 点击“查看教程” |

关闭窗口后可以从托盘或菜单栏重新打开应用。桌面界面与本地后台服务分别运行；关闭桌面不等于停止 CLI 服务。

![启动页面、界面语言和快速入门设置](/images/product-preferences-cn.png)

## 外观

入口：**设置 → 外观**。

| 设置 | 作用 | 默认或可选值 |
| --- | --- | --- |
| 主题 | 设置应用明暗外观 | 默认浅色；浅色、深色、跟随系统 |
| 文档字号 | 调整文档正文大小，设置页有正文预览 | 默认 15 px；14、15、16、18 px |

文档字号调整的是阅读显示，不修改原文件中的文字。跟随系统会使用系统的明暗主题。

![主题、文档字号与正文预览](/images/product-appearance-cn.png)

## 快捷键

入口：**设置 → 快捷键**。这里可以自定义或关闭快捷搜索的全局快捷键，并查看其他键盘操作。

快捷搜索默认使用 macOS 的 **⌘⇧Space** 或 Windows 的 **Ctrl+Shift+Space**。点击快捷键输入框录入组合键，再点击“应用快捷键”，立即保存并生效。快捷键冲突会显示错误；也可点击“打开快捷搜索”验证弹窗。详见[快捷搜索弹窗](/zh/docs/search#快捷搜索弹窗)。

关闭或启用右侧开关后，同样点击“应用快捷键”保存。

![快捷搜索开关、全局快捷键与操作按钮](/images/product-quick-search-settings-cn.png)

| 操作 | macOS | Windows |
| --- | --- | --- |
| 搜索文件 | ⌘ K | Ctrl K |
| 新建问答 | ⌘ N | Ctrl N |
| 保存文档 | ⌘ S | Ctrl S |
| 发送问题或执行搜索 | Enter | Enter |
| 问题中换行 | Shift Enter | Shift Enter |
| 引用文件 | 输入 `@` | 输入 `@` |
| 在引用列表中选择、确认、关闭 | ↑ / ↓、Enter、Esc | ↑ / ↓、Enter、Esc |

## 运行参数

文件、模型、搜索和问答设置分别提供对应的运行参数，常用项直接展示，线程、内存、批量和缓存位于**高级运行参数**。每组可恢复默认，后端统一校验范围和参数关系。

![转换超时和高级运行参数](/images/product-runtime-cn.png)

| 页面 | 可调整参数 |
| --- | --- |
| 文件设置 | 内置转换和Docling超时、输入/输出大小、线程、OCR/表格开关及批量、页数、内存预算、文本限制、文件变更合并 |
| 模型设置 | 请求失败重试次数、初始/最大退避间隔、总时限；MinerU独立解析参数 |
| 搜索设置 | JEV并发和上下文预算、本地查询线程、查询/语料缓存 |
| 问答设置 | 文档折叠并发、每批段落数 |

内置转换默认120秒；Docling默认1800秒，外层自动额外预留60秒清理进程。转换正文默认16MiB，与后续索引入口一致；需要更大正文时，一起提高转换输出、索引输入、解码、准备及总预算。单任务内存0表示自动，实际并发还受转换并行数与可用预算限制。

保存后新任务使用新值，正在运行的任务保持启动时参数。超时、并发和缓存变化不重建索引；OCR、表格、页数和解析引擎变化会在后续扫描重算相应转换。anydoc超时后放弃结果，但原生线程可能继续运行到库调用返回；Docling超时会终止子进程树。
