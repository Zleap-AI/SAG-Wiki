## 设置如何保存

点击左下角“设置”，在左侧选择分类，修改后点击 **保存设置**。点击 **取消** 放弃未保存的普通设置；界面语言会在选择时预览，取消后恢复。

测试连接只验证当前填写的配置，不等于保存。移除密钥、安装或卸载 Skill、恢复目录、清理数据等独立操作会立即执行或单独要求确认，不依赖底部的保存按钮。

## 通用

入口：**设置 → 通用**。

| 设置 | 作用 | 默认或可选值 |
| --- | --- | --- |
| 启动页面 | 下次打开应用时首先显示哪个页面 | 默认问答；可选问答、搜索 |
| 界面语言 | 调整应用菜单、按钮和提示的语言 | 默认简体中文；可选简体中文、English |
| 关闭窗口后 | 显示关闭窗口后的运行方式 | 后台继续运行 |
| 快速入门 | 重新查看文件接入、搜索与问答教程 | 点击“查看教程” |

关闭窗口后可以从托盘或菜单栏重新打开应用。桌面界面与本地后台服务分别运行；关闭桌面不等于停止 CLI 服务。

![启动页面、界面语言和快速入门设置](/images/product-preferences-cn.png)

## 外观

入口：**设置 → 外观**。

| 设置 | 作用 | 默认或可选值 |
| --- | --- | --- |
| 主题 | 设置应用明暗外观 | 默认浅色；浅色、深色、跟随系统 |
| 文档字号 | 调整文档正文大小，设置页有正文预览 | 默认 15 px；14、15、16、18 px |

文档字号调整的是阅读显示，不修改原文件中的文字。跟随系统会使用系统的明暗主题。

![主题、文档字号与正文预览](/images/product-appearance-cn.png)

## 快捷键

入口：**设置 → 快捷键**，当前提供快捷键说明。

| 操作 | macOS | Windows |
| --- | --- | --- |
| 搜索文件 | ⌘ K | Ctrl K |
| 新建问答 | ⌘ N | Ctrl N |
| 保存文档 | ⌘ S | Ctrl S |
| 发送问题或执行搜索 | Enter | Enter |
| 问题中换行 | Shift Enter | Shift Enter |
| 引用文件 | 输入 `@` | 输入 `@` |
| 在引用列表中选择、确认、关闭 | ↑ / ↓、Enter、Esc | ↑ / ↓、Enter、Esc |

## 帮助文档

点击左侧底部的 **?** 按钮，用系统默认浏览器打开 [SAG Wiki 文档站](http://sag-wiki.zleap.com)。当前会话或文档仍保留在应用中，收起侧边栏后也可以使用。
